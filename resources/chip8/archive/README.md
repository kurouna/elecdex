# chip8Archive

The CHIP-8 pane's library, from https://github.com/JohnEarnest/chip8Archive, commit
761e3ffc63f43e6a849e80714122feff2afca208 (2026-09-15): every `.ch8` in its `roms/`, and its `programs.json` as `source.json`.

Everything in chip8Archive is placed under Creative Commons 0 (CC0 1.0), "No Rights
Reserved": https://creativecommons.org/publicdomain/zero/1.0/ - the authors are named in
`source.json` and in the pane beside each program.

Update with `node scripts/gen-chip8.mjs --archive <a newer checkout>`.
