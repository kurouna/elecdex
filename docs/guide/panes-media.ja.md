# メディアのペイン — elecdex

elecdex は eDEX-UI を Electron で作り直した SF 風のターミナルエミュレーター兼システムモニターです。このページでは、メディアのペインを説明します。**Spectrum**（コンピューターが再生している音のスペクトラムアナライザー）、Web ペインの **Browser, YouTube and X**、**Mixer**（システムとアプリごとの音量）、**Now playing**（いまのメディアセッションと、前へ・再生／一時停止・次へ）です。それぞれのペインが何をいつ読むか、何を決して読まず送らないかを、Windows、macOS、Linux について書きます。elecdex は Windows で開発し使っています。macOS と Linux は GitHub Actions のテストでビルドして動かしているだけで、手での検証は十分ではありません。

## media プリセット

| | |
|---|---|
| 開き方 | Ctrl+Shift+F5、または LAYOUTS ダイアログ |
| ペイン | YouTube (TV)、その下に Now playing・Spectrum・Mixer を横に並べ、X と RSS をタブに。左にシステム列 |

プリセットはひな形です。選ぶと保存レイアウトが 1 つ追加され、その後は作業に合わせて変わります。どのペインも既定のレイアウトにはなく、ペインのピッカー（Ctrl+Shift+A）からも追加できます。ショートカットは *Settings → Keyboard* で変えられます。プリセットの一覧は [presets.ja.md](presets.ja.md#media) にあります。

## Spectrum

<p align="center">
  <img src="../screenshots/pane-spectrum.jpg" alt="Spectrum ペイン単体：蛍光管シアンのセグメントの列とピーク、下に帯域のラベル">
  <br><sub>Spectrum</sub>
</p>

| | |
|---|---|
| 開き方 | media と retro のプリセット。ピッカー: "spectrum"。ワークスペースの上にポップアップでき、前面に出せる |
| 読むもの | システムの音声出力（ループバックキャプチャ）。レベルだけ |
| 更新 | ペインが画面に出ている間だけ。音がある間は 1 秒に 20 フレーム、無音の間は描かない |
| プラットフォーム | Windows: 検証済み。macOS: 同じ画面キャプチャの経路で、画面収録の許可が要る。未検証。Linux: PulseAudio か PipeWire 上の `parec`（pulseaudio-utils） |
| プライバシー | キャプチャは専用の隠しウィンドウで行い、ペインに届くのはレベルだけ。録音はしない |
| 設定 | ペインの設定ボタン: スタイル、帯域の数、パターン、ピークホールド |

### 使い方

- ピッカーから追加します。システムの音声出力を 7、10、16、31 のいずれかの帯域に分け、1990 年代のカーステレオの表示のように、ピークを保持するセグメントの列で表示します。
- 設定ボタンで選ぶもの:
  - スタイル: VFD シアン（既定）、VFD 琥珀、LED、テーマの色
  - 帯域の数: 7、10、16、31
  - パターン: バー、鏡像、ピークのみ
  - ピークホールド
- VFD と LED は自前の暗いガラスの上に描くので、明るいテーマでも同じに見えます。選んだものはペインの状態に残ります。
- *no sound* のような短い状態は設定ボタンと同じ行に出し、バーには重ねません。長い理由（キャプチャできない、モニターがミュート）は表示の上に出します。

### 音の取り方

- **Windows と macOS**: Chromium が再生中の音を取れるのは、ループバック音声付きの画面キャプチャだけです。elecdex はその許可をワークスペースに与えません。キャプチャは専用の隠しウィンドウ（`main/audio/capture-window.ts`）で行います。このウィンドウはメモリだけの専用セッション（画面キャプチャを許すのはこのセッションだけ）、フレームと状態を送るだけの preload、ネットワークのないページを持ちます。キャプチャに必要な映像トラックはすぐ止めます。
- 隠しページは 4096 点の FFT を 20 Hz〜20 kHz の対数の 60 本のビンにまとめ、1 秒に 20 回送ります。無音が 2.5 秒続くと送るのをやめ、読み取りを 1 秒に 10 回に落とします。main はそのウィンドウからの通信だけを受け、形を確かめてから購読しているペインに渡します。
- ペインはビンを帯域にまとめます。31 帯域は 20 Hz〜20 kHz の ISO 1/3 オクターブです。
- **Linux**: Electron に Linux のループバックキャプチャがないため、main が `parec --device=@DEFAULT_MONITOR@` を起動し、既定の出力のモニターを録ります（既定の入力、つまりマイクは録りません）。解析は隠しページと同じ手順で main が行います。
  - システム設定でモニターの音量を下げていても補正するので、バーは鳴っているとおりの音を示します。
  - モニターがミュートされているときはそう知らせ、**unmute monitor** ボタンを出します。システムの設定が変わるのはこのボタンを押したときだけで、main がモニターのミュートを解除し、音量を 100% にします。
  - `parec` がない、または止まったときは理由を出します。ペインを開き直すともう一度試します。

### 負荷と制限

- ペインが別のタブの後ろにある、閉じた、ウィンドウが最小化されたときは音を拾わず、隠しキャプチャウィンドウも止まります。
- i5-1335U での実測: 音が鳴っている間はコアの約 3 分の 1、画面に出ていて無音の間は約 10 分の 1。
- macOS のループバックキャプチャは検証していません。

## Browser, YouTube and X

<p align="center">
  <img src="../screenshots/pane-web.jpg" alt="Browser, YouTube and X ペイン単体。代わりのページを表示している">
  <br><sub>Browser, YouTube and X・代役のページ</sub>
</p>

| | |
|---|---|
| 開き方 | media プリセット（YouTube (TV) と X）。ピッカー: "browser"、"youtube (tv)"、"x"。どれも複数置け、前面に出せる |
| 読むもの | サイト。main が持つ別のブラウザービューで表示する |
| 更新 | 裏のタブや最小化中もページは動き続け、動画は再生を続ける |
| プラットフォーム | Windows、macOS、Linux（macOS と Linux は手で検証していない） |
| プライバシー | elecdex にアクセスできない。カメラ、マイク、位置情報、通知は使えない。ダウンロードできない。http(s) だけ。サイトごとのサインインはすべての Web ペインで 1 つを共有し、アプリの他の部分とは分けて持つ |
| 設定 | *Settings → General → tint pages in the theme's colour*（既定 off）、*Settings → General → sign out of all sites*、ペインごとの ◐ ボタン |

### 3 つのペイン

- **Browser** にはアドレスバーがあり、任意の http(s) のページを開けます。
- **YouTube (TV)** は YouTube のリビングルーム向けインターフェース（`youtube.com/tv`）を開き、矢印キーで操作します。これを YouTube のペインとして提供しているのは、サインインできるのがこちらだからです。表示されるコードを、スマートフォンで yt.be/activate に入力します。Google は埋め込みブラウザーからのサインインを拒否します（「このブラウザまたはアプリは安全でない可能性があります」）。elecdex は Google がテレビ向けに用意しているデバイスのサインインを使い、ペインを Chrome に見せかけることはしません。
- **X** は x.com を開きます。
- YouTube (TV) と X はそれぞれのサイトにとどまります。他のサイトへのリンクは、自分でたどったとき（ペインでのクリックやキーの数秒以内。1 回の押下で 1 タブ）だけ既定のブラウザーに送ります。ページが勝手にサイトの外へ移ろうとしたときは、その場にとどめます。
- 以前の YouTube ペイン（デスクトップ版のサイト）はサインインできないため、ピッカーには出しません。保存されたレイアウトが名指ししていれば、今までどおり開きます。

### Web ペインの使い方

- 各ペインには戻る、進む、再読み込み（サイトのペインではホーム）、*open in your browser* のボタンがあります。YouTube (TV) の動画を *open in your browser* で開くと、その動画の視聴ページを渡します。
- 右クリックメニュー: 戻る、進む、再読み込み、切り取り、貼り付け（入力欄のみ）、コピー、すべて選択、リンクのコピー、リンクを既定のブラウザーで開く。
- 各ペインは再起動をまたいでページを覚えています。覚えたページがペインのサイトの外なら、サイトのホームを開きます。
- ペインを動かしても、タブを付け替えても、ページは再読み込みしません。
- ページがキーボードを受け取っている間もアプリのショートカットは効き、それ以外のキーはすべてページに届きます。そのとき押しても何もしないショートカット（タブグループの外でのタブのキーなど）はページに渡します。
- ポインターがページの上にある間は、ステータスバーと全画面時のウィンドウコントロールは現れません。ショートカットを使うか、ポインターを別のペインに移してください。
- 動画の全画面ボタンは elecdex のウィンドウいっぱいに広げます。ペインが隠れる前に、ページは全画面を抜けます。

### 色

- ページは既定では本来の色で表示します。
- アドレスの右にある ◐ ボタンで、そのペインのページを見ている間テーマの色で描けます。
- *Settings → General → tint pages in the theme's colour* は、自分のボタンを使っていないペインの既定です。Business テーマでは色付けしません。
- ページにはテーマの明暗（`prefers-color-scheme`）を伝え、自分で色を決めていないページにはそれに合う既定の色を与えます。暗いテーマでも文字が読めます。

### ページにできること、できないこと

- ページはペインの上に重ねた、サンドボックス化された別のブラウザービュー（Electron の `WebContentsView`）が描きます。iframe や `<webview>` は使いません。preload はなく、elecdex にアクセスできません。ワークスペース自身のセキュリティの設定は変わりません。
- 権限はクリップボードへの書き込み（リンクのコピー）と全画面だけです。カメラ、マイク、位置情報、通知、そのほかはすべて拒否します。
- ダウンロードはすべて取り消します。開くのは http、https、`about:blank` だけで、`file:` や `javascript:` などは、アドレスバーに打ったときも拒否します。
- User-Agent からは Electron と elecdex の印を外します。スペルチェックは切ってあり、辞書をダウンロードしません。
- Google や Apple のサインインのウィンドウは、同じセッションの子ウィンドウとして開きます。ペインごとに 1 枚までで、ペインを閉じると閉じます。

### サインインとサイトのデータ

- すべての Web ペインは 1 つのセッション（`persist:web`）を共有し、アプリのほかの部分はこれを使いません。YouTube へのサインインは一度で、どの YouTube ペインにも、Browser ペインで開いた youtube.com にも効きます。
- セッションを共有するため、同じサイトの 2 つのアカウントを並べては使えません。
- *Settings → General → sign out of all sites* で、このセッションのサイトのデータを削除します。

### 裏のタブとダイアログ

- Web ペインは「見えている間だけ読む」の例外です。別のタブの後ろでも、最小化中も、ページは再生を続けます。描画と動画のデコードも続くので、長く置いた裏のタブも CPU と GPU を使います。
- ダイアログ、通知、ドラッグ中のペインがページの上に重なっている間は、ページの代わりにその静止画を表示します。

## Mixer

<p align="center">
  <img src="../screenshots/pane-mixer.jpg" alt="Mixer ペイン単体：master と音を出しているアプリのストリップ。それぞれにフェーダー、ミュートボタン、ピークメーター">
  <br><sub>Mixer</sub>
</p>

| | |
|---|---|
| 開き方 | media プリセット。ピッカー: "mixer"。ワークスペースの上にポップアップでき、決まった大きさで前面に出せる |
| 読むもの | 出力デバイスの音量とミュート。Windows と Linux では音を出している各アプリも |
| 更新 | ペインが画面に出ている間だけ。Windows は状態を毎秒、ピークを 0.1 秒ごと。macOS と Linux は 2 秒ごと |
| プラットフォーム | Windows: マスター、アプリ、ピークメーター。macOS: マスター音量のみ。Linux: マスターとアプリ |
| 設定 | なし |

- 各ストリップにはフェーダーとミュートボタン、Windows ではピークメーターもあります。アプリは Windows の音量ミキサーと同じく、プロセス名でまとめます。
- 読み方:
  - **Windows**: 常駐する 1 つの PowerShell で Core Audio を読むループを回します。ペインが要らなくなれば終わります。
  - **macOS**: AppleScript で、マスター音量だけ。
  - **Linux**: `pactl`（PulseAudio または PipeWire。PulseAudio 16 以降の pactl）で、既定のシンクとアプリを読み、変えます。pactl がない、または JSON を出せない古いものなら、マスター音量には WirePlumber の `wpctl` を使います。どちらもなければそう表示し、ツールが失敗したときはエラーの 1 行目を出します。
- 変更はすぐ画面に反映し、まだ追いついていない読み取りでフェーダーが戻ることはありません。
- i5-1335U での実測: コアの約 5%。そのうち PowerShell の分は 1.3%。

## Now playing

<p align="center">
  <img src="../screenshots/pane-nowplaying.jpg" alt="Now playing ペイン単体：架空の曲のために描いたジャケットの横に曲名・アーティスト・アルバム、位置のバー、前へ・再生／一時停止・次へのボタン">
  <br><sub>Now playing</sub>
</p>

| | |
|---|---|
| 開き方 | media プリセット。ピッカー: "now playing"。ワークスペースの上にポップアップでき、決まった大きさで前面に出せる |
| 読むもの | Windows が「いまのもの」とするメディアセッション（System Media Transport Controls） |
| 更新 | 1 秒に 2 回、ペインが画面に出ている間だけ。裏のタブ、最小化、格納中は何も読まない |
| プラットフォーム | **Windows のみ。** macOS と Linux はまだサポートしていない（ペインに UNSUPPORTED と表示） |
| プライバシー | ディスクにもログにも何も書かない。プラグインからは届かない。音量は変えない |
| 設定 | なし |

### 表示するもの

- Windows が「いまのもの」とするメディアセッション: Spotify、YouTube を再生中のブラウザー、メディア プレーヤーなど、再生中の内容をシステムに伝えるプレーヤーすべて。いまのものがなければ、再生中の最初のもの。
- アート、曲名、アーティスト、アルバム、アプリ名と、曲のどこにいるか。プレーヤーは位置をときどきしか報告しないので、報告の間はペインが 1 秒ごとに数え進めます（終わりは越えません）。長さのないストリームにはバーを出しません。
- ランプ: PLAYING、PAUSED、NO SESSION、STANDBY、UNSUPPORTED。
- elecdex 自身の Web ペインが再生しているときは、アプリ名を `elecdex` と出します。
- アートにポインターを留める（またはキーボードで移る）と、アートを大きく、曲名・アーティスト・アルバムを全文で出し、プレーヤーの名前と Windows の id、長さ、アートの元の大きさ、ほかのプレーヤーの数を添えるカードが開きます。

### 押せるもの

- 前へ・再生／一時停止・次へ。どれもプレーヤーが受け付けるときだけ出します。プレーヤーが押下を断ったときは、ボタンの横に 3 秒だけそう出します。
- プレーヤーが再生位置の変更を受け付けるときは、バーに頭が付き、ドラッグ、または ← →（5 秒）と Home / End で動かせます。新しい位置は離したときに 1 回だけ送ります。受け付けないときは頭の無いメーターで、つまめるようには見せません。
- ページが押せるのはこれらとシークだけで、音量は変えません（それは Mixer の領分）。それもペインを表示している間だけです。
- 再生／一時停止にショートカットはありません。フォーカスしたボタンは Space か Enter で押せます。

### 読み方

- main が常駐する 1 つの PowerShell でセッションを読みます。最初にペインが表示されたときに起動し、最後のペインが消えてから 15 秒後に閉じるので、ペインを動かしても起動し直しません。i5-1335U での実測: 最初の答えまで約 0.6 秒、その後は 1 回の読み取りが約 1 ms。
- アートはリーダーの中で小さくし、確かめた JPEG としてページに渡します。カード用の大きいものは、カードが開くまで main のメモリに置きます。ディスクには何も書きません。
- Now playing はメトリクスのソースではなく、プラグイン API にもありません。
- macOS: Apple のメディアのインターフェースは非公開で、署名のないプロセスには答えなくなったため、リーダーはありません。Linux（D-Bus の MPRIS）はまだ作っていません。
