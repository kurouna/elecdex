# ネットワークの利用とデータソース — elecdex

elecdex は Windows・macOS・Linux 向けのデスクトップのターミナルエミュレータ兼システムモニタです。このページは、elecdex がつなぐ先、送るもの、頻度、利用条件をすべて挙げます。画面（レンダラー）自体はネットワークにつなげず（`connect-src 'self'`）、下の要求はすべてメインプロセスが、ペインや設定がそのデータを要る間だけ行います。テレメトリや利用状況の収集はありません。IP アドレスの国は同梱の GeoIP データベースで調べ、外部の検索サービスは使いません。

| データ | 提供元 | 備考 |
| --- | --- | --- |
| 天気（日本） | [Japan Meteorological Agency](https://www.jma.go.jp/) の予報 JSON: `https://www.jma.go.jp/bosai/forecast/data/forecast/<office code>.json` | Web ページをスクレイピングするのではなく、JSON を直接読みます。これは気象庁自身の[予報ページ](https://www.jma.go.jp/bosai/forecast/)が読み込むデータで、公開された API ではないため、寛容に解析し、取得に失敗しても最後の予報を表示し続けます。天気ペインが日本の地点を表示しているときだけ、気象庁の発表時刻（日本時間 0、5、11、17 時）の前後に、条件付きリクエストで取得します。気象庁の[利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)に従って利用しており、規約が求めるクレジット「出典：気象庁ホームページ（https://www.jma.go.jp/bosai/forecast/）を加工して作成」を、JSON の元である予報ページを示してペインに表示します。 |
| 天気（アメリカ合衆国） | [National Weather Service](https://www.weather.gov/) (api.weather.gov) | オープンデータです。地点の検索結果は 1 日保持し、予報はペインがその地点を表示している間だけ、おおむね 1 時間ごとに取得します。 |
| 天気（その他の地域） | [MET Norway](https://api.met.no/) Locationforecast 2.0 | [CC BY 4.0](https://api.met.no/doc/License)。ペインにクレジットを表示します。リクエストは[利用条件](https://api.met.no/doc/TermsOfService)に従います: 識別できる User-Agent、小数点以下 4 桁の座標、直前の応答の `Expires` より前には送らない（かつ最低 30 分の間隔）、If-Modified-Since。 |
| 天気の地点選択に使う都市一覧 | [GeoNames](https://www.geonames.org/)（人口 50 万人以上の都市と首都） | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。アプリに同梱しています。地点選択に入力した内容はどこにも送信されません。 |
| 株価・市況 | [Yahoo Finance](https://finance.yahoo.com/)（yahoo-finance2 経由） | 非公式の API で、Yahoo が承認したものではありません。相場は遅れている可能性があり、投資助言ではありません（ペインにもそう表示します）。マーケットペインが開いている間だけ取得します: まとめたリクエストを 1 分に 1 回（一覧のすべての市場が閉まっているときは 5 分に 1 回）、各チャートは 5 分ごと（1D）から 1 時間ごと（6M 以上）。 |
| 地震 | [Japan Meteorological Agency](https://www.jma.go.jp/) の地震一覧 JSON: `https://www.jma.go.jp/bosai/quake/data/list.json` | 気象庁自身の[地震情報ページ](https://www.jma.go.jp/bosai/map.html#contents=earthquake_map)が読み込むデータ（約 1 か月分の情報）を JSON として読みます。地震ペインが見えているか地震アラートが有効なときだけ、`max-age=60` の指定どおり 1 分に 1 回、If-None-Match 付きで取得するので、一覧に変化がなければ 304 が返ります。気象庁の[利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)に従って利用しており、ペインには「出典：気象庁ホームページ（URL）を加工して作成」を表示し、アラートには気象庁の名前を示します。緊急地震速報ではありません。 |
| 津波（日本） | 気象庁の津波一覧 JSON: `https://www.jma.go.jp/bosai/tsunami/data/list.json` と、そこに挙げられた各情報 | 地震一覧と一緒に確認します（通常は空の一覧で、初回以降は 304 が返ります）。新しい情報の詳細は一度だけ取得します。対象は津波警報・大津波警報・津波注意報で、津波予報と解除は含みません。クレジットは地震と同様に表示します。 |
| 地震（世界） | [USGS](https://earthquake.usgs.gov/) のリアルタイムフィード `summary/4.5_day.geojson` | パブリックドメインです。地震ペインまたはアラートが世界のソースを使っているときだけ、1 分に 1 回（`max-age=60` に従い）、条件付きで取得します。 |
| 津波（世界） | [NOAA Tsunami Warning Centers](https://www.tsunami.gov/): 太平洋（`PHEBAtom.xml`）と国内（`PAAQAtom.xml`）の Atom フィード | パブリックドメインです。それぞれのフィードにはセンターの最新の報が入っています。warning、watch、advisory、threat message が対象で、information statement は含みません。USGS のフィードと一緒に、条件付きで確認します。アラートでは現地当局の指示に従うよう伝えます。 |
| RSS フィード | RSS ペインに登録したフィードの URL | ページではなくアプリが取得し、ペインがそのフィードを表示している間だけ動きます: 15 分ごと（フィードの指定があればそれに従い、最長 1 時間）、条件付き（If-None-Match / If-Modified-Since）、同時に 2 件まで、1 件あたり最大 2 MB、Cookie なし、User-Agent は `elecdex/<version>`。見出しはプレーンテキストとして表示し、フィードごとの最新の見出しをアプリのデータフォルダーの `feeds-cache.json` に保存します。他のサイトには何も送信しません。 |
| AI チャット | *Settings -> AI* に登録したプロバイダー: 自分のコンピューターやネットワーク上のサーバー、またはホスティングされた API（Anthropic は[公式 SDK](https://github.com/anthropics/anthropic-sdk-typescript) を使い、それ以外は OpenAI 互換の `chat/completions` として扱います） | ページではなくアプリが問い合わせ、それもメッセージを送信したとき、**test** を押したとき、ペインのモデル一覧を開いたときだけです。レイアウトに置かれているだけのチャットペインは、どこにも問い合わせません。送信するのはそれまでの会話（添付したファイルを含む）、システムプロンプト、モデル名で、送り先は選んだアドレスだけです。各プロバイダーの利用規約とデータ保持方針が適用されます。Cookie は使わず、リダイレクトにも従いません。API キーはオペレーティングシステム（DPAPI、キーチェーン、デスクトップのキーリング）によって暗号化され、`settings.json` とは別の `ai-keys.json` に保存され、二度と表示されません。キーは入力したときのアドレスにだけ送ります。プロバイダーのアドレスを変えたら、キーを入れ直すまでどこにも送りません。システムが暗号化できない環境では、elecdex が終了するまでメモリ上にのみ保持します。自分のコンピューターとローカルネットワーク以外にある平文の http アドレスには、キーを送りません。独自のキーがない場合、Anthropic SDK はいつもの場所（`ANTHROPIC_API_KEY`、`ant auth login` のプロファイル）を参照します。Anthropic 自身のエンドポイントでは、`claude-opus-5` と `claude-fable-5-1` にサーバー側のフォールバック（`fallbacks: "default"`）を付けて問い合わせるので、安全性の分類器が断ったリクエストは同じ呼び出しの中で別の Claude モデルで実行し直されます。回答には、それを書いたモデルの名前が示されます。会話はアプリのデータフォルダーの `chats/` にファイルとして保存されます。 |
| ELEC システム | 同じプロバイダー（各席が指定するもの） | AI チャットと同様で、議案を提出したとき（またはモデル一覧を開いたとき）だけ問い合わせます。各ユニットにはその立場、投票の指示、議案を送り、第 2 ラウンドでは他のユニットの最初の発言も送ります。1 ラウンドに 3 件のリクエストで、1 ラウンドまたは 2 ラウンドです。審議はアプリのデータフォルダーの `elec/` にファイルとして保存されます。 |
| Web ペイン | ブラウザー、YouTube、X のペインで開いたサイト | アプリのサンドボックス化されたブラウザービューが、ブラウザーと同じように読み込みます。そうしたペインがある間だけで、elecdex 自身がそれらのサイトに何かを送ることはありません。Cookie とサイトデータは *sign out of all sites* を実行するまで、アプリのデータフォルダー（`Partitions/web`）に保存されます。YouTube と X は、それぞれの利用規約のもとで利用します。 |
| 軌道要素 | [CelesTrak](https://celestrak.org/) の GP データ（第 18・第 19 宇宙防衛飛行隊のデータを [Space-Track.org](https://www.space-track.org/) 経由で提供）: `GROUP=stations` を OMM JSON で、`GROUP=starlink` を TLE で | 位置はお使いのコンピューター上で計算し、ダウンロードするのは軌道要素だけです。CelesTrak の[利用ポリシー](https://celestrak.org/usage-policy.php)に従い、ORBIT ペインがそのセットを表示している間だけ、ステーションは最大 1 日 2 回、Starlink は最大 1 日 1 回取得し（CelesTrak の更新は 2 時間ごと）、再起動をまたいでディスクに保持し、識別できる User-Agent を使い、200 以外の応答があった後は 1 日何も取得しません。ペインにクレジットを表示します。 |
| Wi-Fi ペイン | 自分のゲートウェイと `1.1.1.1`（ネットワーク状態ペインがもともと ping している相手） | それぞれに毎秒 1 回の ping を、Wi-Fi ペインが画面に出ている間だけ行います。インターネットへの ping はネットワーク状態ペインも同じものを読むので、同じ相手に二重に送ることはありません。信号、チャネル、接続ログなどそれ以外はすべて OS から読み、外部のサービスには問い合わせません。Windows ではネットワーク名を接続プロファイルから取り、位置情報の許可が必要なもの（BSSID、スキャン）は読みません。macOS では位置情報サービスなしではネットワーク名が隠されたままで、elecdex はその許可を求めません。 |
| Ethernet ペイン | 自分のゲートウェイ（有線アダプタ自身のアドレスから）と `1.1.1.1` | Wi-Fi ペインと同じく、それぞれに毎秒 1 回、ペインが画面に出ている間だけ。インターネットへの ping は Wi-Fi ペインやネットワーク状態ペインと同じものです。リンク、カウンタ、ドライバの設定は OS から読み、変えません。アダプタの ID やネットワーク名は読みません。 |
| 更新確認 | [GitHub Releases API](https://docs.github.com/rest/releases/releases#get-the-latest-release) | 有効な間（既定で有効）、起動の 15 秒後とその後 1 日ごとに、公開されている最新リリースを 1 回問い合わせます。何もダウンロードもインストールもしません。新しいリリースがあれば、そのページを開く通知を表示します。 |
