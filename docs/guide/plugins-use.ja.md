# プラグイン — elecdex

elecdex は Windows・macOS・Linux 向けの SF 風ターミナルエミュレーター兼システムモニターで、eDEX-UI を作り直したものです。プラグインは elecdex に自分のペインを 1 つ追加します。このページは利用者の側から見たプラグインの説明です: インストールのしかた、有効にするときに何を許可し何を尋ねられるか、プラグインが届くもの・届かないもの、ファイルの置き場所、そして 2 つの見本、ポモドーロタイマーとリズムゲーム KEYSTREAM。プラグインを書くための API は [docs/plugins.md](../plugins.md) にあります。macOS と Linux は自動テストでビルドと実行をしているだけで、手作業での確認は十分ではありません。

## プラグインとは

| | |
| --- | --- |
| 場所 | *Settings → Plugins*。有効にしたプラグインは、ペインの追加ピッカー（Ctrl+Shift+A）に *plugin* バッジ付きで出ます |
| 読むもの | 許可したものだけ: メトリクスのソース、指定されたホスト、サインインセッション、キー、音 |
| 更新 | Worker は、そのペインが 1 つでも開いている間だけ動きます。*ペインを閉じても動き続ける* を許可した場合は常に動きます |
| プライバシー | ページ、ファイル、ネットワークに自分からは届きません。リクエストはすべてアプリが行い、許可と照合します |
| 設定 | `settings.json` の `plugins`（プラグインの id ごと） |

- プラグインはペインを 1 つ追加するもので、アプリのデータフォルダーにある `plugins` フォルダーに置いた TypeScript または JavaScript のファイル、あるいは `index.ts` を持つフォルダーです。
- 保存するたびに読み込み直されます。フォルダーは見張られていて、中身が変わったプラグインだけが再起動します。
- 隣にある `elecdex-plugin.d.ts` がエディターに API の型を教えます。elecdex は起動のたびに自分の API に合わせてこれを書き直すので、編集しないでください。
- プラグインはポップアップできず、組み込みのペインを置き換えることもできません。

## プラグインのインストール

### フォルダーから

1. *Settings → Plugins* を開き、**install from a folder…** を押します。
2. プラグインのフォルダーを選びます。

elecdex はそこからプラグインだけを取り出します。取り出すのはエントリーと、そこから import されるものだけです。コードの隣にある README、`package.json`、`.git`、`node_modules` やテストはそのまま残ります。ただし `tests/` の下にあっても、プラグインが import しているファイルは一緒にコピーされます。基準はプラグインから辿れるかどうかで、フォルダーの名前ではありません。

- コピー先の名前はフォルダー自身の名前です。同じ名前のプラグインがすでにある場合は先に確認します。権限と保存データは id に結びついたまま残ります。
- 実行せずに分かることはコピーの前に確かめます。コードがコンパイルできること、そしてすべての import が一緒にコピーされるファイルを指していることです。そのため、プラグインではないフォルダーや npm を必要とするフォルダー（`from 'lodash'` のようなパッケージの import）は、後になって動かないのではなく、理由を示してその場で断られます。
- プラグインを *入れてある* フォルダー（別の elecdex の plugins フォルダーなど）と、それ自体がプラグインであるフォルダーも区別されます。
- 入れたプラグインは、手で置いたものと同じく無効の状態で始まります。

### 手で置く

*Settings → Plugins* の *open plugins folder* でフォルダーを開き、そこにプラグインを置きます。

| 形 | 規則 |
| --- | --- |
| ファイル 1 つ | `plugins/` の直下の `.ts` または `.js`（`.d.ts` は除く） |
| フォルダー | `plugins/` の直下で `index.ts` か `index.js` を持つフォルダー。4 階層・64 ファイルまで |
| 大きさ | 1 プラグイン合計 1 MiB まで |
| リンク | 通常のファイルとフォルダーだけを読み、シンボリックリンクは辿りません |

読み込めないプラグインはほかと切り離され、ほかを止めません。設定のその行に理由が出ます。

## プラグインを有効にする

プラグインは *Settings → Plugins* で有効にするまで動きません。入れたものも手で置いたものも、新しいプラグインは無効です。

1. プラグインのスイッチを入れます。
2. 権限を求めるプラグインなら、行に *[プラグイン] will be able to:* として権限が平易な言葉で並び、確認を待ちます。
3. **agree and turn on** か **cancel** を押します。

権限を何も求めないプラグインは、確認なしで有効になります。

| 権限 | 設定に出る、許されること |
| --- | --- |
| メトリクスのソース | 動いているプログラムの名前、このコンピューターの通信先のアドレス、ネットワークアドレス、機種、OS とマシン名、そのほかの読み取りを読む |
| ホスト | 指定されたホストに、Cookie なしでインターネット経由でアクセスする |
| セッション | ホストにあなたとしてサインインした状態でアクセスする。そのサイトがあなたに見せるものが見えます（専用の窓で一度サインインし、設定でサインアウトします） |
| バックグラウンド | ペインを 1 つも開いていないときも動き続ける |
| 通知 | 音を鳴らし、システム通知を出す |
| キー（API 第 2 版） | ペインにフォーカスがある間に押したキーを受け取る（Ctrl や Alt との組み合わせは渡しません） |
| 音（API 第 2 版） | 音楽と音を鳴らす |

- 個人に関わる読み取り（プログラム名、通信先、ネットワークアドレス、機種、OS とマシン名）とホストへのアクセスを両方求めるプラグインには、同意の画面で *It could send … to …*（それらを通信先へ送れる）とはっきり書かれます。
- 同意はプラグインの id と、そのファイル名またはフォルダー名の組に結びつきます。別のファイルが、ほかのものに同意した id を名乗った場合は、改めて尋ねます（*x.ts now uses the id you agreed to for y.ts*）。
- プラグインを編集しても、求める権限が増えなければ同意は保たれます。増えた場合は止まって確認を待ちます（*It now asks for more than you agreed to*）。
- connections ペインのソケット一覧（`net.sockets`。どのプログラムがどこと通信しているか）は、どのプラグインにも許可できません。

## プラグインが届くもの

| | |
| --- | --- |
| 動く場所 | ページのサンドボックスの中の、専用の Web Worker。main プロセスはテキストを変換するだけで、実行はしません |
| 描画 | アプリがテーマに合わせて表示するブロック（テキスト、数値、メーター、チャート、表、リスト、ボタン）。API 第 2 版からは、Worker の中で自分のキャンバスにも描けます |
| ネットワーク | アプリを通して、許可したホストにだけ: https のみ、ホスト名は完全一致（ワイルドカード、IP アドレス、`localhost` は不可）、リダイレクトも許可したホストにだけ |
| 保存 | main が持つ自分専用のキーと値（`plugin-data/<id>.json`、1 MiB まで） |
| キー | API 第 2 版のみ。ペインにフォーカスがある間だけで、Ctrl や Alt との組み合わせ、Tab、ファンクションキーは渡しません。受け取っている間は KEYS のランプが点きます |
| 音 | API 第 2 版のみ。elecdex のシンセサイザーで、決まった音色の一覧から |

- プラグインは、ページ、ファイル、ネットワークにはアクセスできません。プラグインを閉じ込めているのは、ページのコンテンツセキュリティポリシー（`connect-src 'self'`）です。
- 応答しなくなったプラグインは、アプリを止めることなく停止されます。そのペインには *plugin not responding* と再起動のボタンが出ます。
- プラグインの設定で secret と指定された値は、画面で伏せられるだけです。`settings.json` に平文で保存され、そのままプラグインに渡されます（AI のキーとは違います）。

## プラグインの管理

*Settings → Plugins* には、プラグインごとに 1 行あります。

| 部分 | 表示と操作 |
| --- | --- |
| 状態 | *loading*、*error*、*needs a newer elecdex*、*duplicate id*、*off*、*needs your agreement*、*on* |
| 権限 | 許されること（上の言葉で） |
| 設定 | プラグイン自身の設定（テキスト、数値、スイッチ、選択）。説明があれば各欄の下に出ます |
| *sign in to [ホスト]* / *sign out* | セッションを許可したプラグインで: サインインの窓を開く、またはセッションを消す |
| *forget* | プラグインを無効にし、保存したデータとサインインを消す（2 回目のクリックで確定） |

- 無効にした、削除した、またはエラーのプラグインのペインはレイアウトに残り、理由と設定を開くボタンを出します。プラグインを有効に戻せばペインも戻ります。
- フォルダーから消えたプラグインの同意は、*forget* するまで残ります。エディターの保存で一時的にファイルが消えたり名前が変わったりしても、無効にならないようにするためです。

## ファイルの置き場所

どれもアプリのデータフォルダー（[ファイルの場所](themes-settings.ja.md#ファイルの場所)）にあります。

| パス | 内容 |
| --- | --- |
| `plugins/` | プラグイン（ファイルかフォルダーが 1 つずつ）。初回起動時にポモドーロの見本を入れて作られます。フォルダーが一度できたら、空でも二度と書き込みません |
| `plugins/<フォルダー名>/` | フォルダーからインストールしたプラグイン（そのフォルダーの名前で） |
| `plugins/elecdex-plugin.d.ts` | エディター向けの API の型。起動のたびに書き直されます |
| `plugin-data/<id>.json` | プラグインが保存したもの |
| `settings.json` → `plugins` | プラグインの id ごとに: 有効かどうか、同意したこと、設定値 |
| `persist:plugin-<id>` | サインインしたプラグイン専用の Cookie。Web ペインのものとは別で、*sign out* と *forget* で消えます |

## pomodoro

| | |
| --- | --- |
| 場所 | 新しく作られる plugins フォルダーに入っています。ソースはこのリポジトリの `examples/plugins/pomodoro` |
| 権限 | 通知（チャイムとシステム通知） |
| 設定 | Focus (minutes) 25、Short break (minutes) 5、Long break (minutes) 15、Rounds before a long break 4、Start the next phase by itself オフ |

ポモドーロタイマーです。集中セッション、短い休憩、数ラウンドごとの長い休憩を VFD 風のメーターで表示し、フェーズが終わるとチャイムと通知で知らせます。再起動しても続きから動きます。ネットワークには一切つなぎません。パネルとして手前に出せます。

## KEYSTREAM

| | |
| --- | --- |
| 場所 | このリポジトリの `examples/plugins/keystream`。フォルダーから入れます（キーと音の同意が要るため、plugins フォルダーには書かれません） |
| 権限 | キーと音（API 第 2 版） |
| 設定 | Volume (%) 80、Timing offset (ms) 0（−150〜+150、5 刻み）、Guide melody（自分のパートを小さく鳴らす）オフ |

プラグイン API 第 2 版の見本になるリズムゲームです。

- 文字が、その文字を打つキーの上に立つレーンを落ちてきます。判定線で打つと主旋律が鳴り、伴奏はゲームが鳴らします。
- ホーム段が白鍵、その上の段が黒鍵で、キーボードの段のずれがそのままピアノの鍵盤の並びになるので、どのキーもいつも同じ音を鳴らします。
- 曲は 21 で、4 つのジャンルのタブ（CLASSICS、POP、DANCE、ELECTRO）に分かれ、難しさの星が付き、カーソルを合わせた曲はプレビューで聴けます。どれも曲に合わせて書いた伴奏付きで、選ぶ手がかりにスタイルの語が付きます。
  - elecdex のオリジナル 13 曲: J-POP 風・K-POP 風・EDM 風・シティポップ風・チップチューン、それに拍がどれも 1 つのキーに落ちて EASY なら 1 つのキーをリズムに合わせて叩くだけで乗れる、180 BPM のアイドルポップと 200 BPM の J-CORE を含みます。
  - パブリックドメインの 8 曲を elecdex が編曲したもの: 「きらきら星」、「かえるの合唱」、「歓喜の歌」、「白鳥の湖」、「天国と地獄」、モーツァルトの交響曲第 40 番と「トルコ行進曲」、「山の魔王の宮殿にて」。
- Enter で選んだ曲の 3 つの難易度のパネルが一覧の上に開きます。EASY は拍の上の音だけを打って残りはゲームが弾き、HARD は判定幅が狭く SIGNAL が尽きると終わります。Space でプレビューを切ったり入れたりできます。
- 判定線には eDEX-UI のオンスクリーンキーボードが戻ってきます。
- 演奏の終わりはゲームのリザルト画面のように、スコアが数え上がり、ランクが菱形に叩き込まれ、どう終えたかをランプ（CLEAR、FULL CHAIN、ALL SYNC、NO CARRIER）が示します。前の最高との差や、打鍵が早かったか遅かったかも並びます。
- タイミングは端から端まで 1 本の時計です。キーはシステムが受けた瞬間で判定し、伴奏は聞こえる瞬間に合わせて鳴らし、レーンは 1 フレーム先（そのフレームが画面に出る時点）の位置で描くので、ノーツは音と同時に判定線に着きます。残るのは奏者とキーボードの分で、それは結果画面が教えます: 打鍵が全体として遅れていた・早かったときは、設定すべき *Timing offset* の値（SET OFFSET +20）を出すので、プラグインの設定にそのまま入れられます。
- **FREE PLAY** では、キーボードがそのまま楽器になります。キーは押している間だけ鳴り、Space がサステインペダル、DAW のミュージカルタイピングと同じく Z X でオクターブ、C V で強さを変えられます。楽器は数字の段で、どの画面でも（曲の途中でも）一押しで切り替わります。好きな曲の伴奏をループで流してその上で弾くこともでき、押さえている和音はその場でコード名が表示されます。

| 画面 | キー |
| --- | --- |
| 曲の一覧 | ↑ ↓ で曲、← → か < > でジャンルのタブ、Enter で難易度のパネル、Space でプレビューの入・切 |
| 難易度のパネル | ↑ ↓ か ← → で難易度、Enter で開始、Escape か Backspace で戻る |
| 演奏中 | Escape か Space で一時停止（R でやり直し、Q でメニュー）、↑ ↓ で落下速度。ペインのフォーカスが外れたり見えなくなったりすると一時停止します |
| どの画面でも | 数字の段で楽器: 1 E.PIANO、2 PIANO、3 GUITAR、4 SYNTH LEAD、5 CHIP、6 ORGAN、7 MARIMBA、8 E.BASS、9 PAD、0 PLUCK、- SYNTH BASS |

判定幅は SYNC ±40 ms、LOCK ±80 ms、ACK ±120 ms で、HARD ではそれぞれ 3/4 になります。

楽器はどれも演奏しながら音声スレッドで計算しています。録音は使っていません。

- ピアノの音は物理モデルです。硬く、倍音が少しずつ伸びた弦が 2 本・3 本ずつうなりながら二段に減衰し、フェルトのハンマーは強く打つほど明るく鳴り、低音の強打には金属的な響きが混じります。響板と部屋を通り、ペダルを踏めば打っていない弦まで共鳴します。
- リードギターは、ギタリストが弾く弦とフレットで弾かれ、ピックアップ、4 倍のオーバーサンプリングで計算する歪んだアンプ、スピーカーキャビネットを通ります。押さえたまま次の音へ移ればハンマリングやスライドに、押さえ続ければベンドのビブラートがかかりフィードバックで伸びます。
- ほかの音色: 強く弾くとピックアップで吠えるエレクトリックピアノ、往年のドラムマシンの回路の作り方で鳴らすドラム、ゲーム機の音源チップ、トランジスタのラダーフィルタのアナログシンセ、回転スピーカーを通すトーンホイールのオルガン（サステインペダルが回転の速さの切り替え）、マリンバ、指弾きのエレキベース。

## プラグインを書く

API とそのルール（descriptor、ブロック、`ctx`、権限、通信、保存、キャンバス、キー、音）は、開発者向けの [docs/plugins.md](../plugins.md) にあります。上の 2 つの見本がその実例です。個人用のプラグインや非公式の API を使うプラグインは、このリポジトリではなく自分の plugins フォルダーに置きます。
