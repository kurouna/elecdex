# デスク系のペイン — elecdex

elecdex は Windows・macOS・Linux 向けの SF 風ターミナルエミュレータ兼システムモニタです。このページはデスク系のペインを説明します。**Calculator**（式の書き方を含む）、**Notes**、リマインダー付きの **Tasks**、カウントダウンとアラームのある **Timer**、**Clipboard** の履歴とスニペット、祝日を示す **Calendar**、そして **Utility** ペイン（AWAKE、QR、CODEC）です。各ペインが何をどこに保存するか（メモ・タスク・アラーム・スニペットはペインの状態ではなく、メインプロセスが持つファイルです）、クリップボードペインが何を読み、何を決して読まないか、リマインダーとアラームをどう予約するかを扱います。このページのペインはどれもネットワークを使いません。elecdex は Windows で開発・使用しています。macOS と Linux は自動テストでビルド・実行しただけで、人の手による確認は十分ではありません。

## desk プリセット

<p align="center">
  <img src="../screenshots/elecdex-desk.jpg" alt="Paper テーマの desk プリセット：リリースのチェックリストを書いたメモペインとその下のタイマーと電卓、期限をメーターで描くタスクペインとその下の架空のコピーを並べたクリップボード履歴、3 か月のカレンダーとその下に Utility ペインのタブの前に出した関数電卓 ELEC-16 SCI。sin(45)+1/2 を正確な形 (1+√2)/2 で答えている">
  <br><sub>desk · Paper</sub>
</p>

**desk** プリセット（Ctrl+Shift+F6）には、システム列の横に、メモとその下のタイマーと電卓、タスクとその下のクリップボード履歴、カレンダーとその下の Utility ペイン（その後ろのタブに関数電卓 [ELEC-16](panes-retro.ja.md#elec-16) SCI）が並びます。

- **デスク系ペイン** — 入力して使う電卓（全角数字や 3百万 も入力どおりに読み、テープ表示と、貼り付けた数値の列を集計する機能付き）、自動で保存されるプレーンなメモ、期限をメーターで描き、ペインを開いているかどうかに関係なく知らせるタスク、そしてタイマー。タイマーには、ラップがスペクトラムのように積み上がるストップウォッチ、その横で動くカウントダウン、一日の決まった時刻のためのアラームがあります。タスクの下には、画面に出ている間にコピーしたものを並べ、クリックでクリップボードへ戻せるクリップボード履歴、カレンダーの下には Utility ペイン（スリープの抑止、QR コード、エンコードとハッシュ）。
- **Utility** — 小さな道具を 1 枚にまとめたペイン。指定したあいだスリープを止める、QR コードを作る（テキスト・アドレス・Wi-Fi）、エンコード・デコード・ハッシュ・時刻の変換。

**dev** プリセット（Ctrl+Shift+F4）にもクリップボードペインがあり、その後ろのタブにタイマーとシェルがあります。既定のレイアウトでは、右の列にカレンダーがあります。

## Calculator

<p align="center">
  <img src="../screenshots/pane-calc.jpg" alt="Calculator ペインを単独で表示したところ：入力行とその下の答え、これまでの答えのテープ">
  <br><sub>Calculator</sub>
</p>

| | |
| --- | --- |
| 場所 | **desk** プリセット（Ctrl+Shift+F6）、またはピッカー（Ctrl+Shift+A、"calculator"）。複数置けます。既定のレイアウトにはありません。固定の大きさで前面に出せます（Ctrl+Shift+Z）。 |
| 読むもの・データ源 | 入力した式。コードとして評価されるものは一切ありません。式のパーサーは elecxzy のもので、改変せずにテストとともに同梱しています。 |
| プライバシー | ネットワークもファイルも使いません。 |

入力する行のすぐ下に答えが表示され、これまでの答えはすべてテープに残り、そこから数値を取り出して使えます。全角数字、`×` `÷`、数字の後の桁（`3百万`、`5千`）、3 桁区切りのカンマ（`1,234,567`。関数の括弧の中のカンマは引数の区切りのまま）も入力どおりに読むので、日本語キーボードのまま、文書から写した数も打ち直さずに式を書けます。

- `ans` で直前の答えを使えます。`rate = 8 * percent` のように書くと、名前がレジスタ行に残り後の行で使えます。
- `0x` を付けると答えの下に 32 列のビットマップが表示されます（32 ビットに収まる整数のとき。負の数は 2 の補数で示します）。
- `C` で行を消し、行が空ならテープを消します。空の行で `?` を押すと電卓が知っているものがすべて表示され、↑ で入力履歴をさかのぼれます。
- **tally** モードでは、貼り付けた数値の列を集計し（件数、合計、平均、中央値、標準偏差、四分位数）、ヒストグラムと箱ひげ図を描きます。日付の各部分を別々の数値と取り違えることはありません。読むのは 20,000 個までです。
- 答えは有効数字 12 桁に丸め、3 桁区切りで表示し、役に立つときは 16 進と 2 進も添えます。
- 同じ評価器が [Notes](#notes) の `Ctrl+=` と、[Timer](#timer) に手で入力した時間を計算します。

### 式の書き方

| 要素 | 書き方 |
| --- | --- |
| 数値 | `42`、`3.14`、`.5`、`1e-3`、`0x1F`、`0b1010`、`0o17`、`1,234,567` |
| 日本語の桁 | 数字の後ろだけ：`十` `百` `千` `万` `億` `兆` と、`百万`・`千万`・`百億` のような組み合わせ（`3百万` は 3,000,000）。漢数字だけの表記（`三百万`）は読みません。 |
| 全角の入力 | `１２３`、`＋`、`×`、`÷` を `123`、`+`、`*`、`/` として読みます |
| 四則演算 | `+ - * / %`。0 で割るとエラーになり、無限大にはなりません |
| べき乗 | `^`、右から結合（`2^3^2` は `2^9`）。`-2^2` は `-4` |
| 階乗 | `5!`、`170!` まで |
| ビット演算（32 ビット） | `&` `\|` `~` `<<` `>>`。排他的論理和は `xor(a, b)` |
| 括弧 | `( )`、入れ子は 64 段まで |
| 名前 | `ans`、`name = 式` で付けた自分の名前 |

演算子の優先順位（弱い順）：`|`、`&`、`<< >>`、`+ -`、`* / %`、単項の `+ - ~`、`!`、`^`。暗黙の掛け算はありません。`2tb` はエラーで、`2 * tb` と書きます。1 行は 500 文字までです。

| 関数 | 備考 |
| --- | --- |
| `sqrt cbrt abs exp sign pow` | |
| `ln log log2 log10` | `log(x)` は底 10、`log(x, base)` |
| `sin cos tan asin acos atan atan2 sinh cosh tanh` | ラジアン：`sin(rad(30))` |
| `rad deg` | 度からラジアン、その逆 |
| `round floor ceil trunc` | `round(x, digits)` |
| `min max sum avg hypot` | 引数はいくつでも |
| `gcd lcm fact` | |
| `and or xor not shl shr` | 32 ビット |

| 定数 | 値 |
| --- | --- |
| `pi e tau phi` | 数学定数 |
| `percent permille bp` | 0.01、0.001、0.0001（`4800 * 12 * percent`） |
| `k thousand million billion trillion` | 10³〜10¹² |
| `man oku cho` | 万・億・兆（10⁴、10⁸、10¹²） |
| `kb mb gb tb` | 10 進のバイト（10³ …） |
| `kib mib gib tib` | 2 進のバイト（1024 …） |
| `minute hour day week` | 秒で |
| `tsubo` | 平方メートルで |

自分で付ける名前：レジスタ行に 20 個まで、英字か下線で始まり英数字と下線からなる 1〜16 文字。定数・関数の名前・`ans` には代入できません。

例：`1920 * 1080`、`2 * tb / (512 * gib)`、`3百万 / 12`、`round(2 / 3, 4)`、`(1 << 20) / kib`。

## Notes

<p align="center">
  <img src="../screenshots/pane-notes.jpg" alt="Notes ペインを単独で表示したところ：プレーンテキスト、タイトルバーのメモの名前、フッターの保存バー">
  <br><sub>Notes</sub>
</p>

| | |
| --- | --- |
| 場所 | **desk** プリセット（Ctrl+Shift+F6）、またはピッカー（Ctrl+Shift+A、"notes"）。複数置けます。既定のレイアウトにはありません。 |
| データ | アプリのデータフォルダー（userData）の `notes.json`。メインプロセスが書き、レイアウトには入りません。 |
| 更新 | 入力をやめて 0.5 秒後に保存します。 |

マークアップもレンダリングもないプレーンテキストで、入力をやめて 0.5 秒後に保存されます。保存待ちの間はフッターのバーが満ちていき、保存されると光るので、黙って自動保存されたかどうか気をもむ必要はありません。

- メモはレイアウトではなく、アプリの userData の `notes.json` に保存されるので、ペインを閉じても残り、2 つのペインで同じメモを表示できます（2 つ目のペインは入力中の内容を上書きせず、*edited elsewhere* と表示します）。
- 1 行目がメモの名前になり、タイトルバーにすべてのメモが並び、それぞれの × で削除できます（元に戻せます）。
- *Save as .md…* と *delete*（元に戻せます）は設定ボタンの中にあります。

| キー | 動作 |
| --- | --- |
| Ctrl+= | キャレットのある式を計算して答えをその後ろに書き込みます。地の文には手を付けません |
| Ctrl+F | メモの中を検索（Esc で検索を閉じる） |
| Ctrl+N | 新しいメモ |
| Ctrl+S | すぐに保存 |

## Tasks

<p align="center">
  <img src="../screenshots/pane-todo.jpg" alt="Tasks ペインを単独で表示したところ：期限をメーターで描いたタスクと、見出しでカウントダウンする最も近い期限">
  <br><sub>Tasks</sub>
</p>

| | |
| --- | --- |
| 場所 | **desk** プリセット（Ctrl+Shift+F6）、またはピッカー（Ctrl+Shift+A、"tasks"）。複数置けます。既定のレイアウトにはありません。 |
| データ | アプリのデータフォルダーの `tasks.json`。メインプロセスが書きます。 |
| 更新 | リマインダーはメインプロセスが、次の締め切り 1 つを 1 つのタイマーで待って予約します。ポーリングはしません。 |
| 設定 | ペインの設定ボタン：リマインダー（`settings.json` に保存され、すべてのタスクペインで共通）。 |

各締め切りを、タスクの期間のどれだけが過ぎたかを示すメーターで描くリストです。残りが少なくなると琥珀色、過ぎると赤になり、見出しでは最も近い締め切りがカウントダウンされます。

- `歯医者 明日 9:00`、`review fri 18:30`、`毎週 掃除` と入力すると、行から日付と繰り返しを読み取り、タスクを追加する前に読み取った内容を示すので、読み違いはその場で気づけます。理解できない行は入力どおりに残ります。
- タスクは読んでいるその場で直せます。タイトルをクリックすると名前を変更でき、時刻をクリックすると同じ書き方で締め切りを設定できます（空の行で締め切りを外します）。キーボードでは Delete でタスクを削除し、F2 で名前を変更します。
- 完了したタスクは DONE の下に並び、必要なら折りたためます。

### リマインダー

次の締め切りのリマインダーはアプリ自身が予約します。ペインが閉じていても、別のタブにあっても、一度も開いていなくても届き、隅に *done*、*snooze*、*open* の付いたカードが出て、elecdex が前面にないときはシステム通知も出ます。

| 設定 | 既定 |
| --- | --- |
| remind me | オン |
| system notification when away | オン |
| sound（インターフェースの音がオンのとき） | オン |
| snooze | 10 分（1〜1440） |
| warn … min early | 0 分（0〜1440） |

- すべての締め切りのうち次の 1 つを 1 つのタイマーが待つだけです。待つものが何もなければタイマーも動いていません。
- タイマーは機械が起きていた時間を数えるので、スリープから復帰したときに予定を組み直します。
- 約 24.8 日を超える待ち時間は区切って待ち、各締め切りは 1 回だけ知らせます。

## Timer

<p align="center">
  <img src="../screenshots/pane-timer.jpg" alt="Timer ペインを単独で表示したところ：ラップをバーで描いたストップウォッチ">
  <br><sub>Timer</sub>
</p>

| | |
| --- | --- |
| 場所 | **desk** プリセット（Ctrl+Shift+F6）、**dev** プリセット（Ctrl+Shift+F4）のクリップボードの後ろ、またはピッカー（Ctrl+Shift+A、"timer"）。複数置けます。既定のレイアウトにはありません。固定の大きさで前面に出せます（Ctrl+Shift+Z）。 |
| データ | 動いているタイマーは実時間の時刻としてペインの状態に、アラームはアプリのデータフォルダーの `alarms.json` に（メインプロセスが書きます）。 |
| 更新 | 表示は共有の 10 fps ループで描きます。アラームはメインプロセスが予約します。 |

1 つのペインに 3 つの計器があります。

- **ストップウォッチ。** ラップはバーとして並び、計測中は伸びていき、記録すると光って固定されます。最速と最遅には印が付き、最も高いバーには保持されたピークの線が引かれます。
- **カウントダウン。** 最大 6 本で、それぞれに時間を設定でき、区切られたはしごを 1 段ずつ消しながら減っていき、最後の 10 秒は脈打ち、終わるとカードで知らせます。`+1 +3 +5 +10 +25` をタップして設定済みの時間に足していき、その横の欄では分数をちょうどの値で設定できます。手で入力した時間は電卓を通るので、`90/2` は 45 分になります。
- ストップウォッチとカウントダウンは、スマートフォンと同じく別々の装置です。片方を開始してももう片方は始まらず、片方をリセットしてももう片方はそのままで、画面のモードがストップウォッチでもカウントダウンは動き続け（時間が来れば鳴り）、それぞれのモードは見出しでそのことを示します。
- Space で、画面に出ているものを開始・停止します（ペインのどこにフォーカスがあっても。入力欄とボタンの上を除く）。
- すべてをティックの数ではなく実時間の時刻として保持するので、ペインを動かしても、タブを切り替えても、再読み込みや再起動をしても、動いているタイマーはまったく同じところにあります。表示は 10 分の 1 秒までで、これは共有の 10 fps 描画ループで正直に示せる精度です。ラップはミリ秒単位で記録します。
- **アラーム。** 時刻とラベルを、選んだ曜日に鳴らします。毎回作り直すのではなく、一覧からオン・オフを切り替えて使います（起床、昼休みの始まりなど）。アラームは `alarms.json` に保存され、アプリが予約するので、ペインが閉じていても一度も開いていなくても鳴り、応答するまで待つカードと、（elecdex が前面にないときは）システム通知が出ます。1 回限りのアラームは鳴った後に自動でオフになります。`07:30`、`1730`、`7`、`19.5`、`１９：３０` はどれも時刻として読みます。

## Clipboard

<p align="center">
  <img src="../screenshots/pane-clipboard.jpg" alt="Clipboard ペインを単独で表示したところ：架空のコピーを新しい順に並べ、それぞれに TXT・URL・PATH・NUM・CLR のタグ">
  <br><sub>Clipboard</sub>
</p>

| | |
| --- | --- |
| 場所 | **desk** と **dev** のプリセット、またはピッカー（Ctrl+Shift+A、"clipboard history"）。置けるのは 1 つです。既定のレイアウトにはありません。 |
| 読むもの・データ源 | システムのクリップボード。読むのはメインプロセスで、ページは読みません。 |
| 更新 | 1 秒に 4 回（0.25 秒の境界ごと）、クリップボードペインが画面に出ていて一時停止していない間だけ。100 万文字を超えるテキストが載っている間は 2 秒に 1 回です。 |
| プラットフォーム | 非公開の印は Windows・macOS・KDE のものを見分けます（下記）。macOS と Linux は人の手による確認が十分ではありません。 |
| プライバシー | クリップボードペインが画面にない間にコピーしたものは残しません。非公開の印が付いたコピーは中身を読みません。履歴はメモリにだけあり、elecdex を終了すると消え、プラグインからは見えません。ディスクに書くのは、残すと決めたスニペットだけです。 |
| 設定 | 設定ダイアログにはありません。ペインに **PAUSE**、**MASK**、**CLEAR** と、**history** / **snippets** の切り替え。 |

ペインが画面に出ている間にコピーしたものを、大きさと何分前かを添えて新しい順に並べます。各エントリーには種類のタグ（TXT・URL・PATH・NUM、色見本付きの CLR）が付き、書式付きでコピーしたもの（HTML、または Word やワードパッドがコピーする RTF）にはその下に RICH が付きます。

- ポインタを置く（またはキーボードで移る）と、GIT ペインのコミットと同じようにカードが開き、中身（先頭 600 文字まで）・一緒にコピーされた形式・コピーした時刻を示します。
- クリック（または Enter）でコピーしたときの書式ごとクリップボードへ戻り、好きな場所に貼り付けられます。↑ ↓ でエントリー間を移動し、Delete か × で 1 件消します。戻しても一覧の並びは動きません。
- 同じテキストをもう一度コピーすると二重には並ばず上へ移り、シェルでドラッグした選択（1 歩ごとにコピーされる）は 1 件になります。
- **見えている間だけ。** 別のタブの裏、ウィンドウの最小化や格納中、**PAUSE** 中は何も読まず、その間にコピーしたものは残りません。ペインが現れた瞬間にクリップボードにあるものは一覧に入ります。
- **非公開のコピー。** パスワードマネージャーが付ける「非公開」の印が付いたコピーは、形式の一覧だけで見分けます。中身は読まず、件数だけを数えます（「N private copies left out」）。

| システム | 印 |
| --- | --- |
| Windows | `ExcludeClipboardContentFromMonitorProcessing`、`Clipboard Viewer Ignore`、0 に設定された `CanIncludeInClipboardHistory` |
| macOS | `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType` |
| KDE | `x-kde-passwordManagerHint` |

- 最大 50 件をメモリに持ち、elecdex を終了すると消えます。ディスクには書かず、プラグインからも見えません。テキストは 200,000 文字までを丸ごと持ち、それより長いものは先頭だけを示して NOT KEPT とし、戻せません。ページに渡るのは各エントリーのプレビューだけで、全文はメインプロセスに残ります。
- **MASK** で内容を伏せ（絞り込み欄とカードも出しません）、**CLEAR**（2 回押す）で一覧とクリップボードを空にします。
- テキストのみで、画像やファイルは残しません。コピーはクリップボードのテキストが変わったことで知るので、間に何もはさまずに同じテキストを 2 回コピーしても 1 回です。
- 貼り付けの代行はせず、OS のクリップボード履歴とも同期しません。

### スニペット

ペインの **snippets** の切り替えの裏には、残しておくと決めたテキストがあります。

- エントリーの **SNIP** で書式ごと残します（以後そのエントリーには ★ が付きます）。本文はメインプロセスが写し、ページを通りません。**+ NEW** で名前（任意）を付けて手で書くこともできます（Ctrl+Enter で保存、Esc で取り消し）。同じテキストは二重に残しません。
- **COPY** でスニペットをクリップボードに置き、履歴には加えません。
- 番号をドラッグ（または Alt+↑ ↓）で並べ替え、**EDIT** か F2 で書き換え（本文を変えるとコピー時の書式は外れます）、× を 2 回押して削除します。
- 最大 100 件を設定と同じフォルダーの `snippets.json` に保存します。履歴と違ってディスクに書きますが、書くのは残すと決めたものだけです。MASK はスニペットにも効きます。プラグインからは見えません。

## Calendar

<p align="center">
  <img src="../screenshots/pane-calendar.jpg" alt="Calendar ペインを単独で表示したところ：今日の印が付いた月">
  <br><sub>Calendar</sub>
</p>

| | |
| --- | --- |
| 場所 | 既定のレイアウトの右の列、**desk** プリセット、またはピッカー（Ctrl+Shift+A、"calendar"）。 |
| 読むもの・データ源 | なし。祝日はローカルで計算します。 |
| 設定 | ペインの設定ボタン：祝日カレンダー（既定はなし。ペインの状態に保存）。 |

今日の印が付いた月を表示します。‹ › かマウスホイールで月を変えると、日付が動いた方向に流れます。余裕があれば（幅の広いペイン、または Ctrl+Shift+Z で前面に出したペイン）、前月と翌月が両側に薄く加わり、矢印で 3 か月とも動きます。設定ボタンで祝日カレンダーを選べ（今のところ日本のみ、ローカルで計算します）、月の下に次の祝日の名前が表示されます。

- 日本の祝日は祝日法の規則から計算します。固定日、ハッピーマンデー、近似式による春分・秋分、振替休日、国民の休日、そして 2019〜2021 年の特例による移動です。対象は 2000〜2099 年で、内閣府の公表一覧と一致することを確かめています。ネットワークは使わず、毎年のデータ更新も要りません。
- 土曜はテーマの情報色、日曜と祝日は警告（danger）色で描きます。カレンダーの文字は言語設定に関わらず英語です。複数の国を選ぶと、祝日の名前に国のタグが付きます。

## Utility

<p align="center">
  <img src="../screenshots/pane-utility.jpg" alt="Utility ペインを単独で表示したところ：AWAKE モジュール">
  <br><sub>Utility</sub>
</p>

| | |
| --- | --- |
| 場所 | **desk** プリセット、またはピッカー（Ctrl+Shift+A、"utility"）。複数置けます。Ctrl+Shift+U でレイアウトの Utility ペインにフォーカスし（もう一度押すと次のペインへ）、レイアウトになければポップアップで開き、ポップアップが出ているときに押すと閉じます。固定の大きさで前面に出せます（Ctrl+Shift+Z）。 |
| 読むもの・データ源 | ペインの外のものは読みません。すべてこの PC の中で動きます。 |
| プラットフォーム | AWAKE はどのプラットフォームでも Electron の省電力ブロッカーを使います。Linux の IBus は Ctrl+Shift+U を Unicode 入力に使うので、キーが届かない場合は *Settings → Keyboard* で割り当てを変えてください。macOS と Linux は人の手による確認が十分ではありません。 |
| プライバシー | ネットワークを使いません。プラグインからは届きません。CODEC の入力はディスクに書きません。Wi-Fi のパスワードはシステムの暗号化で封をしたものだけを保存します。 |
| 設定 | ペインの中。表示中のモジュールと各モジュールの選択はペインの状態に、AWAKE のホールドは `awake.json` に保存します。 |

小さな道具を切り替えボタン（`AWAKE | QR | CODEC`）で 1 つずつ出すペインで、ポップアップにもできます。どれもこの PC の中で動き、ネットワークは使わず、プラグインからは届きません。

### AWAKE

AWAKE はスリープを止めます。

| 選択 | 効果 |
| --- | --- |
| OFF | 何も止めない |
| SYSTEM | システムはスリープしない。画面は消えてよい |
| DISPLAY | 画面も点けたまま（システムも止める） |
| 期間 | ∞、30M、1H、2H、4H。+30M で 30 分延長（今から 24 時間まで） |

- Electron の省電力ブロッカーでシステムに頼むので、プログラムは起動しません。蓋を閉じる・スリープを選ぶとスリープします。
- ホールドはペインではなくアプリのものです。止めるか時間が切れるまで、ペインを閉じても、再起動しても続きます。elecdex が動いていない間は止めていません（クラッシュを含め、プロセスが終わると OS が要求を解きます）。
- 止めている間は、ステータスバー（`awake · system · until 15:42`。下端の目印が灯り、押すと AWAKE を出した Utility がポップアップします）と通知領域のツールチップがそう言い、ブートログにも出ます。バッテリーで動いているときはペインがそう示しますが、ホールドを自動で解くことはしません。
- 期限は 1 つのタイマーで待ち、スリープから復帰したときにも確かめます。刻み続ける処理はありません。

### QR

QR はテキスト、アドレス（スキームがなければ `https://` を足します）、Wi-Fi（スマートフォンがカメラを向けるだけで接続できる形式）の QR コードを作ります。

- 誤り訂正は L〜H（既定は M）。入力は UTF-8 なので日本語も入ります。使ったバイト数と、その誤り訂正での最大のコードの容量（L 2953、M 2331、Q 1663、H 1273 バイト）を示し、超えると `OVER CAPACITY` と表示します。
- テーマの色で描きます。常に明るい地に暗いモジュールで、テーマのコントラストが足りなければ白地に黒になります。周りには 4 モジュールの余白を取ります。COPY で画像としてクリップボードに置けます。
- Wi-Fi のパスワードは、AI のキーと同じくシステムの暗号化で封をしたものだけを保存し、パスワード入りのコードは REVEAL を押すまで覆われています（ペインが見えなくなったり動いたりすると、また覆います）。別の機械で封をしたパスワードは開けず（`SEALED ON ANOTHER MACHINE`）、keyring のない Linux では保存しません（`NOT SAVED · NO KEYRING`）。

### CODEC

| 操作 | 内容 |
| --- | --- |
| ENCODE | Base64、Base64URL、URL エンコード、16 進 |
| DECODE | Base64、URL エンコード、16 進。JWT の中身の表示（署名は検証しません） |
| HASH | SHA-1、SHA-256、SHA-512 |
| TIME | Unix 時刻（秒またはミリ秒）と日時の相互変換。空なら現在 |
| WIDTH | 全角英数と半角の相互変換、NFKC |
| UUID | 押すたびに新しいバージョン 4 の UUID |

- 結果は入力に合わせてその場で変わり、失敗は結果の欄に理由を示します。COPY で結果をコピーし、⇅ で結果を入力に移して続けてデコードできます。
- 入力はディスクに書きません（ペインを動かしても残りますが、終了すると消えます）。入力は 200,000 文字までです。

## デスク系のデータの置き場所

| もの | 場所 | 書くもの |
| --- | --- | --- |
| メモ | `notes.json` | メインプロセス |
| タスク | `tasks.json` | メインプロセス |
| アラーム | `alarms.json` | メインプロセス |
| クリップボードのスニペット | `snippets.json` | メインプロセス |
| AWAKE のホールド | `awake.json` | メインプロセス |
| リマインダーの設定 | `settings.json`（`reminders`） | メインプロセス |
| クリップボードの履歴 | メモリのみ。終了で消える | — |
| CODEC の入力 | ページのメモリのみ。終了で消える | — |
| カレンダーの祝日、Utility のモジュール、QR の入力、動いているタイマー | ペインの状態 | — |

ファイルはすべてアプリのデータフォルダー（Electron の userData）にあります。ペインが持つのは表示の選択と id だけなので、メモ・タスク・アラーム・スニペットはそれを表示するペインより長く残り、リマインダーとアラームはペインがなくても鳴ります。どちらもメインプロセスの `setTimeout` 1 つで待ち、ポーリングはしません。
