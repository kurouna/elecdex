# ワークスペース — elecdex

elecdex は SF 風のデスクトップ向けターミナルエミュレーター兼システムモニターで、eDEX-UI を Electron・Svelte・
TypeScript で作り直したものです。このページでは、そのワークスペースについて説明します。ペイン・分割・タブ、ペインの
移動・クローズ・前面表示、ポップアップ、保存レイアウト、CRT の演出とモーションの設定、テーマ、設定ダイアログ、
アクションパレット、バックグラウンド実行、そして既定のキーボードショートカットのすべてです。elecdex は
Windows・macOS・Linux で動きます。開発と利用は Windows で行っており、macOS と Linux は GitHub Actions の自動テストで
動かしただけなので、十分には検証されていません。

**レイアウト** — どのペインもタイトルをドラッグして移動でき、閉じる、分割する、タブにする、サイズを変える、元に
戻すことができます。レイアウトは保存され、リセットもできます。配置に名前を付けて保存し、あとで戻ることも
（Ctrl+Shift+G、またはステータスバーの *layouts*）、10 個の[プリセット](presets.ja.md)から始めることもできます。

## ペイン・分割・タブ

| | |
| --- | --- |
| 保存先 | `layout.json`（いまの配置。手で編集できる）、`layouts.json`（保存レイアウト） |
| 設計 | [architecture.md §5.1](../architecture.md) |

- ワークスペースは木です。葉は **ペイン** で、それぞれウィジェットを 1 つ持ちます。シェルも監視ウィジェットも
  Web ページもプラグインも同じ扱いです。**分割** は子を横または縦に、割合で並べます。**タブグループ** は 1 つの
  場所を共有するペインを束ねます。
- タブグループにはシェルに限らずどのペインでも入れられるので、ときどき使うペインに専用の場所を取らせず、シェルと
  場所を共有させることができます（たとえばシェルのタブの後ろに RSS や天気）。タブをクリックすると切り替わります。
  後ろのタブのシェルは動き続け、戻るとセッションも画面もそのままです。
- グループは入れ子にできません。1 つのタブに入るペインは 1 つです。
- 分割にはヘッダーがありません。シェルには TERMINAL のヘッダーがあり、グループのドラッグの取っ手を兼ね、シェルの
  フォルダを表示します。
- 後ろのタブや最小化したウィンドウのペインは、要らないものを読むのをやめます。ほとんどのペインは見えている間だけ
  データを取り、最後に表示したものを残します。見えていなくても動き続けるのは、シェル、書き込み中の回答、タイマー
  とアラーム、地震の警報、プラグイン、Web ページです。
- **ペインを移動すると再マウントされます。** 移動を越えて残すべきものは、ペインの状態か main プロセスに置かれ
  ます。移動したシェルはセッションとスクロールバックを保ちます。
- ペインが失敗すると、そのペインだけが **RETRY** の表示で止まり、赤い通知が何が起きたかを伝えます。
  **COPY DETAILS** でコピーされるのは、メッセージとバージョンとプラットフォームだけです。

## ペインの移動とサイズ変更

- **ペインはタイトルをドラッグ**（時計のようにタイトルのないペインは上端の線をドラッグ）して、別のペインの上で
  離すと、そのペインの、ポインターにいちばん近い側に入ります。
- 離すときに **Ctrl**（macOS は **Cmd**）を押していると、代わりにそのペインのタブとして、ポインターで選んだタブ列の
  位置に入ります。すでに入っているグループの上で同じように Ctrl を押すと、タブの並べ替えになります。
- シェルのタブは単独でドラッグして取り出せます。タブグループのヘッダーはグループ全体を動かします。
- **Escape** でドラッグを取り消します。移動したシェルはセッションを保ちます。
- *unreleased*：ドラッグ中は、ペインが入る場所の四隅に括弧が出ます。落としたペインは元の場所から移った先へ
  飛んで着地し、入れ替わったペインも同じように飛びます。グループにタブとして落としたペインは、そこで瞬いて点灯します。
- **サイズの変更** は 2 つのペインのあいだの区切り線をドラッグするか、区切り線にフォーカスして **矢印キー**
  （**Shift** で大きく）で行います。区切り線を **ダブルクリック** すると、両隣の 2 つのペインで場所を等分します。
  区切り線が動かすのは両隣の 2 つだけです。

## ペインの追加とクローズ

<p align="center">
  <img src="../screenshots/elecdex-blank.jpg" alt="Amber テーマの blank プリセット：ペインが一つもないワークスペースの上に、ペイン追加のピッカーが開き、すべてのウィジェットが説明つきで並ぶ。上部に配置の選択（右、下、新しいタブ、ポップアップ）">
  <br><sub>空のレイアウトの上のペイン追加のピッカー · Amber</sub>
</p>

- **Ctrl+Shift+A**（またはステータスバーの追加ボタン）で **ペイン追加のピッカー** が開きます。すべてのウィジェットが
  説明つきで並び、上部に配置 **right**、**below**、**⧉ new tab**、**▣ pop up** があります（**Tab** で巡回）。新しい
  ペインはフォーカスのあるペインの隣に入ります。
- ペインをグループに入れるには、グループの上に Ctrl を押しながらドラッグするか、グループのペインにフォーカスして
  ピッカーを開き、ウィジェットの前に **⧉ new tab** を選びます。
- 1 つしか置けないウィジェットがすでにレイアウトにあるときは、どの配置を選んでもそのペインにフォーカスします。
  2 つ目は作りません。
- **Ctrl+Shift+E** でフォーカスのあるペインを右に、**Ctrl+Shift+O** で下に分割し（タブならグループ全体）、
  **Ctrl+Shift+T** でそのペインの隣にタブを足します。
- **Ctrl+Shift+W** でフォーカスのあるペインを閉じます。ペインの **×** ボタン（ポインターを置くと出ます）でも同じ
  です。タブグループの × はグループのタブをすべて閉じ、タブ自身の × はそのタブだけを閉じます。閉じたペインは消灯し、
  隣のペインがその場所へ広がります。
- *unreleased*：閉じたペインは元に戻せます。通知の **undo** が 6 秒間、次に配置を変えるまで使えます。戻せるのは
  最後に閉じたものだけです。戻したシェルはセッションとスクロールバックを保ち、Web ページは表示していたアドレスで
  開き直します。
- どのレイアウトでも、最後のペインを閉じると空になります。*no panes in this layout* の下の **+ add pane** で
  ピッカーが開き、最初に選んだペインが画面いっぱいに入ります。空のレイアウトでは、分割と新しいタブのキーはシェルを
  入れます。
- **Ctrl+Shift+Backspace** で既定のレイアウトに戻します。シェルが開いている間は、レイアウトの切り替えと同じく
  先に確認します。ステータスバーのリセットボタンは、代わりに 2 回目のクリックで確かめます。

## ペインを前面に出す

| | |
| --- | --- |
| ショートカット | **Ctrl+Shift+Z**（もう一度で戻す）、ペインの × の隣の ⤢ ボタン |
| 保存 | しない。アプリはすべてのペインを元の位置で始める |
| 設計 | [architecture.md §5.5](../architecture.md) |

よく見たいペインは前面に出せます。**Ctrl+Shift+Z** か、右上の × の隣の **⤢** ボタン（タブグループにも同じ角が
あります）で、ウィンドウの大部分をほかのペインの上から覆います。ほかのペインは暗幕の後ろで元の位置のままです。

- ほとんどのペインはワークスペースの約 9 割に出ます。電卓、タイマー、ミキサー、Now playing、ディスク、プロセス
  一覧、Utility は、ウィンドウ全体ではなく中央のパネル（最大 880x560）として出ます。システムストリップとネット
  ワークの状態には ⤢ がありません。
- 前面にある間は、シェルの切り欠きのある縁取りを一回り大きくした枠（四隅のブラケットと、下の辺の
  `ESC · RETURN`）で、ペインのすぐ外側を囲みます。そのため、ペインは与えられた場所をすべて使えます。
- **Escape**、もう一度のショートカット、ボタン、暗幕のクリックで元に戻ります。前面にある間、角には **⤡**（戻す）
  だけがあり、隣に × は出ません。前面のペインを閉じるのは **Ctrl+Shift+W** です。
- タブはグループごと前に出るので、ほかのタブにもそのまま切り替えられます。
- 何も並べ替えず、何も保存しません。シェルはセッションを、Web ペインはページを保ちます。後ろのペインは 1 ピクセル
  も動かないので、ほかのシェルのサイズも変わりません。木を変える操作（分割、移動、リセット、ほかのペインを閉じる）、
  ドラッグの開始、ほかのペインへのフォーカスで元に戻ります。
- モーションを減らす設定では、飛ぶ演出なしで出て、戻ります。

## ポップアップ

| | |
| --- | --- |
| 場所 | ペイン追加のピッカーの **▣ pop up**。アクションパレットの PANE の行。レイアウトにないときの **Ctrl+Shift+L**（ランチャー）と **Ctrl+Shift+U**（Utility） |
| 保存 | しない（ペインも位置も）。中で選んだものはアプリを終えるまで残る |
| 設計 | [architecture.md §5.13](../architecture.md) |

**▣ pop up** はウィジェットをワークスペースの上に出し、レイアウトはそのままにします。枠には × だけがあり、保存
されません。**Escape**、×、横のクリックで片付きます。

- ズーム、ドラッグ、分割、タブはありません。どのダイアログを開いても片付きます。
- 組み込みのペインはすべてポップアップにできますが、シェル（誰も持たないセッションは終了されます）、タイマー
  （片付けたカウントダウンは鳴らせません）、ファイルブラウザー（レイアウトのシェルに追従します）、CHIP-8、ELEC-16
  は除きます。Web ページとプラグインもできません。ピッカーではそれらに *pane only* と出ます。
- ポップアップの中で選んだものは、アプリを終えるまで、次に開いたときにも残ります。
- **Ctrl+Shift+L** は、レイアウトにランチャーがないときに同じようにランチャーを出し、何かを起動するとランチャーは
  消えます。**Ctrl+Shift+U** は Utility ペインへ行きます。レイアウトにあれば次のものへ、なければポップアップで
  出し、もう一度押すと片付きます。
- ポップアップの上に開くのは、天気ペインの地点選択だけです。

## 保存レイアウト

| | |
| --- | --- |
| ショートカット | **Ctrl+Shift+G**（LAYOUTS ダイアログ）、**Ctrl+Shift+1**〜**9**・**0**（先頭 10 件）、**Ctrl+Shift+F1**〜**F10**（プリセット） |
| 保存先 | `layouts.json`、最大 20 件 |
| 設定 | *Settings → General → Layouts* の *ask before switching layout*（既定はオン） |
| 設計 | [architecture.md §5.6](../architecture.md) |

残したい配置は名前を付けて保存し（**Ctrl+Shift+G**、またはステータスバーの *layouts*）、あとで戻れます。先頭の
10 件は Ctrl+Shift+1〜9 と 0、ステータスバー左の番号ボタンに割り当てられます。

- **レイアウトは作業に追従します。** いま使っているものに印が付き、ワークスペースへの変更はそこに残るので、戻って
  くると離れたときのままです。スナップショットではありません。
- レイアウトをリセットしても保存レイアウトはすべて残り、そのあとの配置は、保存するか適用するまでどれにも属しません。
- ダイアログではレイアウトの名前を変え、上下に動かせます。一覧での位置が *そのまま* 番号キーです。保存できるのは
  20 件までで、11 件目以降にはキーがなく、ダイアログから適用します。
- **レイアウトを適用するとワークスペースが置き換わり**、置き換えられるペインのシェルは、それらのペインを閉じたとき
  と同じく終了します。シェルが開いている間は先に確認し、その問いの中に確認をやめる方法
  （*Settings → General → Layouts*）があります。適用したレイアウトのシェルは新しく始まります。
- 前の配置はブラウン管のように消灯し、新しい配置が起動時と同じようにペインごとに点灯します（シェルが先、ほかのペインは
  順不同で続き、起動時の約 3 分の 1 の時間で終わります）。モーションを減らす設定では演出しません。
- 切り替えの前に、まだ保存していない変更を書き出すので、直前の操作は失われません。
- 保存レイアウトは、このマシン固有のものを持たない 1 つのファイルにまとまっています（シェルのセッションは除いて
  あります）。**`layouts.json` を別のコンピューターにコピーすれば、配置もいっしょに移ります。** ダイアログの
  *layouts.json* ボタンでファイルマネージャーに表示できます。ファイルの壊れたエントリーはそれだけが捨てられ、
  ほかは残ります。
- 一覧の下の棚に 10 個の **プリセット** があります。選ぶとそこから作ったレイアウトが足されます。
  [レイアウトプリセット](presets.ja.md#プリセットの仕組み)を参照してください。

## 見た目と操作感

**見た目と操作感** — その場で切り替わる 7 つのテーマ。HUD 向けの Tron、Amber、Phosphor、White、White を反転させて
淡い地に黒に近い文字で同じ走査線を引く Black と、普段の仕事向けに Windows 11 の配色、システムフォント、フルカラーの
アイコンを使う Business (Dark) と Business (Light) があり、どれも[プリセット](presets.ja.md)のページのいずれかの
画像に写っています。

- このマシンの実際の情報を並べる Linux 風のブートログのあと、**CRT の電源が入るような起動シーケンス** が続きます。
- **ペインは点灯し、消灯します。** あとから追加したペインも同じように点灯し、閉じたペインは消灯して隣のペインが
  その場所へ広がります。保存したレイアウトに切り替えると画面全体が消灯し、次のレイアウトがペインごとに点灯します。
  ダイアログ、通知、ポップアップも点灯し、消灯します。
- *unreleased*：分割や移動でペインの場所が狭まると、動いた辺に光の線が走ります。グループの前面に出たタブは、
  チャンネルを変えたように瞬いて点灯します。キーボードで移った先のペイン（**Ctrl+Shift+]** / **[** と矢印、シェルのキー、
  ペインごとのショートカット）は、枠が一度だけ光ります。クリックしたペインは光りません。
- 走査線とグロー、合成したインターフェース音、テーマに合わせたタイトルバー、画面下端からスライドして現れる
  ステータスバー。
- 月ごとの日付の波、せり上がる天気予報、3 秒間ハイライトしながらスライドインする新しい見出しや地震といった短い
  登場エフェクトは、モーションの設定に従います。
- **モーション** は *Settings → General → Appearance* にあり、**system**（OS の「視差効果を減らす」設定に従う。
  既定）、**full**、**reduced** から選びます。モーションを減らす設定（またはシステムの「視差効果を減らす」設定）
  にすると、何も動きません。CRT の演出、前面に出るペインの飛行、登場エフェクトは省かれます。
- ウィンドウが隠れているか最小化されている間、常時動くアニメーションは止まります。
- 明るいテーマ（Black と Business (Light)）では、状態の色を濃くし、シェルの最小コントラストを確保します。

| *Plugins* | プラグイン |
| *Updates* | アップデートの確認。1 日 1 回 GitHub に最新のリリースを尋ねるだけで、何もダウンロードもインストールもしない |

## アクションパレット

| | |

| ショートカット | **Ctrl+Shift+P** |
| 設計 | [docs/palette.md](../palette.md)、[architecture.md §5.24](../architecture.md) |

**アクションパレット** — Ctrl+Shift+P で、ショートカットのアクション・保存レイアウト・プリセット・テーマ・ペイン・
設定のセクションを文字で探して実行できます。各行には今のキーが出ます。今使えない行は理由を添えて薄く残り、取り消せ
ないものは Enter 2 回で実行します。

<p align="center">

| 種類 | Enter ですること |
| --- | --- |

| PRESET | Ctrl+Shift+F1〜F10 と同じく、プリセットから作ったレイアウトへ行くか、足して行く |
| THEME | テーマを当てる |
| PANE | ポップアップにできればポップアップで、できなければ右に追加する。1 つしか置けないペインがすでにあればフォーカスする |
| SETTINGS | 設定ダイアログをそのセクションで開く |

- 文字を打つと絞り込まれ、名前の一致した文字に下線が引かれます。何も打っていないときは最近の 5 行（ページを
  再読み込みするまでの記憶）が先頭に、続いて種類ごとの見出しの下に並びます。
- **↑** / **↓** で選び、**PageUp** / **PageDown** で 8 行ずつ動き、**Tab** / **Shift+Tab** で種類を回し、
  **Enter** で実行、**Escape** で閉じます。マウスでも選んでクリックできます。
- 今使えない行は理由を添えて薄く残ります（たとえば Next tab は *not in a tab group*、Clear the shell's
  scrollback は *only from a shell*）。Enter しても何もしません。
- **Enter 2 回**: Quit、Clear the shell's scrollback、そして確認ダイアログが出ないとき（シェルがない、または
  *ask before switching layout* がオフ）の Reset layout。行が赤くなって *ENTER AGAIN* と出ます。選択を動かすか
  文字を打つと解けます。
- パレットが開いている間は、Quit と全画面以外のショートカットは効きません。もう一度 Ctrl+Shift+P を押しても何も
  しません。ポップアップの上でも開き（ポップアップは片付きます）、Web ペインにフォーカスがあっても開きます。
- テーマの試し当て、個々の設定の切り替え、プラグインが行を足す仕組みはありません。プラグインのペインはピッカーと
  同じく PANE に並びます。

## プラグイン

**プラグイン** — TypeScript ファイル 1 つで自分だけのペインを作れます。サンドボックス化されたワーカーの中で、許可した
権限だけで動きます。[プラグインを使う](plugins-use.ja.md)を参照してください。

## バックグラウンド実行

| | |
| --- | --- |
| 設定 | *Settings → Window*（アイコンを出す、そこへ最小化する、ウィンドウを閉じても動き続ける、どのアプリからでも表示／非表示）、*Settings → Window → Startup*（サインイン時に起動する、バックグラウンドで始める） |
| 既定 | どれもオンにするまではオフ |
| プラットフォーム | 提供されるのはそのマシンでできることだけ（下の表）。macOS と Linux は十分には検証されていません |

**バックグラウンド実行** — 通知領域・メニューバー・トレイのアイコン、システム全体で使える表示／非表示の
ショートカット、サインイン時の起動。提供される機能はそのマシンで実際にできることに合わせるため、環境によって異なり
ます。Windows では通知領域への最小化と、閉じたときの格納が加わります。macOS ではそれらを Dock に任せ（ウィンドウを
閉じても elecdex は動き続けます）、ログイン項目から非表示で起動することはできません。Linux ではトレイとショート
カットはデスクトップ環境次第で、どちらもないセッションでは、何もしないスイッチを出す代わりにそう表示します。どれも
*Settings → Window* でオンにするまではオフです。

| | Windows | macOS | Linux |
| --- | --- | --- | --- |
| ウィンドウの外のアイコン | 通知領域 | メニューバー | デスクトップにあればシステムトレイ（素の GNOME は拡張機能が必要） |
| アイコンへの最小化・格納 | あり | なし（ウィンドウを閉じても elecdex は動き続け、Dock から戻せる） | デスクトップにアイコンを置く場所があるとき |
| システム全体の表示／非表示のショートカット | あり | あり | X11 のみ。Wayland のセッションはそのキーを自分で持つので、そう表示する |
| サインイン時の起動 | Run キーのエントリー（アンインストーラーが削除する） | アプリのログイン項目（macOS が許可を求めることがある） | `~/.config/autostart/elecdex.desktop` |
| *start in the background* | あり | なし（ログイン項目は引数を取らない） | あり |

- アイコンをクリックすると elecdex が開き、右クリックのメニューから設定を開くか終了できます。Windows では、新しい
  アイコンがタスクバーの **^** の中に入ることがあります。ウィンドウが隠れている間もアイコンは出るので、隠した
  ウィンドウはいつでも戻せます。
- **どのアプリからでも表示／非表示**: 既定は **Ctrl+Alt+Shift+E** で、スイッチの横で設定します。文字・数字・
  ファンクションキーだけを受け付け、ほかのアプリがすでにそのキーを持っていれば、注記を出してオフに戻します。
  *reset all shortcuts* の対象外で、ショートカットを記録している間はキーを手放すので、これ自体も記録できます。
  オンの間は、同じキーのアプリ内ショートカットに *Settings → Keyboard* で印が付きます。OS はそのキーを elecdex の
  ウィンドウのショートカットへ先に渡すためです。elecdex が手前にあれば片付け（トレイの設定がオンならアイコンへ、
  そうでなければタスクバーへ）、ほかのどこからでも elecdex を手前に出します。
- *サインイン時の起動*: システム側でオフにされると（Windows ではタスクマネージャーのスタートアップアプリ）、設定にも
  オフとして表示されます。インストールしたアプリでのみ使えます。*start in the background* を付けると、サインイン時に
  非表示で始まります。
- **Ctrl+Shift+Q** は、閉じても通知領域に格納するだけの設定のときも終了します。明示的な終了は必ず終了します。
- 何が起きても、elecdex をもう一度起動すれば動いているものが戻ってくるので、ウィンドウを見失うことはありません。

## Utility

**Utility** — 小さな道具を 1 枚にまとめたペイン。指定したあいだスリープを止める、QR コードを作る（テキスト・
アドレス・Wi-Fi）、エンコード・デコード・ハッシュ・時刻の変換。**Ctrl+Shift+U** でこのペインへ行くか、ポップアップで
出します。[Utility](panes-desk.ja.md#utility) を参照してください。

## キーボードショートカット

区切り線のキー以外のショートカットは、すべて *Settings → Keyboard* で変更できます。変えたいものをクリックして新しい
キーを押します。ショートカットには **Ctrl**（macOS は **Cmd**）、**Alt**、またはファンクションキーが必要なので、
それ以外のキーはすべてシェルに届きます。すでに使われている組み合わせには印が付きます。キーは US キーボードの刻印で
示していますが、ほかのキーボードでも同じ位置のキーです（日本語キーボードでは Ctrl+Shift+= は Ctrl+Shift+^、
Ctrl+Shift+[ / ] は Ctrl+Shift+@ / [）。アプリ内の一覧やツールチップは、今の割り当てを、お使いのキーボードの刻印で
示します。

| ショートカット | 操作 |
| --- | --- |
| Ctrl+Shift+A | ペインを追加（任意のウィジェットを、フォーカスのあるペインの右・下・隣のタブに、またはポップアップで） |
| Ctrl+Shift+E | フォーカスのあるペイン（タブならそのグループ全体）を右に分割 |
| Ctrl+Shift+O | フォーカスのあるペイン（タブならそのグループ全体）を下に分割 |
| Ctrl+Shift+T | フォーカスのあるペインの隣に新しいタブ |
| Ctrl+Shift+W | フォーカスのあるペイン、または前面のペインを閉じる |
| Ctrl+Shift+Z | フォーカスのあるペインをワークスペースの前面に出す／戻す（Escape でも戻る） |
| Ctrl+Shift+] / [ | 次／前のペインへフォーカス |
| Ctrl+Shift+← / → / ↑ / ↓ | *unreleased*：その方向のペインへフォーカス。その方向にペインがなければ、キーはペインに届く |
| Ctrl+Shift+Backspace | 既定のレイアウトに戻す（シェルが開いている間は先に確認） |
| Ctrl+Shift+G | 保存レイアウト |
| Ctrl+Shift+1〜9、0 | 先頭 10 件の保存レイアウトを、ダイアログの並び順で適用（0 は 10 件目）。空の番号ならキーはフォーカスのあるペインへ |
| Ctrl+Shift+F1〜F10 | プリセットへ: standard、network、earth、dev、media、desk、ai、cockpit、retro、blank |
| Ctrl+Shift+L | ランチャーを検索（レイアウトになければポップアップで出す） |
| Ctrl+Shift+U | Utility ペイン: レイアウトの次のもの、なければポップアップ。もう一度押すと片付く（Linux では IBus がコードによる文字入力にこのキーを使うことがあるので、変更してください） |
| Ctrl+Shift+S | 選択中のタブのシェルにフォーカス（シェルのペインがなければ追加） |
| Ctrl+Shift+F | シェルのスクロールバックを検索（Enter / Shift+Enter で次と前、Escape で閉じる） |
| Ctrl+Shift+K | シェルのスクロールバックを消去 |
| Ctrl+Shift+= / - | すべてのシェルの文字を大きく／小さく |
| Ctrl+Tab / Ctrl+Shift+Tab | フォーカスのあるタブグループ（シェルのタブなど）の次／前のタブ（*unreleased*：以前は Ctrl+Shift+→ / ←） |
| Ctrl+Alt+Shift+→ / ← | シェルから: 次／前のシェルのペイン（またはシェルのタブのグループ） |
| Ctrl+Shift+. | 設定 |
| Ctrl+Shift+P | アクションパレット |
| F11 | 全画面の切り替え |
| Ctrl+Shift+M | ウィンドウを最小化（Windows、Linux） |
| Ctrl+Shift+Q | 終了 |
| Ctrl+Alt+Shift+E | どのアプリからでも elecdex を表示／非表示（*Settings → Window* でオンにするまでオフ。Wayland のセッションでは不可） |
| 区切り線の上で矢印キー | サイズ変更（Shift で大きく） |
| 区切り線をダブルクリック | 両隣の 2 つのペインで場所を等分 |

- シェルでは、PuTTY や Windows Terminal と同じく、テキストを選択するとコピー、右クリックで貼り付けです。Ctrl+C は
  シェルの割り込みのままです。検索バーが移動した一致箇所はコピーされず、自分で選んだものだけがコピーされます。左右に
  隣のペインがないとき、Ctrl+Shift+← / → はシェルに届き、PSReadLine が単語単位で選択します。
- その場で当てはまらないショートカットは、キーをペインに残します。前面に出せないペインでの Ctrl+Shift+Z、タブ
  グループの外でのタブのキーなどです。

## ステータスバーとウィンドウ

- **ステータスバー** は、ポインターを画面の下端に持っていくとスライドして現れます。左端には保存レイアウトごとの
  番号ボタン（番号はそれを適用するキー）があり、ペインの追加、保存レイアウト、レイアウトのリセット、設定、テーマ、
  サウンド、終了のボタンが続きます。
- Windows と Linux の全画面では、ポインターを右上の隅に持っていくと、最小化・全画面の解除・閉じるのボタンが降りて
  きます。閉じるは、通知領域で動き続ける設定なら elecdex をそこへ格納し、そうでなければ確認してから終了します。
- 起動フラグ: `--windowed`（全画面にしない）、`--no-intro`（起動シーケンスを省く）。
