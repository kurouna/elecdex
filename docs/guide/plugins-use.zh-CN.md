# 插件 — elecdex

elecdex 是面向 Windows、macOS 和 Linux 的科幻风格终端模拟器兼系统监视器，是对 eDEX-UI 的重写。插件为它添加一个你自己的窗格。本页从用户的角度介绍插件：如何安装、开启时授予什么以及会询问什么、插件能访问和不能访问什么、文件放在哪里，以及两个示例插件——番茄钟和节奏游戏 KEYSTREAM。编写插件所需的 API 见 [docs/plugins.md](../plugins.md)（日文）。macOS 和 Linux 只经过自动化测试的构建和运行，尚未经过充分的人工验证。

## 插件是什么

| | |
| --- | --- |
| 位置 | *Settings → Plugins*；开启的插件会出现在添加窗格的选择器（Ctrl+Shift+A）中，带有 *plugin* 标记 |
| 读取 | 只有你授予的：指标来源、指定的主机、登录会话、按键、声音 |
| 运行时机 | 只要它的窗格打开着，它的 Worker 就运行；若你授予了*在没有窗格时继续运行*，则一直运行 |
| 隐私 | 自己无法访问页面、你的文件或网络；每个请求都由应用发出，并对照你的授权检查 |
| 设置 | `settings.json` 中的 `plugins`，按插件 id |

- 插件用来添加一个窗格。它是一个 TypeScript 或 JavaScript 文件，或者一个含有 `index.ts` 的文件夹，放在应用数据文件夹下的 `plugins` 文件夹中。
- 保存修改即会加载：文件夹受到监视，只有内容变化了的插件会重启。
- 旁边的 `elecdex-plugin.d.ts` 为编辑器提供 API 的类型。elecdex 每次启动都会按自己的 API 重写它，请不要编辑。
- 插件不能弹出，也不能替换内置窗格。

## 安装插件

### 从文件夹安装

1. 打开 *Settings → Plugins*，点击 **install from a folder…**。
2. 选择插件的文件夹。

elecdex 会从中取出插件本身——入口文件及其导入的内容，别的一概不要，所以 README、`package.json`、`.git`、`node_modules` 以及代码旁的任何测试都会留在原处。插件确实导入了的 `tests/` 下的文件会一起复制：关键在于插件是否用到它，而不是文件夹叫什么。

- 插件以该文件夹自己的名字安装。如果已有同名插件，会先询问；它的权限和保存的数据仍跟随其 id 保留。
- 复制之前会检查不运行就能知道的事：代码能否编译、每个导入是否都是随之复制的文件。因此不是插件的文件夹，或需要 npm 的插件（例如 `from 'lodash'` 这样的包导入），会被拒绝并说明原因，而不是之后才出错。
- *包含*多个插件的文件夹（例如另一个 elecdex 的 plugins 文件夹）也能与本身就是插件的文件夹区分开来。
- 安装的插件和手动放入的一样，初始为关闭状态。

### 手动放入

*Settings → Plugins* 中的 *open plugins folder* 会打开该文件夹；把插件放进去即可。

| 形式 | 规则 |
| --- | --- |
| 单个文件 | 直接位于 `plugins/` 下的 `.ts` 或 `.js` 文件（`.d.ts` 除外） |
| 文件夹 | 直接位于 `plugins/` 下、含有 `index.ts` 或 `index.js` 的文件夹；最多 4 层、64 个文件 |
| 大小 | 每个插件合计最多 1 MiB |
| 链接 | 只读取普通文件和文件夹，不跟随符号链接 |

加载失败的插件会被隔离，不会影响其他插件；设置中它那一行会显示原因。

## 开启插件

插件在 *Settings → Plugins* 中开启之前一直处于关闭状态。新插件，无论是安装的还是手动放入的，都是关闭的。

1. 打开插件的开关。
2. 如果它请求权限，那一行会用平实的语言列出这些权限（*[插件] will be able to:*），并等待你确认。
3. 点击 **agree and turn on** 或 **cancel**。

不请求任何权限的插件会直接开启，不会询问。

| 权限 | 设置中说明它可以做什么 |
| --- | --- |
| 指标来源 | 读取正在运行的程序名、这台电脑连接的地址、你的网络地址、这台电脑的品牌和型号、操作系统和机器名，或其他读数 |
| 主机 | 通过互联网访问指定的主机，不带 Cookie |
| 会话 | 以你的身份登录后访问某个主机：它能看到该网站向你展示的内容（你在专用窗口中登录一次，在设置中退出） |
| 后台 | 在没有打开任何窗格时继续运行 |
| 通知 | 播放声音并显示系统通知 |
| 按键（API 第 2 版） | 接收其窗格获得焦点时你按下的按键（绝不包含与 Ctrl 或 Alt 的组合） |
| 声音（API 第 2 版） | 播放音乐和声音 |

- 如果插件既能读取个人相关的读数（程序名、连接、网络地址、品牌和型号、操作系统和机器名），又能访问主机，同意界面会明确写出：*It could send … to …*。
- 同意绑定在插件的 id 与其文件名或文件夹名上。另一个文件冒用你为别的插件同意过的 id 时，会重新询问（*x.ts now uses the id you agreed to for y.ts*）。
- 编辑插件时，只要它没有请求更多权限，同意就保持有效；请求更多时，它会停下来等待你确认（*It now asks for more than you agreed to*）。
- 连接窗格的套接字表（`net.sockets`，哪个程序在和哪里通信）永远不能授予任何插件。

## 插件能访问什么

| | |
| --- | --- |
| 运行于 | 页面沙箱中属于它自己的 Web Worker；主进程只转换它的文本，从不运行它 |
| 绘制方式 | 通过应用按主题渲染的区块：文本、数字、仪表、图表、表格、列表、按钮。从 API 第 2 版起，也可以在 Worker 中在自己的画布上绘制 |
| 网络 | 只能经由应用、只能访问已授权的主机：只允许 https，主机名完全匹配（不允许通配符、IP 地址或 `localhost`），重定向也只能到已授权的主机 |
| 存储 | 由主进程保存的专属键值存储（`plugin-data/<id>.json`，最多 1 MiB） |
| 按键 | 仅限 API 第 2 版，仅在其窗格获得焦点时，绝不包含与 Ctrl 或 Alt 的组合、Tab 或功能键；接收期间会亮起 KEYS 指示灯 |
| 声音 | 仅限 API 第 2 版，通过 elecdex 的合成器，从固定的音色列表中选择 |

- 插件无法访问页面、你的文件或网络。真正把它关在里面的是页面的内容安全策略（`connect-src 'self'`）。
- 停止响应的插件会被终止，不会拖住应用：它的窗格会显示 *plugin not responding* 和一个重启按钮。
- 插件设置中标为 secret 的值只是在屏幕上被遮住。它们以明文保存在 `settings.json` 中，并原样交给插件，这一点与 AI 密钥不同。

## 管理插件

*Settings → Plugins* 中每个插件占一行：

| 部分 | 显示或操作 |
| --- | --- |
| 状态 | *loading*、*error*、*needs a newer elecdex*、*duplicate id*、*off*、*needs your agreement*、*on* |
| 权限 | 它可以做什么（措辞同上） |
| 设置 | 插件自己的设置（文本、数字、开关或选项），有说明的会显示在各栏下方 |
| *sign in to [主机]* / *sign out* | 对于获得会话授权的插件：打开它的登录窗口，或删除它的会话 |
| *forget* | 关闭插件，并删除它保存的数据和登录信息（第二次点击时确认） |

- 已关闭、已删除或出错的插件的窗格会留在布局中，显示原因和一个打开设置的按钮；重新开启插件后窗格即恢复。
- 从文件夹中消失的插件，其同意会一直保留，直到你 *forget* 它；这样编辑器保存时短暂删除或重命名文件，也不会让它被关闭。

## 文件放在哪里

都在应用数据文件夹中（见[文件位置](themes-settings.zh-CN.md#文件位置)）：

| 路径 | 内容 |
| --- | --- |
| `plugins/` | 插件，每个一个文件或文件夹。首次启动时创建并写入番茄钟示例；文件夹一旦存在，即使为空，也不会再写入任何东西 |
| `plugins/<文件夹名>/` | 从文件夹安装的插件，以该文件夹的名字命名 |
| `plugins/elecdex-plugin.d.ts` | 供编辑器使用的 API 类型，每次启动都会重写 |
| `plugin-data/<id>.json` | 插件保存的内容 |
| `settings.json` → `plugins` | 按插件 id：是否开启、你同意了什么、设置值 |
| `persist:plugin-<id>` | 已登录插件的专属 Cookie，与网页窗格的分开；*sign out* 和 *forget* 会将其删除 |

## pomodoro

| | |
| --- | --- |
| 位置 | 写入新建的 plugins 文件夹；源代码在本仓库的 `examples/plugins/pomodoro` |
| 权限 | 通知（提示音和系统通知） |
| 设置 | Focus (minutes) 25、Short break (minutes) 5、Long break (minutes) 15、Rounds before a long break 4、Start the next phase by itself 关闭 |

番茄钟：专注时段、短休息，每隔几轮一次长休息，带 VFD 仪表、提示音和阶段结束时的通知，重启后继续。它不发出任何网络请求。可以以面板形式放大。

## KEYSTREAM

| | |
| --- | --- |
| 位置 | 本仓库的 `examples/plugins/keystream`；从其文件夹安装（它需要按键和声音的同意，所以不会写入 plugins 文件夹） |
| 权限 | 按键和声音（API 第 2 版） |
| 设置 | Volume (%) 80；Timing offset (ms) 0，范围 −150 到 +150，步长 5；Guide melody（在下面小声演奏你的声部）关闭 |

一款节奏游戏，也是插件 API 第 2 版的示例。

- 字母沿着立在对应按键上方的轨道落下，在判定线处按下就会奏出主旋律，伴奏由游戏演奏。
- 主键行是白键，上一行是黑键——键盘各行的错位正好就是钢琴键的排列——所以每个键总是奏出同一个音。
- 共 21 首曲目，分在四个流派标签页中（CLASSICS、POP、DANCE、ELECTRO），并以星级标示难度，光标停留的曲目还会播放试听；每首都配有专门为它编写的伴奏和一个便于挑选的风格词。
  - 十三首 elecdex 原创：其中有 J-POP、K-POP、EDM、City Pop 和 Chiptune 风格各一首，还有每一拍都落在同一个键上、EASY 只要跟着节奏敲一个键就能乐在其中的 180 BPM 偶像流行和 200 BPM J-CORE。
  - 八首由 elecdex 编曲的公有领域乐曲：《小星星》、《青蛙合唱》、《欢乐颂》、《天鹅湖》、《天堂与地狱》康康舞曲、莫扎特第 40 号交响曲与《土耳其进行曲》、《在山魔王的宫殿里》。
- 按 Enter 会在列表上方打开所选曲目的三个难度面板。EASY 只需敲击落在拍上的音，其余由游戏演奏；HARD 判定更严，信号耗尽即结束。Space 可关闭或开启试听。
- eDEX-UI 的屏幕键盘作为判定线回来了。
- 演奏结束时像游戏的结算画面一样：分数逐步累加，评级砸进菱形框中，并以指示灯表示结果（CLEAR、FULL CHAIN、ALL SYNC 或 NO CARRIER），旁边还有与此前最高分的差距，以及按键偏早还是偏晚。
- 时序从头到尾只用一个时钟：按键以系统收到它的瞬间判定，伴奏按听到的瞬间调度，轨道则提前一帧、按这一帧真正显示在屏幕上时的位置绘制，所以音符到达判定线时正好发声。剩下的只是演奏者和键盘本身的偏差，结算画面会告诉你怎么办：当按键整体偏晚或偏早时，它会给出应设置的 *Timing offset* 值（SET OFFSET +20），直接填进插件设置即可。
- **FREE PLAY** 把键盘变成乐器：按住的键才会发声，Space 是延音踏板，与 DAW 的音乐键入一样用 Z X 切换八度、C V 调整力度，数字键一键切换乐器（在任何画面、乐曲中途也可以），还可以让任意曲目的伴奏循环播放、在其上即兴演奏，按住的和弦会即时显示和弦名。

| 画面 | 按键 |
| --- | --- |
| 曲目列表 | ↑ ↓ 选曲；← → 或 < > 切换流派标签页；Enter 打开难度面板；Space 开关试听 |
| 难度面板 | ↑ ↓ 或 ← → 选难度；Enter 开始；Escape 或 Backspace 返回 |
| 演奏中 | Escape 或 Space 暂停（之后 R 重来，Q 回到菜单）；↑ ↓ 调整下落速度。窗格失去焦点或不可见时会暂停 |
| 任何画面 | 数字键行切换乐器：1 E.PIANO、2 PIANO、3 GUITAR、4 SYNTH LEAD、5 CHIP、6 ORGAN、7 MARIMBA、8 E.BASS、9 PAD、0 PLUCK、- SYNTH BASS |

判定窗口为 SYNC ±40 ms、LOCK ±80 ms、ACK ±120 ms；HARD 将它们缩小到四分之三。

所有乐器都在演奏时于音频线程中实时计算，没有一个是录音。

- 它的钢琴是物理模型：坚硬、泛音逐渐拉伸的琴弦两根、三根一组，拍动着分两段衰减；毡锤敲得越重，声音越明亮；低音的重击会带出金属般的铿锵；声音经过音板和房间，踩下踏板时，连没有敲击的琴弦也会共鸣。
- 主音吉他在吉他手会用的琴弦和品位上演奏，经过拾音器、以四倍采样率计算的失真音箱和扬声器箱体：按住进入下一个音时会击弦或滑音，持续按住则带上推弦颤音并产生回授而延长。
- 其他音色：重弹时拾音器会发出吼声的电钢琴、按经典鼓机电路方式发声的鼓、老游戏机的音源芯片、带晶体管梯形滤波器的模拟合成器、接旋转扬声器的音轮风琴（延音踏板切换转速）、马林巴，以及指弹电贝斯。
