      見た目と操作
      
    
        
      
      • CODE 画面の一番下に WRITE の行。AI チャットの入力欄と同じ枠・>・SEND。Enter で送り、Shift+Enter で改行。IME 変換中の Enter では送らない
        • 
      
      • 右端でプロバイダとモデルを選ぶ。プロバイダは設定の AI にあるもの。モデルは AI チャットペインと同じ欄（ModelField）で、打つか、開いたときにプロバイダから読む一覧から選ぶ（読む間は QUERYING）。既定はそのプロバイダに設定で選んであるモデル。選んだものはペインの状態に残す。LINK の AI スイッチとは無関係
        • 
      
      • SEND は他のボタンと同じく3 拍点滅してから動く（afterBlink）
        • 
      
      • 上書きの確認: エディタが CODE の最初の見本（SAMPLE）と同じか空なら確かめずに書く。違えば入力欄の上に「REPLACE? … UNDO puts it back」と REPLACE / CANCEL を出す。キーボードは REPLACE から、← → で移り、Enter で押し、Esc は CANCEL（question-keys）
        • 
      
      • 書くとき、エディタは破線の枠になり読み出し専用。答えが流れ込むように書かれる。SEND は STOP（警告色）に変わる。Esc でも止まる
        • 
      
      • 入力欄の上に段階: WRITE → COMPILE → FIX n/2 → READY。右端に経過時間とトークン
        • 
      
      • 書き終えると自動で COMPILE。誤りがあれば、誤りの一覧と今のコードを AI に返して直させる（最大 2 回）。直した行は薄く光る
        • 
      
      • READY で右のアセンブリと段階表が出る。RUN ▸ は人が押す（勝手に走らせない）
        • 
      
      • 直らなければ、誤りは今の CODE と同じく赤い一覧で行に飛べる。手で直すか、もう一度 SEND
        • 
      
      • 前のソースは消えない: 「UNDO」で書く前に戻せる（1 段）。カードに書くのは今と同じく COMPILE のとき
        • 
      
      • 2 回目からの SEND は今のエディタのコードを添えて送る（「スコアを出して」「もっと速く」で直していける）。会話は持たない
        • 
      
      • 設定の AI にプロバイダがなければ、入力欄は無効で「Settings ▸ AI でプロバイダを足すと使える」と出す
        • 
    
      
  
      
  
      
    
      作り（案）
      
    
        
      
      • main: main/elec16/write.ts（CodeWriter）。AI チャットのプロバイダ・鍵・アダプタを使う（targetFor、adapter.stream）。鍵はページに来ない。チャンネル elec16.write（質問、今のソース、プロバイダ id）→ 差分を流す、elec16.writeStop。1 ペイン 1 つずつ、180 秒、ページが消えたら取り消し（whenPageGoes）
        • 
      
      • 修正の往復はページが回す: コンパイラは CODE の worker にあるので、ページが COMPILE → 誤りを付けて main に 2 回目を頼む。main は「文を返す」だけで、コードを実行しない
        • 
      
      • システムプロンプト: shared/e16c/write-prompt.ts（純粋）。e16c の部分集合、型と u16() などの読み方、LIBRARY の関数（code-area.ts から取る）、画面 240×48・40 桁 6 行、キー、2 KB（7000–77FF）、export function main()、例 2〜3 本。答えはコードブロック 1 つだけ。テストで、プロンプトの例が今の e16c で通ることを確かめる
        • 
      
      • 答えから ```ts の中だけを取り出す（extractCode、純粋）。モデルの文は信用しないデータとして、エディタの文字にだけなる
        • 
      
      • CodeView.svelte: 下に WriteLine.svelte を足す。状態（idle / writing / compiling / fixing / ready / failed）は write.svelte.ts に分ける
        • 
      
      • POCKET だけ: PLAY-320 と SCI では WRITE の行を出さない
        • 
      
      • テスト: 単体（取り出し、プロンプト、往復の回数）、e2e は AI のスタブサーバーで「書かれる → 誤り → 直る → READY」と「プロバイダなし」
        • 
      
      • 説明書 elec16-e16c.md、ガイド panes-retro.md（3 言語）、data-sources.md（何を送るか）、decisions.md
