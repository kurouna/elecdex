# ELEC-16 PLAY（PLAY-320）取扱説明書

ELEC-16 のゲーム機モデル **ELEC-16 PLAY（PLAY-320）** の使い方です。カートリッジのゲームを差して遊び、自分でゲームを作ることもできます。

- ゲームを作る人は [elec16-kit.md](elec16-kit.md)（ゲーム開発の手引き）へ
- 見本のゲームは [ELECLANCE](elec16-eleclance.md)（縦スクロールシューティング）、[ELECAIRCOMBAT](elec16-elecaircombat.md)（コックピット視点の空中戦）、[ELECDRILL](elec16-elecdrill.md)（掘り進むブロックパズル）、[ELECFIGHTER](elec16-elecfighter.md)（1 対 1 の対戦格闘）
- 機械の詳しい仕様（メモリ、レジスタ、描画回路、音、カートリッジの形）は [elec16-play.md](elec16-play.md)

## 1. PLAY-320 にする

ELEC-16 ペインのパネルで **TUNE** を開き、モデルの一覧から **PLAY-320** を選びます。

- ユニット（機械と記憶カードのまとまり）ごとにモデルを持ちます。ほかのユニットはポケコンのまま使えます
- PLAY-320 との行き来は機械を再起動し、RAM を消します（BASIC のプログラムとゲームの RAM は意味が違うため）
- **拡張 RAM** の大きさ（0 / 128 / 256 / 512 KB。既定 512）も TUNE で選びます。変えると再起動して RAM を消します
- クロック（既定 4 MHz）は今までどおり TUNE で変えられます。PLAY-320 は自動で電源が切れません

## 2. 本体と画面

- 画面は **320×288** のカラーで、毎秒 60 枚まで描きます
- **本体の形**（TUNE）: auto（ペインの形で縦長か横長）、tall（縦長）、wide（横長）、screen（画面だけ）
- **色**（TUNE）: graphite、ivory、coral
- 本体は形の比のままペインに収まり、伸びません

## 3. 操作: 本体のボタン、PC のキー、ゲームパッド

| ボタン | 本体 | PC のキー | ゲームパッド（標準の配置） |
|---|---|---|---|
| 十字 | 十字キー | 矢印 | 十字、左スティック |
| A | 右 | Z | 右（1） |
| B | 下 | X | 下（0） |
| X | 上 | S | 上（3） |
| Y | 左 | A | 左（2） |
| L / R | 上の角 | Q / W | LB / RB |
| START | START | Enter | Start |
| SELECT | SELECT | 右 Shift | Back |

- 本体のボタンはマウス（タッチ）で押せます。押している間だけ沈みます
- PC のキーとゲームパッドは、ペインに焦点があるときだけ届きます（ペインをクリック）。Ctrl、Alt、Tab、Esc、ファンクションキーは取りません
- 3 つから押されたボタンはまとめて扱います
- **Pause キーは BRK**（止めて起動画面へ）

## 4. ゲームを差して遊ぶ

1. パネルの **GAMES** を開きます。**shelf**（ゲームの棚）に、アプリに入っているゲーム（ELECLANCE、ELECAIRCOMBAT、ELECDRILL、ELECFIGHTER）と取り込んだゲームが並びます
2. 遊ぶゲームを押すと、ユニットのスロットに差さります（**in the slot** に名前が出ます）。**take out** で抜きます
3. 起動画面で **START** を押すと、ゲームを読み込んで始まります

- **import .e16g** で、配られたカートリッジのファイル（.E16G）を棚に入れます。取り込んだゲームは × を 2 回押すと棚から外せます
- **DEVELOP** はゲームを作る人のためのものです（[elec16-kit.md](elec16-kit.md)）
- ゲームを抜くと、遊んでいたゲームは止まり、起動画面に戻ります

## 5. 起動画面

電源を入れると、機種名、RAM と拡張 RAM の大きさ、差してあるゲームの名前、**PRESS START** が出ます。

| 下の行 | 意味 |
|---|---|
| PRESS START | START で始まる |
| NO CARTRIDGE | 何も差していない（GAMES で差す） |
| LINK CART IS OFF | パネルの LINK で、LINK か CART が OFF になっている |
| BREAK AT 番地 / FAULT 原因 AT 番地 | 前のプログラムが止まった場所（BRK か例外） |

ゲームが終わる（START でタイトルへ戻るゲームが多い）と、起動画面に戻ります。

## 6. セーブ、電源、一時停止

- ゲームのセーブ（ベストスコアなど）は、カートリッジの **セーブ RAM** に残り、ユニットごと、ゲームの id ごとにアプリが保存します。同じゲームの新しい版に替えても残ります
- 機械の状態（RAM、拡張 RAM）は電池バックアップと同じく、ペインを隠したり閉じたりしたときに保存され、次に開くと続きから動きます
- ペインの上の ❚❚ で一時停止、▶ で続けます（BRK のボタンもその隣）。ペインが見えないときは自動で止まります（音も止まります）
- 音は設定のインターフェースの音が ON で、ELEC-16 の音量が 0 でないときに鳴ります（16 チャンネルのステレオ）

## 7. パネル: CORE、MEM、CODE、GAMES、LINK、TUNE

| タブ | 働き |
|---|---|
| CORE | レジスタとコード（ブレークポイント、STEP）。PLAY-320 にはモニタがないので、開発と確かめはここで |
| MEM | メモリ。拡張 RAM のバンクと映像メモリも見られる |
| CODE | e16c のプログラムをコンパイルし、RUN で機械に入れて直接呼ぶ（起動画面から）。描いたものは残り、BRK で起動画面へ |
| GAMES | ゲームの棚、スロット、DEVELOP |
| LINK | 機械の外への口（LINK）のサービスごとの ON/OFF。CART（カートリッジの読み込み）は既定 ON、AI は既定 OFF |
| TUNE | モデル、拡張 RAM、クロック、本体の形と色 |

## 8. 機械のあらまし

| 項目 | PLAY-320 |
|---|---|
| CPU | E16（ポケコンと同じ）。既定 4 MHz |
| RAM | 32 KB ＋ 拡張 RAM 最大 512 KB（8 KB のバンク） |
| 画面 | 320×288、モード 0（4 色のビットマップ）とモード 1（描画回路） |
| 描画回路 | 8×8 の 16 色タイル 1,024 枚、背景 2 枚（512×512 でずらせる）、スプライト 128 個（8・16・32 ドット）、パレット 16 本（RGB555）、行の割り込み、DMA |
| 音 | 16 チャンネル（矩形 4 種、三角、のこぎり、ノイズ、波形表 8 本）、エンベロープ、スライド、ビブラート、ステレオ |
| 入力 | 十字、A、B、X、Y、L、R、START、SELECT |
| カートリッジ | ROM 最大 1 MB、セーブ RAM 最大 32 KB（.E16G）。LINK の CART で読み込む |

レジスタと番地は [elec16-play.md](elec16-play.md) の 3〜7 章にあります。

## 9. 困ったとき

| こんなとき | すること |
|---|---|
| ボタンが効かない | ペインをクリックして焦点を移す。ゲームパッドは標準の配置のものだけ |
| START を押しても始まらない | 起動画面の下の行を見る（NO CARTRIDGE なら GAMES で差す。LINK CART IS OFF なら LINK で ON） |
| 音が出ない | 設定のインターフェースの音と ELEC-16 の音量。ペインが見えていること |
| ゲームが止まって起動画面に FAULT が出る | ゲームの不具合。作った人に番地を伝える。BRK（Pause）でも起動画面に戻る |
| 遊んでいたところから続けたい | ペインを閉じても、ユニットの電池バックアップから続く |
