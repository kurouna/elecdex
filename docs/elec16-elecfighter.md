# ELECFIGHTER — ELEC-16 PLAY の 1 対 1 対戦格闘

PLAY-320 のゲームキット（[elec16-play.md の 10 章](elec16-play.md#10-ゲームキットg7)、[elec16-kit.md](elec16-kit.md)）で作った 4 本目のゲームです。ワイヤーフレームとベタ塗りの人が、ラウンド制で 1 対 1 で戦います。ソースは `resources/elec16/games/elecfighter/`、設計と理由は [elec16-elecfighter-design.md](elec16-elecfighter-design.md) にあります。

格闘家は名前のない人型の 4 つの枠です。産業用の格闘シミュレータが使う訓練体で、顔はなく、体つきだけが違います。相手はシミュレータの対戦プログラムで、体は枠の人、違いは頭（操縦）にあります。

## 1. 始め方

1. ELEC-16 ペインを PLAY-320 にし、GAMES の棚から ELECFIGHTER を差して START を押す（[PLAY-320 の手引き](elec16-play-manual.md)）
2. 起動のログが数行流れる（START で飛ばせる）。タイトルで START を押すとメニュー
3. メニューは十字の上下と A: **VERSUS CPU**（勝ち抜き）、**CONTROLS**（操作の画面）、**BEST**（記録）
4. VERSUS CPU の最初の 1 回は操作の画面が自分から出る（START で次へ）。その後は格闘家の選択

タイトルで何もしないと、HOW TO PLAY（遊び方の要点）と BEST が交互に出ます。タイトルの SELECT でボタンの組（3 章）を替えられます。

## 2. 画面

- **格闘家の選択**: 上に 4 人の胸像（同じモデルをカメラを寄せて描いたもの。肩、首、背の高さが違う）、下にカーソルの乗った格闘家の全身が線だけの姿から現れ、右に枠と役、ひとこと、4 本のバー（POWER、SPEED、REACH、DEFENSE、5 段）。十字の左右で選び、A で決める（B でタイトルへ）
- **対戦の前**: 2 人が「RENDER」のバーとともに描き込まれ、相手のプログラムの名前と、その戦い方の 3 行が出る。START か A で飛ばせる
- **戦いの画面**: 上に elecdex のペインの見出しのような HUD（左が P1、右が CPU、それぞれ枠と役）、体力のバー、真ん中に TIME、その下に取ったラウンドの灯（◆）。体力のバーは減った分がしばらく琥珀色で残ってから縮み、4 分の 1 を切ると赤く点滅する。画面のいちばん下が記録の行（9 章）
- **帯**: ROUND 1、FIGHT、K.O.、TIME UP、YOU WIN、PAUSED などは画面を横切る帯に大きな字で出る。ラウンドの終わりの帯は上の方に出て、勝った側の勝ちのポーズを隠さない
- **試合の結果**: WIN か LOSE、相手、HITS（当てた数）、MAX COMBO、TIME LEFT、ROUNDS、STREAK（続けて勝った試合の数）

## 3. 操作

| パッド | PC のキー | 働き |
|---|---|---|
| 十字 左右 | ← → | 前と後ろへ歩く（**相手から見た向き**）。後ろを押している間はガード |
| 十字 下 | ↓ | しゃがむ。後ろ下でしゃがみガード |
| 十字 上 | ↑ | ジャンプ（斜めで前後へ） |
| Y | A | 弱パンチ |
| X | S | 強パンチ |
| B | X | 弱キック（TYPE A）／強キック（TYPE B） |
| A | Z | 強キック（TYPE A）／弱キック（TYPE B） |
| START | Enter | 一時停止 |
| SELECT | 右 Shift | ボタンの組を替える（タイトルと操作の画面） |
| L、R | Q、W | 使わない |

- **ボタンの組**: パッドの菱形では左下の Y と B が弱、右上の X と A が強で自然に並ぶ。PC のキーでは A・S と Z・X の並びが逆になるので、**TYPE A（パッド向き）と TYPE B（キックを入れ替えた PC のキー向き）** を選べる。操作の画面の `PAD | PC KEY | ACTION` の表は選んだ組に合わせて書き換わり、組はセーブ RAM に残る
- コマンドの入力（方向の組み合わせ）はない。技は「立ち、しゃがみ、ジャンプ × 4 つのボタン」と投げだけ
- 技を出せない間に押したボタンは、8 フレーム以内に出せるようになれば出る（先行入力）。同じフレームに出せる技が 2 つあれば、投げ、強、弱の順

## 4. 技

どの格闘家も同じ 13 の技を持つ（速さ、届く距離、ダメージが格闘家ごとに少し違う。8 章）。

- **弱**（弱パンチ、弱キック）: 出が速く（3〜6 フレーム）、当たっても小さい。ガードされても隙が少ない
- **強**（強パンチ、強キック）: 出が遅く（7〜14 フレーム。S4 の中段の立ち強パンチが 14）、当たると大きい。ガードされると隙が大きく、弱で反撃される
- **しゃがみ強パンチは対空**: 出始めから 8 フレームの間、上半身に攻撃が当たらない。跳び込んできた相手を迎え撃つ
- **しゃがみ強キックは足払い**: 当たると相手はダウンする
- **ジャンプ攻撃**: 4 つのボタンでそれぞれ出る。空中で当たった相手は必ずダウンする（空中で続けて当てることはできない）

## 5. ガードと高さ

後ろを押している間はガードになる。立ちガードとしゃがみガードで受けられる攻撃が違う。

| 攻撃 ＼ 防御 | 立ちガード | しゃがみガード |
|---|---|---|
| 上段（立ちの技、しゃがみ弱パンチ、しゃがみ強パンチ） | 受ける | 受ける |
| 下段（しゃがみ弱キック、足払い） | 当たる | 受ける |
| 中段（ジャンプ攻撃、S4 の立ち強パンチ） | 受ける | 当たる |
| 投げ | 抜けない | 抜けない |

基本はしゃがみガードで待ち、跳び込みと中段を見たら立つ。近づかれたら投げに気をつける。

## 6. 投げ、チェーン、カウンター、ダッシュ

- **投げ**: 相手の近くで「前か後ろ + 強パンチ」（後ろなら後ろへ投げる）。ガードしている相手も投げられる。両者とも地上にいて、相手がのけぞりやガードの硬直の最中でなく、起き上がったばかりでないときだけ掴む。遠いと同じボタンで強パンチが出る。掴むフレームに打撃を受けると投げは負ける。空振りすると 22 フレームの隙
- **投げ抜け**: 投げられた最初の 7 フレームの間に、同じ入力（前か後ろ + 強パンチ）で抜けられる（`THROW TECH`、両者が離れる）。両者が同時に投げると、どちらも抜ける
- **チェーン**: 弱が当たるかガードされたら、その弱の持続か戻りの最初の 4 フレームに、同じ系統（パンチならパンチ、キックならキック）で同じ姿勢（立ちなら立ち、しゃがみならしゃがみ）の強を押すと、続けて出る。弱から弱、強から、空振りからは出ない
- **カウンター**: 相手の技の出始め（出がかり）に当てると、のけぞりが 4 フレーム長く、ダメージが 2 割増し（記録の行に `COUNTER`）
- **コンボの補正**: 続けて当たるほど 1 発ごとにダメージが 1 割ずつ減る（最小 4 割）
- **ダッシュ**: 前を 10 フレーム以内に 2 回押すと前へダッシュ（14 フレームで約 36 ドット）。後ろを 2 回でバックダッシュ（18 フレームで約 32 ドット下がり、最初の 6 フレームは投げられない）。ダッシュの間はガードも技もできない
- **ダウンと起き上がり**: 足払い、投げ、空中で受けた攻撃でダウンする。起き上がる間は攻撃が当たらず、立った直後の 2 フレームは投げられない
- **壁**: 画面の端（台の縁）では下がれない。壁際の相手に当てると、当てた側が押し戻される

## 7. ラウンドと勝ち抜き

- **ラウンド**: 2 本先取。時間は 99 カウント（1 秒に 1）。体力が 0 で K.O.、時間切れは体力の多い方の勝ち（TIME UP）。同じ体力の時間切れとダブル K.O. は引き分けで、ラウンドを数えずにやり直す。3 回続けて引き分けると両者の負け
- **勝ち抜き**: 自分の選んだ格闘家以外の 3 人の体で戦うプログラムを強さの順に 3 人、最後に **ROOT**（自分と同じ体で、別の頭）。4 人に勝つと **SYSTEM CLEAR**（クリアの時間、コンティニューの数。記録を破ると NEW RECORD）

| 順 | プログラム | 体 |
|---|---|---|
| 1 | PACKET | S2 RUSH |
| 2 | MAINFRAME | S3 POWER |
| 3 | DAEMON | S4 OUTBOX |
| 4 | KERNEL | S1 BALANCE |
| 最後 | ROOT | 自分の選んだ枠 |

  自分の選んだ枠の体のプログラムは抜かれる（S1 を選べば PACKET、MAINFRAME、DAEMON、ROOT）
- 後で会う相手ほど反応が速い。プログラムの戦い方は対戦の前の 3 行に出る
- **CONTINUE?**: 負けると 9 から 0 まで 1 秒ずつ数える。START か A で同じ相手ともう一度（コンティニューの数が記録に出る）。数え終わると GAME OVER でタイトルへ
- **一時停止**: 戦いの最中の START で画面が暗くなり、PAUSED と RESUME、CONTROLS、QUIT FIGHT（十字と A）。一時停止の間は時間も相手も進まない。QUIT FIGHT で勝ち抜きをやめてタイトルへ
- 相手の動きは時刻を種にした乱数で揺れるので、同じ操作でも試合ごとに違う

## 8. 格闘家

体の違いは小さめです（速さと届く距離で 1〜2 割）。どの格闘家でも同じ読み合いができます。

| | S1 BALANCE | S2 RUSH | S3 POWER | S4 OUTBOX |
|---|---|---|---|---|
| ひとこと | どれも標準の体 | 小さく速い。届く距離は短い | 肩と胴の厚い、重い体 | 背が高く手足が長い |
| 体力 | 125 | 124 | 116 | 132 |
| 歩く速さ（前） | 標準 | 速い | 遅い | 標準 |
| ジャンプ | 標準 | 高い | 低い | いちばん高い |
| 弱の出 | 標準 | 1 フレーム速い | 1 フレーム遅い | 標準 |
| 強のダメージ | 標準 | 少し小さい | 少し大きい | 標準 |
| 届く距離 | 標準 | 短い | 少し長い | 強キックと足払いが長い |
| 投げの間合い | 28 | 26 | 34 | 30 |
| 特徴 | — | — | 当たっても守っても押し下がりにくい（重い） | 立ち強パンチが中段（両手の振り下ろし。出が遅い） |

選択の画面のバーは、この表から計算した 5 段の目安です（POWER は強の 4 つのダメージの合計、SPEED は前へ歩く速さ、REACH は立ち強キックの届く距離、DEFENSE は体力と重さ）。

## 9. 記録の行

画面のいちばん下の 1 行に、端末のログのように今起きたことが出ます。出てから 60 フレームで暗くなって消えます。

| 出る言葉 | 意味 |
|---|---|
| `> P1 COUNTER  LIGHT PUNCH` など | カウンターで当たった（どちらの、どの技か） |
| `> CPU ANTI-AIR` など | 対空で跳び込みを落とした |
| `> P1 THROW` など | 投げた |
| `> THROW TECH` | 投げ抜け |
| `> READ` | 相手があなたの動きを読んで受けた |

操作の画面で A を押すと記録の行を消せます（LOG OFF。もう一度で LOG ON）。セーブ RAM に残ります。

## 10. BEST とセーブ RAM

- **BEST**（メニューか、タイトルで待つと出る）: 枠ごとのクリアの数といちばん速いクリアの時間、いちばん長い STREAK（続けて勝った試合の数。コンティニューで途切れる）
- **セーブ RAM**（カートリッジの 1 バンク）: 0 に印 "EF"、2 にボタンの組、4 に記録の行の入り切り、6 に並びの版、8 に印（操作の画面を一度出したか）、10 にいちばん長い STREAK、16 から枠ごとに 8 バイト（クリアの数、いちばん速いクリアの秒）。版のない前のセーブは、ボタンの組と記録の行を残して、記録を新しく作る

## 11. 作り（要点）

- 格闘家は低ポリゴンの 3D モデル（glTF）を three.js で前もって描いた 16×16 のセルで、ゲームの中で 3D は描かない。ポーズが替わったフレームだけ、そのセルをカートリッジから写す。当たりと喰らいの箱は絵から下書きし、手で直した分は `fighters/<id>/boxes.txt` に重ねる
- 色の演出（線だけの姿から塗りが満ちる、当たりの光、ガードの青白、投げの赤紫、K.O. で塗りが消えて破片に割れる、一時停止の暗さ）はパレットの書き換えだけ
- ステージ GRID は SVG（`scripts/elecfighter/svg/stage.svg`）から描き、床は 1 行ごとのラスタで遠近を付けている。タイトルの ELEC / FIGHTER の字も自作の SVG（`svg/logo.svg`、ワイヤーとベタ塗り）
- 絵は `node scripts/elecfighter-art.mjs` が最初に描いた PNG で、以後は PNG が元（`title` でタイトルの地図だけ、`screens` で画面の絵とパレットだけを描き直せる）
- テスト: `tests/unit/elec16-elecfighter.test.ts`（技の表と有利不利、高さとガード、投げと投げ抜け、チェーン、カウンター、ダッシュ、ダウン、ラウンド、勝ち抜き、CPU の反応の速さ、一時停止、記録の行、画面の流れ、セーブ RAM、絵の決まり、曲の同期、1 フレームの予算）
