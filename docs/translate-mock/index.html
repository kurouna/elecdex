このモックで見られるもの

  • TEXT：左が原文、右が訳文。原文を段落（文のまとまり）に分け、llama-server のスロットで並列に訳します（モデルカードの推奨どおり 1 リクエスト 1 段落）。中央の背骨に段落ごとの線と番号が通り、どこがどこに訳されたかを示します。段落・番号にポインタを置くと両側が光り、番号のカードに所要時間とトークン数が出ます。
  • 訳文は届いたそばから書かれ（キャレットは共有パルス）、書き終えた段落は他のペインと同じ fx-fresh のバーで知らせます。訳している間だけ訳文の枠がアクセント色になります。
  • FORM（常体／敬体、訳先が日本語のときだけ有効）、GLOSSARY（用語集。原文と訳文の該当語に下線）、CONTEXT（文脈。訳さず、毎回いっしょに渡す）、ROUND TRIP（訳文を原文の言語に訳し戻して意味のずれを見る。一致度は chrF）、LIVE（打ち終えて 0.6 秒で、変わった段落だけ訳し直す）。
  • 訳文の段落ごとに RETRY / EDIT / COPY。EDIT で直した段落は、後の段落を訳すときの履歴（前の訳）として使われ、言い回しがそろいます。
  • STATE：NO MODEL → SETUP、STANDBY（エンジン停止中。最初の翻訳で起動）、BOOT（llama-server のログを 1 行ずつ）、FAULT（終了コードと stderr の末尾、RESTART）。
  • SETUP：ENGINE（llama-server を探す／既存サーバーのアドレス）→ MODEL（この PC のメモリと GPU から推奨。4 サイズ × 量子化）→ LICENCE（PLaMo コミュニティライセンスへの同意）→ FETCH（再開できるダウンロードと sha256 照合）→ READY（自己テストの 1 文）。
  • HISTORY と ENGINE（右上のスライダー：起動方法、モデルの追加・削除、コンテキスト長・スロット・GPU 層・アイドル停止、ログ、ライセンス）。
  • 開閉するものは CRT のパワーオン／オフ、押したボタンはランチャーのタイルと同じ点滅。8 テーマすべてで見られます。

仕組みの案

  • main の新しいモジュール（main/translate/）が llama-server を子プロセスとして起動：--host 127.0.0.1 --port <空き番号> --api-key <起動ごとの乱数> --no-webui -c 16384 -np 4。ほかのプロセスやブラウザからは使えず、ページは IPC だけで話します（ページのネットワーク禁止はそのまま）。
  • プロンプトは PFML3 を shared の純関数で組み立てて /completion にストリーミング（モデルカードが本番向けに勧める形。chat_template.jinja は不要）。原文に紛れた <|plamo:…|> は無害化してから渡します。temperature 0、stop は <|plamo:tag|> と <|plamo:bos|>。
  • 段落ごとに並列、直前の段落の原文と訳を履歴として添えて一貫させます。結果は段落の内容と設定のハッシュで覚え、LIVE や言語の切り替えでは変わった段落だけ訳し直します。
  • モデルは main が Hugging Face から取得（Range で再開、sha256 照合、replaceFile で置く）。外に出る通信はこのダウンロードだけです。
  • エンジンは最初の翻訳で起動し、10 分使わなければ止め、最後の TRANSLATE ペインを閉じても止めます。見えていない間は新しく何も始めません（訳しかけの段落は書き終えます）。
  • フッターに「PLaMo 3 Translate · PLaMo Community License」を常に出し、data-sources.md にダウンロード先と頻度を書きます。

決めたいこと

Q1llama-server の入手。推奨：A 利用者が入れたもの（winget install llama.cpp / brew install llama.cpp）を探して使い、既に動いているサーバーのアドレスも選べる。B は elecdex が GitHub のリリースから実行ファイルを取ってくる（GPU 別のビルド選びと署名のない exe の扱いが要る）。 Q2モデルの一覧。0.8B / 2B / 8B / 31B の 4 つを出し、PC のメモリと VRAM から推奨を付ける（このモックでは 2B）。31B（19.5 GB）も一覧に出すか。メモリの目安は実測で決めます。 Q3履歴。main のファイルに保存（上限 200 件、CLEAR、保存しない設定あり）か、メモリだけか。 Q4LIVE の既定。推奨：オフ（Ctrl+Enter で訳す）。 Q5呼び出しキー。Ctrl+Shift+Y（空いています）でクリップボードの文を持って TRANSLATE を出す（レイアウトに無ければポップアップ）。 Q6ROUND TRIP の一致度（chrF の数値とバー）を出すか、訳し戻した文だけにするか。
