ELEC-16 SCI — 関数電卓モデル モック

ELEC-16 の 3 つ目のモデル。CPU・数値演算ユニット・電池バックアップはそのままに、128×64 のドット液晶と関数電卓の鍵盤、電卓の ROM を持つ。CALC は実際に計算できる（キーをクリック、または PC のキー）。ほかのモードは画面だけ。
