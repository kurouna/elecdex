設計は docs/agents-codex.md。まだ実装していない（2026-10-19、見送り）。

  • NEW 見出しの行に、どのエージェントのセッションかを示すチップ（CLAUDE / CODEX）を置く。Codex は枠を破線にする。読むエージェントが 1 つだけのときは出さない。
  • NEW サブエージェントの行は、Codex が付けた名前（Huygens）と task_name（subagent_b）を並べる。依頼文は暗号化されていて読めない。ツリーは session_meta の parent_thread_id と depth から組む。
  • NEW BUSY のセッションは、動きの行の右端に最後の書き込みからの経過時間（quiet 18s）を出す。Codex は許可待ちを記録しないので、許可待ちで止まっていてもこれが伸びていくだけになる。
  • NEW 直前のツールは、exec の中の tools.X(...) から取り出す。exec_command は EXEC、apply_patch は PATCH、spawn_agent は SPAWN、wait_agent は WAIT と短く表示する。
  • NEW 差分は、記録の item_completed にある FileChange の unified_diff をそのまま使う（ファイル自体は読まない）。見出しに「FROM THE RECORD」と書き、出どころを示す。
  • NEW 生きているかどうかは thread-writer-locks/<id>.lock で判定する。Codex が動いている間はファイルがあって OS がロックしており、終了すると消える。これで ENDED を経過時間で推測する必要がなくなった（30 分の決まりは、消え残ったロックの予備としてだけ残す）。BUSY と IDLE は、ターンが開いているかどうかで分ける。
  • ペインの見出しの小さい文字は「3 live · Claude Code, Codex」とし、読んでいるエージェントの名前を並べる（今の仕組みのまま）。
  • ENDED、10 分残す、FINISHED の折りたたみ、FILES CHANGED、SUB の印は、今の Claude Code の表示と同じ。
