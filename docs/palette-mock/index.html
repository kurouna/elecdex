操作

Ctrl+Shift+P（モックでは画面のどこでも）で開く。文字で絞り込み、↑↓ で選び、Enter で実行、Esc で閉じる。Tab / Shift+Tab で種類（ALL・ACTION・LAYOUT・PRESET・THEME・PANE・SETTINGS）を切り替える（ペイン追加の置き場所と同じ使い方）。空の入力では RECENT と種類ごとの見出しを出し、入力があれば種類をまたいで順位付けした一覧になる。上の「focused pane」を変えると、使えない項目（TAB GROUP にいない、シェルでない）が理由つきで薄くなる。Quit と Clear the shell's scrollback は Enter を 2 回（2 回目まで行が赤い）。Reset layout は、シェルがあり「confirm switch」がオンなら既存の確認ダイアログが聞くので構えず、オフにすると Enter 2 回になる。開いている間の Ctrl+Shift+P は何もしない（閉じるのは Esc）。テーマの試し当ては入れない（docs/palette.md Q2）。

パレットは Workspace を import しない。ショートカットの項目は、パレットが閉じて（dialogOpen が下りて）フォーカスが元のペインに戻ってから commands.run(id) を呼び、Workspace の既存の run がキーを押したときと同じ shortcutApplies を通して実行する。だから「キーで動くこと」と「パレットで動くこと」は常に同じで、パレット専用の分岐は Workspace に入らない。レイアウト・テーマ・ペイン・設定の項目は、既存の公開メソッド（layout.switchTo、appearance.patch、layout.addPane / ui.openPopup、ui.openSettings(section)）を呼ぶだけ。

守る決まり

決まりパレットでは
大きさと位置ピッカーと同じ min(46rem, 90vw) × min(34rem, 80vh)、画面の中央
ショートカットはデータ、キーの判定は Workspace だけ開くキーは keybindings.ts の 1 行。パレット内の ↑↓ Enter Esc Tab は、ピッカーと同じくダイアログ自身の操作（chord ではない）
ツールチップのキーは今の割り当て（chordHint）行の右端のキーは actionChord（利用者の上書き・キーボードの刻印つき）。割り当てなしなら出さない
scope: 'global' は main の OS 登録Show or hide elecdex は載せない（ページからは押せない）。palette.open 自身も載せない
CRT の開閉、motion.speccrt-on と transition:crtPower、背景は backdropShade。モーション低減で省く。motion.spec.ts に足す
Web ペインの上に描くものダイアログとして ui.dialogOpen に数えれば、WebWidget が自分のビューを片付ける（coverWeb は要らない。docs/palette.md §9）。モックの右上ペインを参照
切り替え・リセットの確認レイアウト・プリセットは layout.switchTo 経由なので、シェルがあり確認がオンなら今の確認が出る。Reset layout は確認が出ないとき（シェルなし、または確認オフ）だけ Enter 2 回。Quit と Clear は常に Enter 2 回
文字の大きさ名前は --step-0、説明は --step--1、種類・状態・キーは --step--2（ラベル）

決まったこと

開くキーは Ctrl+Shift+P、テーマの試し当てはなし、RECENT はページのメモリだけ、SETTINGS はセクション単位、PANE はポップアップできるものはポップアップ、ポップアップの上でも開く（2026-10-19）。設計とその理由は docs/palette.md。設計がこの注記と食い違うときは、設計に従う。
