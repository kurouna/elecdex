# ELEC-16 BASIC 取扱説明書

ELEC-16 は、elecdex のペインの中で動く 16 ビットのポケットコンピュータです。電源を入れると ELEC-16 BASIC が起動します。この説明書は、BASIC で計算をしたり、プログラムを作ったりするための手引きです。

- 機械語のモニタ（`MON`）と E16 の命令は [E16 マニュアル](elec16-e16.md) を見てください
- CODE 画面で TypeScript から機械語を作る方法は [e16c マニュアル](elec16-e16c.md) を見てください
- 機械の設計は [elec16.md](elec16.md) にあります

この説明書の画面の例は、既定の液晶（POCKET-48、40 桁 6 行）で示します。`>` で始まる行は、あなたが打つ行です。その下が ELEC-16 の答えです。

## 1. はじめに

### 1.1 電源を入れる

電源を入れると（ペインの帯の POWER か、BRK/ON キー）、画面にこう出ます。

```
ELEC-16 BASIC 1.0
26622 BYTES FREE
>
```

`26622 BYTES FREE` は、プログラムと変数に使える残りのバイト数です。`>` がプロンプトです。ここに命令や式を打ち、ENTER を押します。

電源を入れたときは、次の状態から始まります。

- プログラムは残っています（電池で保たれる、§3.7）。変数は消えています
- RUN モード、角度は DEG（度）、CAPS が掛かっています（英字は大文字で出ます）

電源と再起動の操作は次のとおりです。

| 操作 | 働き |
|---|---|
| ペインの帯の POWER | 電源を入れる・切る |
| `OFF` 文 | 電源を切る。RAM（プログラム）は残る |
| BRK/ON キー | 電源が切れていれば入れる。動いているプログラムを止める |
| 帯の RESET | CPU を始めからやり直す。RAM は残るので、BASIC はプログラムを持ったまま起動する |
| 自動電源 OFF | キーを待ったまましばらく何もしないと、電源が切れる（PANEL の TUNE で 10 分・30 分・しない） |

### 1.2 表示記号

液晶の上に、今の状態を示す記号が点きます。

| 記号 | 意味 |
|---|---|
| BUSY | プログラムを実行している |
| SHIFT | 次の 1 キーに SHIFT が掛かる |
| CAPS | 英字を大文字で打つ |
| カナ | カナを打つ（§11） |
| RUN / PRO | 今のモード（§3.1） |
| MON | 機械語のモニタにいる |
| DEG / RAD / GRAD | 角度の単位 |
| ♪ | `BEEP` の音が鳴っている |
| LINK | LINK（AI とのやりとり）が ON。答えを待つ間は点滅する（§15） |

### 1.3 キーボード

ELEC-16 のキーは次のとおりです。

| キー | 働き |
|---|---|
| BRK/ON（赤） | プログラムを止める。打っている行を捨てる。電源を入れる |
| MODE | RUN モードと PRO モードを切り替える |
| CLS | 画面を消す |
| ANS | 行を打つときは、カーソルの位置に `ANS` と書く（§2.2、§3.3）。プログラムからは `INKEY$` で読める（§8.3） |
| カナ | カナ入力の切り替え（§11） |
| INS / DEL / BS | 行の編集（§3.3） |
| SHIFT | 次の 1 キーだけ、キーの左上の記号を打つ。もう一度押すと外れる |
| CAPS | 英字の大文字と小文字を切り替える。押すまで続く |
| ← → ↑ ↓ | カーソルの移動と、行の呼び出し（§3.3） |
| SPACE / ENTER | 空白 / 行を BASIC に渡す |

英字は、CAPS と SHIFT のどちらか片方だけが掛かっているときに大文字になります。

記号の多くは、テンキーや句読点のキーの SHIFT 面にあります。

| キー | SHIFT で | キー | SHIFT で | キー | SHIFT で |
|---|---|---|---|---|---|
| 1 | `!` | 8 | `'` | `-` | `_` |
| 2 | `@` | 9 | `[` | `*` | `"` |
| 3 | `#` | 0 | `]` | テンキーの `/` | `?` |
| 4 | `$` | `(` | `{` | テンキーの `.` | `` ` `` |
| 5 | `%` | `)` | `}` | `=` | `\|` |
| 6 | `^` | `+` | `~` | `;` | `:` |
| 7 | `&` | `,` | `<` | `.` | `>` |
| | | | | `/` | `\` |

引用符 `"` は SHIFT と `*`、コロン `:` は SHIFT と `;`、`$` は SHIFT と `4` です。

### 1.4 PC のキーボードから打つ

ペインを選んでいる（フォーカスがある）間は、PC のキーボードで打てます。

| PC のキー | ELEC-16 のキー |
|---|---|
| 英字、数字、記号 | そのキー。SHIFT 面の記号は自動で SHIFT を付けて送る |
| Enter | ENTER |
| Backspace / Delete / Insert | BS / DEL / INS |
| 矢印 | 矢印 |
| Home | CLS |
| Pause | BRK/ON |
| CapsLock | CAPS |
| かな | カナ |

- 英字の大文字と小文字は、ELEC-16 の CAPS と PC の Shift で決まります。PC の CapsLock の状態は見ません
- MODE と ANS は PC のキーにありません。画面のキーを押してください
- Esc、Tab、F キー、Ctrl・Alt との組み合わせは ELEC-16 に送りません（elecdex のショートカットのため）
- 長いプログラムは、PANEL の TUNE にある **PASTE** で、クリップボードの文を打ち込めます。改行は ENTER になります。ひらがなと全角カタカナは半角カナに、全角英数は半角にします。打てない文字は飛ばし、その数を TUNE に出します

## 2. 電卓として使う

### 2.1 式を打つ

プロンプトで式だけを打つと、答えが右に寄せて出ます。

```text
>7/2
                                    3.5
>12*(3+4)
                                     84
>0.1+0.2
                                    0.3
```

数は 10 進で計算するので、`0.1+0.2` はちょうど `0.3` になります（§4.2）。

関数も使えます。電源を入れたときの角度は度（DEG）です。

```text
>SIN 30
                                    0.5
>SQR 2
                            1.414213562
```

変数の値も、名前だけを打てば見られます。文字列の式も答えが出ます。

```text
>A=12
>A*3
                                     36
>"ELEC"+"-16"
                                ELEC-16
```

### 2.2 ANS（直前の答え）

数の答えは `ANS` に残ります。次の式で `ANS` と打つと、その値を使えます。

```text
>7/2
                                    3.5
>ANS*2
                                      7
```

ANS キーを押すと、カーソルの所に `ANS` の 3 文字が入ります（英字で `A` `N` `S` と打っても同じです）。行の残りに 3 文字ぶんの余地がないときは入りません。

### 2.3 直前の式を呼び出す

RUN モードでは、↑ を押すと直前に打った行がもう一度出ます（打っていた行と入れ替わります）。直して ENTER を押せば、その式をもう一度計算します。まだ何も打っていなければ ↑ は何もしません。RUN モードの ↓ は何もしません（打っている行はそのまま）。

## 3. プログラムを作る

### 3.1 RUN モードと PRO モード

MODE キーで 2 つのモードを切り替えます。表示記号の RUN / PRO が今のモードです。

| | RUN モード | PRO モード |
|---|---|---|
| 向いていること | 計算、命令の実行、プログラムの実行 | プログラムを書く・直す |
| 行番号付きの行 | プログラムに入る | プログラムに入る |
| 行番号だけの行（`20`） | 電卓として `20` を出す | その行を消す |
| ↑ ↓ | ↑ で直前に打った行を呼び出す | プログラムの行を呼び出す（§3.3） |

どちらのモードでも、行番号の付いた行はプログラムに入り、行番号のない行はその場で実行されます。

### 3.2 行を打ち込む

行番号（1〜65535）に続けて文を打ち、ENTER を押すと、その行がプログラムに入ります。行番号の順に並ぶので、どの順で打ってもかまいません。

```text
>10 FOR I=1 TO 3
>20 PRINT "HELLO";I
>30 NEXT I
>RUN
HELLO1
HELLO2
HELLO3
>LIST 20
20 PRINT "HELLO";I
30 NEXT I
```

- 同じ行番号でもう一度打つと、その行が置き換わります
- 行を消すには、PRO モードで行番号だけを打つか、`DELETE` を使います
- 1 行は 78 文字までです
- 行を打ち込む・直すと、変数はすべて消えます。`CONT` もできなくなります

### 3.3 行の編集キー

プロンプトで打っている行は、次のキーで直せます。行は画面の端で次の行へ折り返します。プログラムが画面に残した文字の上で打ち始めても、行が使う段の残りは消えるので、打った行に古い文字は混ざりません。

| キー | 働き |
|---|---|
| ← → | カーソルを 1 文字動かす |
| 文字のキー | カーソルの下の文字を書き換える（行の終わりなら足す） |
| INS | カーソルの位置に空白を 1 つ開ける |
| ANS | カーソルの位置に `ANS` と書く |
| DEL | カーソルの下の文字を消す |
| BS | カーソルの前の文字を消す |
| ENTER | 行を BASIC に渡す |
| CLS | 画面を消し、打っていた行を捨てる |
| BRK | 打っていた行を捨て、新しいプロンプトを出す |
| MODE | 打っていた行を消し（同じ行のプロンプトのまま）、RUN と PRO を切り替える |
| ↑ ↓ | 行を呼び出す（下の表） |

**PRO モードでの行の呼び出し**

| キー | 呼び出す行 |
|---|---|
| ↑ | 直前に打ち込んだ行。続けて押すと、その前の行、さらに前の行 |
| ↓ | 次の行 |

- まだ何も呼び出していなければ、↑ は最後の行、↓ は最初の行です。端ではその行のままです
- 呼び出した行を直して ENTER を押すと、その行が置き換わります
- 行番号を書き換えて ENTER を押すと、元の行は残り、新しい番号の写しができます

### 3.4 LIST、RUN、NEW

| 命令 | 働き |
|---|---|
| `LIST` | プログラムを全部出す |
| `LIST 行` | その行（なければその次の行）から終わりまで出す |
| `LIST a-b` | 行 a から行 b までを出す（`LIST 15-25` なら 20 だけ、のように、間にある行） |
| `LIST -b` | 初めから行 b まで |
| `LIST a-` | 行 a から終わりまで（`LIST a` と同じ） |
| `RUN` | 変数を消して、最初の行から実行する |
| `RUN 行` | 変数を消して、その行から実行する |
| `NEW` | プログラムと変数をすべて消す |

- `LIST` の途中で BRK を押すと止まります
- `LIST 30:PRINT "X"` のように、後ろに `:` で文を続けられます
- 範囲の終わりが始めより小さいと `ERR:ARGUMENT` です
- `GOTO 行` をプロンプトで打つと、変数を消さずにその行から実行します

```text
>NEW
>10 PRINT "A=";A
>A=5:GOTO 10
A=5
>RUN
A=0
```

### 3.5 止める、続ける（BRK、STOP、END、CONT）

| 操作 | 働き |
|---|---|
| BRK キー | 実行中のプログラムを止め、`BREAK IN 行` と出す |
| `STOP` | そこで止め、`STOP IN 行` と出す |
| `END` | プログラムを終える |
| `CONT` | BRK か STOP で止めたところから続ける |

```text
>NEW
>10 PRINT "A"
>20 STOP
>30 PRINT "B"
>RUN
A
STOP IN 20
>CONT
B
```

`CONT` ができないのは、`END` やエラーで終わったとき、終わりの行まで実行し終えたとき、`RUN` か `GOTO` で別に動かして終わったとき、行を打ち込んだ・直したとき、`NEW` や `LOAD` をしたときです。そのときは `ERR:CONT` になります。

INPUT で入力を待っているときに BRK を押すと、`BREAK IN 行` で止まります。`CONT` でもう一度入力を聞きます。

BASIC のプログラムは、`WAIT`、`BEEP`、`LIST`、図形を描いている途中でも BRK で止まります。`CALL` で呼んだ機械語も BRK で止まり、モニタに落ちます（§10.3）。

### 3.6 プログラムを書く道具（AUTO、RENUM、DELETE、TRON）

**AUTO [始め][,刻み]**

次の行番号を自動で出します。始めを省くと、プログラムの最後の行 + 10（プログラムがなければ 10）、刻みを省くと 10 です。

```
>AUTO 100,10
>100 PRINT "ONE"
>110 PRINT "TWO"
>120
>
```

行番号だけで ENTER を押すと AUTO は終わります。BRK、CLS、MODE でも終わります。

**RENUM [新しい始め][,元の始め][,刻み]**

行番号を付け直します。省くと 10、0、10 です。`GOTO`、`GOSUB`、`THEN`、`ELSE`、`RESTORE`、`ON` の並びの行番号も合わせて直します。

```text
>NEW
>1 PRINT "START"
>2 GOSUB 5
>3 END
>5 PRINT "SUB":RETURN
>RENUM
>LIST
10 PRINT "START"
20 GOSUB 40
30 END
40 PRINT "SUB":RETURN
```

`RENUM 100,30,5` は、元の 30 番以降の行を 100、105、110…にします。30 番より前の行はそのままです。新しい番号が前の行とぶつかるとき、65535 を越えるときは `ERR:ARGUMENT` で、何も変えません。

**DELETE**

行をまとめて消します。

| 書き方 | 消す行 |
|---|---|
| `DELETE 20` | 20 |
| `DELETE 20-50` | 20 から 50 まで |
| `DELETE -50` | 最初から 50 まで |
| `DELETE 20-` | 20 から最後まで |

`DELETE` だけでは `ERR:SYNTAX` です（全部消すときは `NEW`）。

```text
>NEW
>10 PRINT "START"
>20 GOSUB 40
>30 END
>40 PRINT "SUB":RETURN
>DELETE 20-30
>LIST
10 PRINT "START"
40 PRINT "SUB":RETURN
```

**TRON / TROFF**

`TRON` の後は、行を実行するたびにその行番号を `[行]` と出します。`TROFF` で止めます。

```text
>NEW
>10 A=1
>20 PRINT A
>TRON
>RUN
[10][20]1
>TROFF
```

### 3.7 電源を切ってもプログラムは残る

RAM は電池で保たれます。電源を切っても、ペインを閉じても、プログラムは残ります。電源を入れ直すと、変数は消えます。

1 台の ELEC-16（ユニット）は、同時に 1 つのペインでだけ動きます。プログラムをファイルとして残したいときは、記憶カードに `SAVE` します（§9）。

## 4. BASIC の決まり

### 4.1 文と行

- 1 行に `:` で区切って文をいくつも書けます（`A=1:B=2:PRINT A+B`）
- 命令の語は、空白で区切らなくても読みます。`FORI=1TO3:PRINTI;:NEXT` も動きます。読みやすさのため、空白を入れることをすすめます
- 英小文字で打っても、命令の語と変数の名前は大文字として読みます。引用符の中と `REM` の後は、打ったとおりに残ります
- `LIST` は、打ったとおりの形（空白も数の書き方も）で出します。ただし、引用符の外の英字は大文字になります

### 4.2 数

数は 10 進の浮動小数点です。

| 項目 | 値 |
|---|---|
| 計算の桁 | 仮数 12 桁 |
| 表示の桁 | 10 桁（11 桁目で四捨五入） |
| 指数 | -99〜99（絶対値 9.99999999999E99 まで） |
| 1E-99 より小さい数 | 0 になる |

- 四則と平方根は 10 進で正確に計算し、12 桁に丸めます。だから `0.1+0.2` はちょうど 0.3 です
- `1/3` は 0.333333333333 です。これに 3 を掛けた 0.999999999999 は、表示では 1 ですが、1 とは等しくありません（`PRINT 1/3*3=1` は 0）
- 三角関数、対数、指数は、12 桁に丸めた答えです

数は `123`、`-4.5`、`.5`、`1.5E3`、`2E-5` のように書きます。表示は次のようになります。

```text
>PRINT 1/3;2/3
0.3333333333 0.6666666667
>PRINT 2^40;1E-5;12345678905
1.099511628E12 0.00001 1.234567891E10
```

- 整数は 10 桁までそのまま出します。それより大きいと指数の形（`1.099511628E12`）です
- 小数は、小数点の後が 10 桁に収まるうちは `0.00001` の形で出します
- 正の数の前に空白は付きません。負の数には `-` が付きます

範囲を越えると `ERR:OVERFLOW` です。

```text
>PRINT 1E99*10
ERR:OVERFLOW
>PRINT 1/0
ERR:DIV BY 0
```

### 4.3 変数

| 種類 | 名前の例 | 中身 | 値を入れる前 |
|---|---|---|---|
| 数の変数 | `A`、`X1`、`SC` | 数 | 0 |
| 文字列の変数 | `A$`、`N1$` | 文字列（既定 16 文字まで） | 空の文字列 |
| 数の配列 | `A(3)`、`B(2,5)` | 数の並び | 0 |
| 文字列の配列 | `C$(4)` | 文字列の並び | 空の文字列 |

- 名前は英字 1 文字、または英字と、英字か数字の 2 文字です。3 文字以上の名前（`ABC`）は書けません（`ERR:SYNTAX`）
- `A`、`A$`、`A()`、`A$()` は別々の変数です
- 命令の語と同じ 2 文字（`TO` `IF` `ON` `OR` `AS` `PI` `LN`）は名前に使えません。命令の語は空白がなくても読むため、`TOTAL=5` は `TO` で始まると読まれて `ERR:SYNTAX` になります
- 変数は `RUN`、`CLEAR`、`NEW`、行を打ち込んだとき、電源を入れたときに消えます

### 4.4 文字列

- 文字列は `"` で囲みます。`"` そのものを入れるには `CHR$(34)` を使います
- 文字列の変数は、決まった長さの入れ物を持ちます。既定は 16 文字です。入りきらない分は黙って切られます
- 長い文字列を入れる変数は、使う前に `DIM 名前$*長さ`（1〜255）で大きさを決めます

```text
>B$="ABCDEFGHIJKLMNOPQRSTUVWXYZ":PRINT B$
ABCDEFGHIJKLMNOP
>DIM C$*30:C$="ABCDEFGHIJKLMNOPQRSTUVWXYZ":PRINT C$
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

- 式の中の文字列は 255 文字までです。`+` でつないで越えると `ERR:ARGUMENT` です
- 1 つの文の中で作る文字列（`+`、`STR$`、`CHR$`、`INKEY$`、`TIME$`、`DATE$`）は、合わせて 512 バイトまでです。越えると `ERR:TOO COMPLEX` です。文が変われば、また 512 バイト使えます
- 文字列の比較は、文字コードの辞書順です（`"AB"<"B"` は 1）

### 4.5 配列

- `DIM A(10)` で `A(0)`〜`A(10)` の 11 個、`DIM B(3,4)` で `B(0,0)`〜`B(3,4)` の 20 個を作ります。添字は 0 から始まります
- 次元は 2 つまでです
- 文字列の配列は `DIM C$(5)*20` のように、要素の長さも決められます（既定は 16）
- `DIM` せずに使うと、添字 0〜10（2 次元なら 0〜10, 0〜10）で自動で作ります
- 同じ配列をもう一度 `DIM` すると `ERR:DIM` です。作り直すときは `CLEAR` します
- 添字が範囲の外、負、次元の数が違うときは `ERR:INDEX` です

```text
>DIM A(5),B$(2)*4:A(5)=9:B$(1)="ABCDEFG":PRINT A(5);B$(1)
9 ABCD
>PRINT A(6)
ERR:INDEX
```

### 4.6 演算子と優先順位

上ほど先に計算します。

| 順位 | 演算子 | 意味 |
|---|---|---|
| 1 | `( )`、関数 | 括弧、関数 |
| 2 | `^` | べき乗（右から: `2^3^2` は `2^9`） |
| 3 | `-`、`+`（符号） | 符号。`^` より後なので `-2^2` は -4 |
| 4 | `*`、`/` | 掛け算、割り算 |
| 5 | `+`、`-` | 足し算、引き算。`+` は文字列もつなぐ |
| 6 | `=` `<>` `<` `>` `<=` `>=` | 比較。成り立てば 1、成り立たなければ 0 |
| 7 | `NOT` | 否定（0 なら 1、0 でなければ 0） |
| 8 | `AND` | 両方が 0 でなければ 1 |
| 9 | `OR` | どちらかが 0 でなければ 1 |

```text
>PRINT -2^2;2^3^2;7>3;NOT 0;1 AND 0;1 OR 0
-4 512 1 1 0 1
```

- `AND`、`OR`、`NOT` は真偽（1 か 0）を返します。ビットごとの演算ではありません
- 剰余の演算子（MOD）はありません。`A-INT(A/B)*B` で求めます
- 比較は 1 つの式に 1 回です。`=<` `=>` `><` とは書けません

### 4.7 関数の引数

引数が 1 つの関数は、括弧なしでも書けます（`SIN 30`、`SQR 2`、`LEN A$`）。ただし、括弧なしの引数は符号と `^` までです。

- `SIN X+1` は `(SIN X)+1`、`SIN X*2` は `(SIN X)*2` です
- `ABS -X^2` は `ABS(-(X^2))` です

迷ったら括弧で囲んでください（`SIN(X+1)`）。引数が 2 つ以上の関数（`LEFT$`、`MID$`、`RIGHT$`、`POINT`）は括弧が要ります。

### 5.2 PRINT

```
PRINT 項目 ; 項目 , 項目 …
```

| 区切り | 働き |
|---|---|
| `;` | 続けて出す。数の後には空白を 1 つ置く |
| `,` | 次の 10 桁ごとの位置へ進む |
| 最後の `;` か `,` | 改行しない |

```text
>PRINT "A";1;"B",2
A1 B      2
>PRINT -5;"X";
-5 X
```

- `PRINT` だけなら空の行を出します
- 項目と項目の間には `;` か `,` が要ります
- 画面の右端で次の行へ折り返し、下の端で画面が上に送られます

### 5.3 INPUT

```
INPUT "問";変数,変数…
INPUT 変数
```

問の文と `?` を出して、入力を待ちます。問を省くと `?` だけです。

```basic
10 REM CIRCLE AREA
20 INPUT "RADIUS";R
30 PRINT "AREA ";PI*R^2
```

`RUN` して `2` と打つと、こうなります。

```
RADIUS?2
AREA 12.56637061
```

- 変数をいくつも書いたときは、1 行に `,` で区切って打ちます（`12,HELLO,"A,B"`）
- 数の変数に数でないものを打つと、もう一度聞きます。数が足りないときも、もう一度聞きます
- 文字列は、打ったとおり（前後の空白は除く）か、`"` で囲んで打ちます。`,` を入れたいときは囲みます
- 入力中に使える編集キーは BS だけです。CLS は画面を消してもう一度聞き、BRK はプログラムを止めます
- 入力は 78 文字までです

### 5.4 IF

```
IF 条件 THEN 文:文… ELSE 文:文…
IF 条件 THEN 行 ELSE 行
```

条件の値が 0 でなければ `THEN` の後を、0 なら `ELSE` の後を実行します。

```text
>X=3:IF X>2 THEN PRINT "BIG" ELSE PRINT "SMALL"
BIG
```

- `THEN` の後に `:` で文をいくつも書けます。条件が成り立たなければ、`ELSE` までの文は全部飛ばします。`ELSE` がなければ行の終わりまで飛ばします
- `ELSE` の後は行の終わりまでが「成り立たないとき」の文です
- `THEN` や `ELSE` の後に数だけを書くと、その行へ飛びます（`IF A=0 THEN 100`）
- `THEN` は省けます（`IF A>1 PRINT "X"`）
- 条件は数の式です。文字列そのものを条件にすると `ERR:TYPE` です。文字列は比べて使います（`IF A$="" THEN 50`）

### 5.5 FOR と NEXT

```
FOR 変数=始め TO 終わり STEP 刻み
  …
NEXT 変数
```

- `STEP` を省くと刻みは 1 です。負の刻みで数を減らせます
- 本体は必ず 1 回は通ってから、終わりを越えたかを比べます。`FOR I=3 TO 1` も 1 回は動きます
- 終わった後の変数は、終わりを越えた値です（`FOR I=1 TO 3` の後の `I` は 4）
- `NEXT` の変数は省けます（いちばん内側のループ）。`NEXT J,I` とは書けません。`NEXT J:NEXT I` と書きます
- 入れ子は 8 重までです。9 重目は `ERR:TOO COMPLEX` です
- 1 行の中でも使えます

```text
>FOR I=5 TO 1 STEP -2:PRINT I;:NEXT I:PRINT
5 3 1
>FOR I=3 TO 1:PRINT I;:NEXT I:PRINT
3
```

### 5.6 GOSUB と ON

- `GOSUB 行` でその行へ飛び、`RETURN` で `GOSUB` の次に戻ります。入れ子は 16 重までです
- `ON 式 GOTO 行1,行2,…` は、式の値が 1 なら行 1、2 なら行 2…へ飛びます。値の小数は切り捨てます。0 や並びの数を越える値なら、何もせずに次の文へ進みます
- `ON 式 GOSUB …` は、戻ると並びの後に続きます

```text
>NEW
>10 FOR K=1 TO 3:ON K GOSUB 100,200,300:NEXT K:END
>100 PRINT "ONE":RETURN
>200 PRINT "TWO":RETURN
>300 PRINT "THREE":RETURN
>RUN
ONE
TWO
THREE
```

### 5.7 DATA、READ、RESTORE

- `DATA` の項目は `,` で区切ります。項目は打ったとおりに読みます（命令の語にもなりません）。`,` を含む文字列は `"` で囲みます
- `READ` は、プログラムの最初の `DATA` から順に読みます。行をまたいで続けて読みます
- `RESTORE` で最初から、`RESTORE 行` でその行から読み直します
- 読む項目がなくなると `ERR:NO DATA`、数の変数に数でない項目を読むと `ERR:TYPE` です
- 実行中に `DATA` の行に来ても、何もせずに進みます

```text
>NEW
>10 DATA 3,"A,B",HELLO
>20 READ N,X$,Y$:PRINT N;X$;Y$
>RUN
3 A,BHELLO
```

### 6.1 数の関数

| 関数 | 答え | 例 |
|---|---|---|
| `SIN x` `COS x` `TAN x` | 三角関数（角度は DEG/RAD/GRAD に従う） | `SIN 30` は 0.5（DEG） |
| `ASIN x` `ACOS x` `ATAN x` | 逆三角関数（答えは今の角度の単位） | `ATAN 1` は 45（DEG） |
| `SQR x` | 平方根 | `SQR 2` は 1.414213562 |
| `ABS x` | 絶対値 | `ABS -3` は 3 |
| `INT x` | x を越えない最大の整数 | `INT -2.5` は -3 |
| `SGN x` | 符号（-1、0、1） | `SGN -4` は -1 |
| `LOG x` | 常用対数（底 10） | `LOG 100` は 2 |
| `LN x` | 自然対数 | `LN EXP 1` は 1 |
| `EXP x` | e の x 乗 | `EXP 0` は 1 |
| `PI` | 円周率 | 3.141592654 |
| `RND n` | n が 1 以上: 1〜n の整数。1 未満: 0 以上 1 未満の小数 | `RND 6` はさいころ |
| `ANS` | 電卓の直前の答え（§2.2） | |
| `PEEK 番地` | その番地の 1 バイト（0〜255） | §10 |
| `POINT(x,y)` | 点が点いていれば 1、いなければ 0 | §7 |

| `EOF(n)` | データファイル #n の終わりなら 1 | §9.5 |

```text
>PRINT SIN 30;SQR 2;INT -2.5;ABS -3;SGN -4
0.5 1.414213562 -3 3 -1

2 1 3.141592654
```

- 定義の外の引数（`SQR -1`、`LOG 0`、`ASIN 2`、DEG の `TAN 90`）は `ERR:ARGUMENT` です
- `RND` の数の並びは機械が覚えていて、続きから出ます。種を決める命令はありません

### 6.2 文字列の関数

| 関数 | 答え | 例 |
|---|---|---|
| `LEN(s$)` | 文字数 | `LEN("ABC")` は 3 |
| `LEFT$(s$,n)` | 左から n 文字 | `LEFT$("HELLO",2)` は `HE` |
| `RIGHT$(s$,n)` | 右から n 文字 | `RIGHT$("HELLO",2)` は `LO` |
| `MID$(s$,m[,n])` | m 文字目から n 文字（n を省くと終わりまで）。1 文字目が 1 | `MID$("HELLO",2,3)` は `ELL` |
| `CHR$(n)` | 文字コード n（0〜255）の 1 文字 | `CHR$(65)` は `A` |
| `ASC(s$)` | 最初の文字のコード。空なら 0 | `ASC("A")` は 65 |
| `STR$(x)` | 数を `PRINT` と同じ形の文字列に | `STR$(7)` は `7` |
| `VAL(s$)` | 文字列の頭の数を読む。数でなければ 0 | `VAL("12AB")` は 12 |
| `INKEY$` | 押されたキーの 1 文字。なければ空。待たない | §8.3 |
| `TIME$` | 時刻 `HH:MM:SS` | §8.2 |
| `DATE$` | 日付 `YYYY-MM-DD` | §8.2 |

```text
>A$="HELLO":PRINT LEFT$(A$,2);MID$(A$,2,3);RIGHT$(A$,2)
HEELLLO
>PRINT LEN(A$);ASC("A");CHR$(66);STR$(7)+"X";VAL("12.5")*2
5 65 B7X25
```

- 文字数の引数が文字列より長いときは、あるだけを返します。負の数は `ERR:ARGUMENT` です
- `VAL` は前の空白と `-` を読みます。`VAL("1E3")` は 1000 です

## 7. 画面と図形

### 7.1 液晶の大きさ

液晶の大きさはモデルで決まります。PANEL の TUNE で変えられます。変えると機械は再起動します（RAM は残り、画面は消えます）。

| モデル | ドット | 文字 | 備考 |
|---|---|---|---|
| POCKET-32 | 240×32 | 40 桁 4 行 | |
| POCKET-48 | 240×48 | 40 桁 6 行 | 既定 |
| POCKET-64 | 240×64 | 40 桁 8 行 | |
| HANDHELD-160 | 160×144 | 26 桁 18 行 | 4 階調。BASIC は最も濃い色で描く |

プログラムからは `LCDW`（幅）と `LCDH`（高さ）で大きさを読めます。画面の大きさに合わせて描くと、どのモデルでも動くプログラムになります。

```text
>PRINT LCDW;LCDH
240 48
```

### 7.2 座標

- 点の座標は左上が (0,0) です。x は右へ 0〜`LCDW`-1、y は下へ 0〜`LCDH`-1 です
- 文字と図形は同じ画面に描きます。文字は 6×8 ドットのます目で、桁 c、行 r の文字は x = 6c、y = 8r から始まります
- 座標の小数は 0 の方へ切り捨てます
- 座標は -4096〜4096 まで書けます。それを越えると `ERR:ARGUMENT` です。画面の外の点は描かずに飛ばします（エラーにはなりません）
- 文字が画面の下に届いて画面が上へ送られると、図形も一緒に上へ動きます。図形を描くプログラムは、はじめに `CLS` するのが確かです

### 7.3 画面の文

**CLS** — 画面（文字と図形）を全部消し、文字の位置を左上に戻します。CLS キーと同じです。

**LOCATE 桁,行** — 次に文字を出す位置を決めます。桁と行は 0 から数えます。画面より大きな値は画面の端にします。負の値は `ERR:ARGUMENT` です。

```text
>LOCATE 3,1:PRINT "AT"
   AT
```

**CURSOR n** — プログラムの実行中のカーソルの形を決めます。0 なし、1 下線、2 ブロック、それに 4 を足すと点滅します。プロンプトと `INPUT` では、いつも点滅するブロックになります。

**PSET x,y** — 点を打ちます。`PSET x,y,X` は点を反転します（点いていれば消し、消えていれば点ける）。

**PRESET x,y** — 点を消します。

**LINE (x1,y1)-(x2,y2)** — 2 点を結ぶ線を引きます。後ろに `,B` で四角の枠、`,BF` で塗った四角を描きます。

**CIRCLE (x,y),r** — 中心 (x,y)、半径 r の円を描きます。後ろに `,F` で塗った円です。r は 0〜4096 で、0 は中心の 1 点です。

**POINT(x,y)** — 点が点いていれば 1、消えていれば 0 です。画面の外は 0 です。

```text
>PSET 10,40:PRINT POINT(10,40);POINT(11,40)
1 0
>CIRCLE (220,40),6:PRINT POINT(226,40);POINT(220,40)
1 0
```

図形の文は、消すのではなく点けるだけです（`PRESET` と `PSET ,X` を除く）。動く絵は、`CLS` して描き直すか、同じ点を `PSET ,X` で 2 回反転して消します。

**GPRINT** — 今の文字の位置に、縦 8 ドットの列を左から描きます。1 列は 1 バイトで、ビット 0 がいちばん上の点です。

```
GPRINT 127;8;8;127
GPRINT "7F08087F"
```

- 値は数（0〜255）か、16 進 2 桁ずつの文字列です。16 進は数字と英大文字 `A`〜`F` で書きます。それ以外の文字は `ERR:ARGUMENT` です
- 値は `;` か `,` で区切ってつなげます
- 描いた後、文字の位置は次の文字のます目に進みます。文字と絵を並べて出せます

```basic
10 REM GPRINT: A LITTLE FACE AFTER A WORD
20 CLS:PRINT "HELLO ";
30 GPRINT "3C4295A1A195423C"
40 PRINT
```

## 8. 音と時間

### 8.1 BEEP と WAIT

**BEEP 周波数[,ミリ秒]** — ブザーを鳴らします。周波数は 0〜20000 Hz、長さは 0〜10000 ミリ秒（省くと 100）です。鳴り終わるまで次の文へ進みません。鳴っている間、表示記号 ♪ が点きます。

**WAIT n** — n/64 秒待ちます（`WAIT 64` で 1 秒）。n は 0〜32767 です。待っている間も BRK で止まります。

- 音量は elecdex の設定にある ELEC-16 の音量です。elecdex の音を切っているときや、音量が 0 のときは鳴りません
- 時間は PC の時計で進みます。PANEL の TUNE でクロックを速くしても、`WAIT` と `BEEP` の長さは変わりません

```basic
10 REM SCALE: DO RE MI WITH BEEP
20 FOR I=1 TO 8
30 READ F:BEEP F,250
40 NEXT I
50 DATA 523,587,659,698,784,880,988,1047
```

### 8.2 TIME$ と DATE$

`TIME$` は `13:04:05` の形の時刻、`DATE$` は `2026-10-02` の形の日付です。PC の時計から読みます。

`DATE$` から年・月・日を数として取り出すには、`VAL(LEFT$(DATE$,4))`、`VAL(MID$(DATE$,6,2))`、`VAL(RIGHT$(DATE$,2))` とします。SOFT CARD の CLOCK（時計）と BIORHYTH（バイオリズム）が使い方の例です（§9.3）。

### 8.3 INKEY$ でキーを読む

`INKEY$` は、押されたキーがあればその 1 文字を、なければ空の文字列を返します。キーを待ちません。ゲームのように、動きながらキーを読むときに使います。

- 英字の大小は CAPS と SHIFT に従います。既定（CAPS が掛かっている）では大文字です
- SHIFT、CAPS、カナのキーだけでは、キーとして返しません（モードが変わるだけ）
- BRK はキーではなく、プログラムを止めます

文字を打たないキーは、次の文字コードで返します。`ASC(INKEY$)` で調べます。

| キー | コード | キー | コード |
|---|---|---|---|
| ↑ | 30 | ENTER | 13 |
| ↓ | 31 | BS | 8 |
| ← | 28 | INS | 14 |
| → | 29 | DEL | 15 |
| SPACE | 32 | CLS | 12 |
| ANS | 20 | MODE | 16 |

キーを押すまで待つには、空の間くり返します。

```
50 IF INKEY$="" THEN 50
```

## 9. 記憶カード

ELEC-16 は 1 台に 1 枚の記憶カードを持ちます。プログラム、機械語、データを名前付きのファイルとして残せます。

### 9.1 ファイルの名前と大きさ

| 項目 | 決まり |
|---|---|
| 名前 | 英大文字と数字の 1〜8 文字、後ろに `.` と 1〜3 文字の拡張子 |
| 拡張子を省くと | プログラムは `.BAS`、データファイルは `.DAT` |
| カードの容量 | 256 KB |
| 1 ファイル | 32 KB まで |

名前の決まりに合わないと `ERR:FILE` です。英小文字は使えないので、CAPS を掛けて打ってください。

### 9.2 SAVE、LOAD、FILES、KILL

| 命令 | 働き |
|---|---|
| `SAVE "名前"` | プログラムをカードに書く。同じ名前があれば書き直す |
| `LOAD "名前"` | カードのプログラムを読む。今のプログラムと変数は消える |
| `FILES` | ファイルの名前と大きさ（バイト）、残りの容量（KB）を出す |
| `FILES "SOFT"` | SOFT CARD の一覧を出す（§9.3） |
| `KILL "名前"` | ファイルを消す |

```text
>NEW
>10 PRINT "SAVED"
>SAVE "HELLO"
>NEW
>LOAD "HELLO"
>LIST
10 PRINT "SAVED"
>FILES
HELLO.BAS    17
255 KB FREE
```

（`FILES` の答えは、カードの中身によって変わります。）

- プログラムは `LIST` と同じ文字で書きます（1 行の終わりに CR）。PC でもそのまま読めます
- `LOAD` は、ファイルが読めてから今のプログラムを消します。ない名前なら `ERR:NO FILE` で、今のプログラムは残ります
- `LOAD` の後ろに `:` で文を続けても実行されません（行ごと読み替わるため）。`LOAD` の後は `RUN` を打ってください
- 読むファイルの行は、行番号付きで 78 文字までです。合わない行があると `ERR:FILE` です
- `FILES` が出すのは 16 ファイルまでです。それより多いと `...` を出します

### 9.3 SOFT CARD（同梱ソフト）

どのカードからも読める、読み出し専用のプログラム集です。`FILES "SOFT"` で一覧を出し、`LOAD "PRIMES"` のように読みます。1 本ずつの遊び方・使い方は [SOFT CARD 取扱説明書](elec16-soft.md) にあります（ペインの FILES でプログラムを選んでも出ます）。

| 名前 | 中身 |
|---|---|
| SINEWAVE | 正弦波のグラフ（`PSET`、`LINE`） |
| BOUNCE | 箱の中ではねる玉（`PSET`、`PRESET`、`BEEP`、`INKEY$`） |
| PRIMES | 素数（`INPUT`、`FOR`） |
| CLOCK | 時計（`LOCATE`、`TIME$`、`DATE$`） |
| HITBLOW | 3 桁の数当て（配列、`RND`、`MID$`） |
| LANDER | 月着陸（`INPUT`、計算） |
| CANNON | 大砲で的を撃つゲーム（`CIRCLE ...,F`、`PSET ...,X`、`INKEY$`、`TAN`） |
| MAZE | 斜線の迷路（`CHR$`、`RND`） |
| BIORHYTH | バイオリズム（`GOSUB`、`DATE$`、`SIN`） |
| UNITS | 単位の換算（`ON GOSUB`） |
| ASMDEMO.BIN | 機械語で液晶に描く例（`LOAD "ASMDEMO.BIN":CALL 28672`） |
| TICKER.BIN | 打った文を機械語で流す（`LOAD "TICKER.BIN":CALL 28672`） |
| CHAT | AI と話す（`ASK`、`ASK TYPE`、語の切れ目で折り返す表示） |

- 読んだプログラムは、直して自分のカードに `SAVE` できます。同じ名前で `SAVE` すると、以後はそちらが読まれます
- SOFT CARD のファイルは消せません（`KILL` は `ERR:NO FILE`）

### 9.4 機械語のファイル

拡張子 `.BIN` のファイルには、RAM のバイトをそのまま書きます。

| 書き方 | 働き |
|---|---|
| `SAVE "名前.BIN",番地,長さ` | RAM の番地から長さバイトを書く（RAM の 0〜32767 の中だけ） |
| `LOAD "名前.BIN"` | 機械語の領域の先頭（28672、16 進 7000）に読む |
| `LOAD "名前.BIN",番地` | その番地に読む |

読み込める番地は、プログラムと変数の後ろから 31743（16 進 7BFF）までです。外れると `ERR:MEMORY` です。読み込んだ機械語は `CALL` で動かします（§10）。CODE 画面の SAVE TO CARD も `.BIN` を作ります。

### 9.5 データファイル

プログラムから文字や数を書き、後で読み直せます。同時に 2 つ（#1 と #2）まで開けます。

| 書き方 | 働き |
|---|---|
| `OPEN "名前" FOR OUTPUT AS #n` | 書くために開く。ファイルは空から書き直す |
| `OPEN "名前" FOR APPEND AS #n` | 終わりに足すために開く。なければ作る |
| `OPEN "名前" FOR INPUT AS #n` | 読むために開く。なければ `ERR:NO FILE` |
| `PRINT #n,項目…` | 書く。`,` は区切りの `,` を書く。行の終わりに CR |
| `INPUT #n,変数…` | 次の項目を順に読む |
| `EOF(n)` | 読むものが残っていなければ 1、残っていれば 0 |
| `CLOSE #n` / `CLOSE` | 1 つ / 全部を閉じる |

- n は 1 か 2 です。`#` は省けます。開いている番号をもう一度開くと `ERR:FILE` です
- 書いたものは、`CLOSE` で必ずカードに書き出されます。プログラムが止まったとき（`END`、エラー、BRK）も、開いているファイルは書き出して閉じます
- `PRINT #` は文字列を `"` なしで書きます。`,` を含む文字列は、読むときに分かれてしまいます。保つには `CHR$(34)` で囲んで書きます（`PRINT #1,CHR$(34)+A$+CHR$(34)`）
- `INPUT #` は、`,` か行の終わりまでを 1 項目として読みます。`"` で囲んだ項目は `,` を含めて 1 つです。読み終わった後は `ERR:NO DATA` です
- `.DAT` は `LOAD` できません（`ERR:FILE`）

```text
>OPEN "D" FOR OUTPUT AS #1:PRINT #1,"AB",12:CLOSE
>OPEN "D" FOR INPUT AS #1:INPUT #1,X$,Y:PRINT X$;Y:CLOSE
AB12
```

### 9.6 PC とのやりとり（PANEL の FILES）

ペインの PANEL にある FILES で、カードのファイルと SOFT CARD を見られます。

| ボタン | 働き |
|---|---|
| LOAD ▸ | 選んだファイルの `LOAD` を機械に打ち込む（`.BIN` は `LOAD "名前":CALL 28672`） |
| IMPORT | PC のファイルをカードに入れる（`.bas`、`.bin`、`.dat`、`.asm`） |
| EXPORT | カードのファイルを PC に書き出す |

PC で書いた `.bas` は、行番号付きのテキストなら IMPORT して `LOAD` できます。

## 10. 機械語と BASIC

### 10.1 メモリの地図

| 番地（16 進） | 番地（10 進） | 中身 |
|---|---|---|
| 0000–00FF | 0–255 | システムの作業域 |
| 0100–07FF | 256–2047 | BASIC の作業域 |
| 0800–6FFF | 2048–28671 | プログラムと変数 |
| 7000–7BFF | 28672–31743 | 機械語の領域（3 KB）。BASIC は使わない |
| 7C00–7FFF | 31744–32767 | スタック |
| 8000–DFFF | 32768–57343 | ROM |
| E000–F7FF | 57344–63487 | 液晶の VRAM |
| FF00–FFFF | 65280–65535 | I/O |

### 10.2 PEEK と POKE

- `PEEK 番地` はその番地の 1 バイト（0〜255）を返します。`POKE 番地,値` は 1 バイト書きます（値は下位 8 ビット）
- 番地は 0〜65535 です。-32768〜-1 も書け、上から数えます（-1 は 65535）
- 液晶の VRAM の 1 バイトは縦 8 ドットの列で、ビット 0 が上です。点 (x,y) のバイトは 57344 + INT(y/8)×`LCDW` + x です
- ROM などに書こうとすると、機械は例外でモニタに落ちます（`FAULT`）。モニタで `Q` を打てば BASIC に戻ります。プログラムは残っています

### 10.3 CALL

`CALL 番地` は、その番地の機械語を呼びます。機械語は `RET` で BASIC に戻ります。E16 の呼び出しの約束（s0〜s3 と sp を守る）に従ってください。

次の例は、28672 番地に `RET`（2 バイト: 2 と 33）だけを書いて呼びます。

```text
>POKE 28672,2:POKE 28673,33
>CALL 28672:PRINT "BACK"
BACK
```

機械語が戻らないときは、BRK を押します。機械語はそこで止まり、モニタに `BREAK AT 番地` と出ます（モニタの `G` で動かしたときと同じです）。`Q` で BASIC に戻ります。プログラムは残っています。

### 10.4 MON（機械語のモニタ）

`MON` でモニタに入ります。プロンプトが `*` に変わり、表示記号 MON が点きます。メモリのダンプ（`D`）、書き込み（`E`）、逆アセンブル（`U`）、実行（`G`）、ブレークポイント（`B`）、レジスタ（`R`）が使えます。`Q` で BASIC に戻ります。プログラムと変数はそのまま残ります。

モニタと E16 の命令の詳しい使い方は [E16 マニュアル](elec16-e16.md) にあります。TypeScript で書いて機械語にする CODE 画面は [e16c マニュアル](elec16-e16c.md) にあります。CODE の RUN ▸ は、作った機械語を 28672 番地に読み込んで `CALL 28672` を打ちます。

## 11. カナ

カナキー（PC では「かな」キー）で KANA モードに入ります。表示記号のカナが点きます。もう一度押すと出ます。

- KANA モードでは、カナのあるキーが半角カナを打ちます。並びは JIS かな配列です
- SHIFT を押してから打つと、小さいカナ（ｧｨｩｪｫｬｭｮｯ）と記号（ｦ ､ ｡ ･ ｢ ｣）になります
- 濁点 `ﾞ` と半濁点 `ﾟ` は、別の 1 文字として後に打ちます（`ｶﾞ` は `ｶ` と `ﾞ`）
- カナのないキー（SPACE、ENTER、矢印など）はそのまま働きます
- PC から打つときは、KANA モードの間、PC のキーの位置で決まります（IME は使いません）

| 段 | キーとカナ（SHIFT で） |
|---|---|
| Q の段 | Q ﾀ、W ﾃ、E ｲ（ｨ）、R ｽ、T ｶ、Y ﾝ、U ﾅ、I ﾆ、O ﾗ、P ｾ |
| A の段 | A ﾁ、S ﾄ、D ｼ、F ﾊ、G ｷ、H ｸ、J ﾏ、K ﾉ、L ﾘ、`;` ﾚ |
| Z の段 | Z ﾂ（ｯ）、X ｻ、C ｿ、V ﾋ、B ｺ、N ﾐ、M ﾓ、`,` ﾈ（､）、`.` ﾙ（｡）、`/` ﾒ（･） |
| テンキーの数字 | 1 ﾇ、2 ﾌ、3 ｱ（ｧ）、4 ｳ（ｩ）、5 ｴ（ｪ）、6 ｵ（ｫ）、7 ﾔ（ｬ）、8 ﾕ（ｭ）、9 ﾖ（ｮ）、0 ﾜ（ｦ） |
| テンキーの記号 | `-` ﾎ、`=` ﾍ、`*` ｰ、`(` ﾞ、`)` ﾟ（｢）、`+` ｹ、`/` ﾑ（｣）、`.` ﾛ |

カナを書けるのは、`"` の中、`REM` の後、`DATA` の項目だけです。それ以外の場所に書くと `ERR:SYNTAX` です。`INPUT` で文字列の変数にカナを入れることはできます。

```text
>PRINT "ｴﾚｸ"
ｴﾚｸ
>A=ｱ
ERR:SYNTAX
```

カナの文字コードは 161〜223（16 進 A1〜DF）です（`CHR$(177)` は `ｱ`）。

## 12. エラーメッセージ

エラーが起きると、プログラムは止まり、`ERR:` に続けて理由の語を出します。プログラムの中なら行番号も出します（`ERR:SYNTAX IN 30`）。

| メッセージ | 意味 | おもな原因 |
|---|---|---|
| `SYNTAX` | 書き方の誤り | つづりの誤り、区切りの抜け、3 文字以上の変数名、行番号 0、`"` の外のカナ、`DELETE` だけ |
| `OVERFLOW` | 数が大きすぎる | 計算の答えが ±1E100 以上、整数の引数が範囲の外（`PEEK 65536`、`WAIT 40000`） |
| `DIV BY 0` | 0 での割り算 | `1/0` |
| `ARGUMENT` | 引数が範囲の外 | `SQR -1`、`LOG 0`、`CHR$(256)`、`BEEP 30000`、座標が ±4096 の外、負の半径、`DIM A$*0`、255 文字を越える文字列、16 進でない `GPRINT` の文字、番号が収まらない `RENUM` |
| `NO LINE` | 行がない | `GOTO`、`GOSUB`、`RUN`、`RESTORE`、`ON` の行がない。65535 を越える行番号 |
| `NEXT` | 対応する FOR がない | `FOR` なしの `NEXT`、開いていない変数の `NEXT` |
| `RETURN` | 対応する GOSUB がない | `GOSUB` なしの `RETURN` |
| `MEMORY` | メモリが足りない | プログラム、変数、配列が入らない。`.BIN` の番地が範囲の外 |
| `TOO COMPLEX` | 入れ子が深すぎる | 括弧の入れ子が深い、`FOR` が 9 重、`GOSUB` が 17 重、1 文で作る文字列が 512 バイトを越える、`RENUM` で行が長くなりすぎる |
| `CONT` | 続けられない | `END`、エラー、最後まで実行した後、行の打ち込みの後の `CONT` |
| `TYPE` | 数と文字列の取り違え | `A$=1`、`"A"*2`、`IF` に文字列、`READ` や `INPUT #` で数の変数に文字 |
| `NO FILE` | ファイルがない | `LOAD`、`KILL`、`OPEN … FOR INPUT` の名前がカードにない |
| `CARD` | カードの誤り | カードがいっぱい、ファイルが 32 KB を越える |
| `NO DATA` | データがない | `READ` が `DATA` を読み尽くした。`INPUT #` がファイルを読み尽くした |
| `INDEX` | 添字が範囲の外 | `DIM A(5)` の `A(6)`、負の添字、次元の数の違い |
| `DIM` | 二度目の DIM | 作ってある配列や文字列変数をもう一度 `DIM` |
| `FILE` | ファイルの使い方の誤り | 名前の決まりに合わない、番号が 1〜2 でない、開いていない番号、開いている番号を開く、`LOAD` できない中身 |
| `LINK OFF` | LINK が OFF | PANEL の TUNE で LINK が OFF、AI のプロバイダが選ばれていない（§15） |
| `LINK HELD` | 人の操作がない | 前の `ASK` の後にキーが押されていない（§15.3） |
| `LINK` | AI が答えなかった | つながらない、鍵が違う・ない、時間切れ、断られた、検索できないモデル。理由は TUNE に出る（§15） |

エラーではない止まり方:

| メッセージ | 意味 |
|---|---|
| `BREAK IN 行` | BRK で止めた。`CONT` で続く |
| `STOP IN 行` | `STOP` で止めた。`CONT` で続く |

## 13. 制限の一覧

| 項目 | 制限 |
|---|---|
| プログラムと変数の領域 | 26,622 バイト（何もないとき） |
| 1 行の長さ | 78 文字 |
| 行番号 | 1〜65535 |
| 変数の名前 | 2 文字まで（英字、または英字と英字・数字） |
| 数 | 仮数 12 桁、表示 10 桁、指数 -99〜99 |
| 文字列の変数 | 既定 16 文字、`DIM` で 1〜255 文字 |
| 式の中の文字列 | 255 文字まで。1 つの文で作る文字列は合わせて 512 バイトまで |
| 配列 | 2 次元まで、添字は 0 から |
| FOR の入れ子 | 8 重 |
| GOSUB の入れ子 | 16 重 |
| 括弧の入れ子 | 18 段ほど（式の形で少し変わる） |
| 番地 | -32768〜65535 |
| 図形の座標 | -4096〜4096 |
| WAIT | 0〜32767（64 分の 1 秒） |
| BEEP | 0〜20000 Hz、0〜10000 ミリ秒 |
| 開けるデータファイル | 2 つ |
| 記憶カード | 256 KB、1 ファイル 32 KB、名前は 8+3 文字 |
| ASK | 質問 1〜255 文字、答えは答えの変数の大きさまで（255 文字まで）。AI は直近 10 往復を覚える |
| 機械語の領域 | 28672〜31743（16 進 7000〜7BFF、3 KB） |

メモリの使い方の目安です。

| もの | バイト |
|---|---|
| プログラムの 1 行 | 5 + 行番号の後の文字数（命令の語は 1 語 1 バイトと数える）。偶数に切り上げ |
| 数の変数 | 14 |
| 文字列の変数 | 8 + 長さ（偶数に切り上げ）。既定の 16 文字で 24 |
| 数の配列 | 10 + 8 × 要素の数 |
| 文字列の配列 | 10 + (長さ + 1) × 要素の数（偶数に切り上げ） |

残りのバイト数は、電源を入れたときと、モニタから `Q` で戻ったときに出ます。

## 14. プログラム例

どの例も、`NEW` してから打ち込み、`RUN` で動きます。

### 14.1 動く円

円が画面を右へ動き、輪になって戻ってきます。`CIRCLE` と `FOR` の例です。

```basic
10 REM MOVING CIRCLE: A BALL ACROSS THE SCREEN AND BACK
20 W=LCDW:H=LCDH:R=INT(H/4):Y=INT(H/2)
30 FOR K=1 TO 2
40 FOR X=R TO W-R-1 STEP 4
50 CLS:CIRCLE (X,Y),R,F:WAIT 1
60 NEXT X
70 FOR X=W-R-1 TO R STEP -4
80 CLS:CIRCLE (X,Y),R:WAIT 1
90 NEXT X
100 NEXT K
110 CLS
```

### 14.2 落ちる点をつかまえるゲーム

`INKEY$` でキーを読みながら動く、ゲームの形の例です。← → で下の棒を動かし、落ちてくる点を受けます。3 回落とすと終わりです。Q で途中でやめます。

```basic
10 REM CATCH: CATCH THE FALLING DOT. ARROWS MOVE, Q ENDS
20 W=LCDW:H=LCDH:P=INT(W/2):S=0:L=3
30 X=RND(W-20)+10:Y=8
40 CLS:PRINT "SCORE";S;"LEFT";L
50 LINE (P-6,H-1)-(P+6,H-1):PSET X,Y
60 K$=INKEY$
70 IF K$=CHR$(28) AND P>6 THEN P=P-6
80 IF K$=CHR$(29) AND P<W-7 THEN P=P+6
90 IF K$="Q" THEN END
100 WAIT 2:Y=Y+1:IF Y<H-1 THEN 40
110 IF ABS(X-P)<=6 THEN S=S+1:BEEP 1760,30:GOTO 30
120 L=L-1:BEEP 220,200:IF L>0 THEN 30
130 CLS:PRINT "GAME OVER  SCORE";S
```

- 40〜100 行がゲームの 1 こまです。画面を消し、点数、棒、点を描き、キーを 1 つ読み、点を 1 ドット落とします
- `CHR$(28)` と `CHR$(29)` は ← と → のコードです（§8.3）
- `WAIT 2` の数で速さが変わります

### 14.3 数当て

`INPUT` と `IF` の例です。1〜100 の数を当てます。

```basic
10 REM GUESS: A NUMBER FROM 1 TO 100
20 N=RND 100:T=0
30 INPUT "GUESS";G
40 T=T+1
50 IF G<N THEN PRINT "HIGHER":GOTO 30
60 IF G>N THEN PRINT "LOWER":GOTO 30
70 PRINT "RIGHT IN ";T;"TRIES"
```

### 14.4 並べ替え

配列の例です。10 個の乱数を小さい順に並べます。

```basic
10 REM SORT: TEN RANDOM NUMBERS IN ORDER
20 DIM A(9)
30 FOR I=0 TO 9:A(I)=RND 100:NEXT I
40 FOR I=0 TO 8:FOR J=I+1 TO 9
50 IF A(J)<A(I) THEN T=A(I):A(I)=A(J):A(J)=T
60 NEXT J:NEXT I
70 FOR I=0 TO 9:PRINT A(I);:NEXT I:PRINT
```

### 14.5 文字を逆さに

文字列の関数の例です。

```basic
10 REM REVERSE: A WORD BACKWARDS
20 INPUT "WORD";W$
30 R$=""
40 FOR I=LEN(W$) TO 1 STEP -1
50 R$=R$+MID$(W$,I,1)
60 NEXT I
70 PRINT R$
```

### 14.6 枠と対角線

図形の例です。キーを押すと消えます。

```basic
10 REM BOX: A FRAME AND ITS DIAGONALS; ANY KEY ENDS
20 CLS:W=LCDW-1:H=LCDH-1
30 LINE (0,0)-(W,H),B
40 LINE (0,0)-(W,H):LINE (0,H)-(W,0)
50 IF INKEY$="" THEN 50
60 CLS
```

### 14.7 データファイル

データファイルに 3 行書き、読み直して出します。

```basic
10 REM SCORES: A DATA FILE WRITTEN, THEN READ BACK
20 OPEN "SCORES" FOR OUTPUT AS #1
30 FOR I=1 TO 3
40 PRINT #1,"PLAYER";I,I*100
50 NEXT I
60 CLOSE #1
70 OPEN "SCORES" FOR INPUT AS #1
80 IF EOF(1) THEN 110
90 INPUT #1,N$,S:PRINT N$,S
100 GOTO 80
110 CLOSE #1
```

画面にはこう出ます。カードには `SCORES.DAT` が残ります。

```
PLAYER1   100
PLAYER2   200
PLAYER3   300
```

## 15. AI と話す（ASK）

ELEC-16 は、通信の口 **LINK** を通して AI と話せます。AI は elecdex の設定の AI（AI チャットペインと同じプロバイダ）が答えます。問いと答えは液晶の文字で行き来し、カナで聞けばカナで、英語で聞けば英語で答えます。

### 15.1 使う前に

1. elecdex の設定の AI で、プロバイダ（OpenAI、Anthropic、手元の LLM など）とモデルを決めておきます。鍵が要るプロバイダには鍵を入れます。鍵のないプロバイダも選べます（手元の LLM は鍵が要りません。要るのにないときは、聞いたときに `ERR:LINK` になります）
2. PANEL の TUNE で **LINK を ON** にし、プロバイダを選びます。液晶の上に LINK の表示記号が点きます
3. LINK は既定で OFF です。OFF の間は何も送られません（`ERR:LINK OFF`）

送られるのは、`ASK` で渡した問いと、それまでの会話（§15.4）だけです。プログラムやメモリのほかの中身は送りません。プロバイダによってはお金がかかります。

### 15.2 ASK

**ASK 問$,答$[,状態]** — 問いを AI に渡し、答えを文字列の変数に入れます。

```text
>DIM A$*200
>ASK "WHAT IS A PULSAR?",A$
>PRINT A$
A pulsar is a spinning neutron star that sends out beams of radio waves.
```

- 問いは文字列の式です（1〜255 文字）。答えは文字列の変数か、文字列の配列の要素に入ります
- **答えの長さは、答えの変数の大きさまで**です。AI にもその長さで答えるよう頼みます。既定の 16 文字では短すぎるので、`DIM A$*200` のように大きくしておきます（255 まで）。長すぎる答えは文の切れ目で切り、途中で切ったときは `...` を付けます。AI が自分の長さの上限で書きかけのまま止まったときも、書き終えた文までを出します
- 答えを待つ間、LINK の表示記号が点滅します。BRK で止めると `BREAK IN 行` になり、`CONT` でもう一度聞きます
- 問いに**カナが 1 文字でもあれば、カナで**答えます（漢字は出せないので、かなだけで、文節の間に空白を入れて書きます）。カナがなければ英語で答えます

```text
>ASK "ﾊﾟﾙｻｰｯﾃ ﾅﾆ?",A$
>PRINT A$
ﾊﾟﾙｻｰﾊ ﾋｶﾘﾉ ﾋﾞｰﾑｦ ﾀﾞｼﾅｶﾞﾗ ﾊﾔｸ ﾏﾜﾙ ﾁｭｳｾｲｼﾎﾞｼﾃﾞｽ｡
```

- **3 つ目に数の変数を書くと、答えがなくてもプログラムは止まりません**。変数には、答えが来れば 0、来なければ理由の番号が入り、答えの変数は空になります: 2 LINK が OFF、3 HELD（§15.3）、4 答えなかった（つながらない、鍵、時間切れ、断られた、検索できない。理由は TUNE に出る）、5 問いが正しくない、6 待つ間にペインが閉じた。書かなければ、これまでどおりエラー（`ERR:LINK` など、§12）で止まります。BRK はどちらでも `BREAK` で止まります

```basic
10 DIM A$*200
20 INPUT Q$
30 ASK Q$,A$,S
40 IF S=0 THEN PRINT A$ ELSE PRINT "NO ANSWER ";S
50 GOTO 20
```

- `ASK` は 1 つの文で作る文字列の 512 バイト（§4.4）のうち、問いと答えの分を使います。長い問いを `+` でつないで作り、長い答えを受けると `ERR:TOO COMPLEX` になることがあります。問いを変数に入れてから聞いてください

### 15.3 勝手に送らない（LINK HELD）

`ASK` は、**前の `ASK` の後に人が何か操作したときだけ**送ります。操作とは、ELEC-16 のキー（画面のキー、PC のキー）、BRK/ON、RESET、PANEL の RUN ▸ と LOAD ▸ です。PASTE で打たれた文字は数えません。

プログラムが続けて `ASK` すると、2 回目は `ERR:LINK HELD` で止まります。プログラムが AI を呼び続けてお金を使うことはありません。ふつうは `INPUT` で問いを打ってもらってから `ASK` するので、気にする必要はありません。

### 15.4 会話とタイプ（ASK NEW、ASK TYPE）

AI はそれまでの会話（直近 10 往復）を覚えていて、続きとして答えます。

**ASK NEW** — 会話を忘れ、次の `ASK` から新しい会話にします。RESET、電源 OFF、`ASK TYPE` で種類を変えたときも、会話は新しくなります（elecdex を閉じても忘れます）。

**ASK TYPE 種類** — AI の答え方を選びます。種類は名前（`ASK TYPE "QUIZ"`）か番号（`ASK TYPE 3`）で書きます。電源を入れたときは NORMAL です。

| 番号 | 名前 | 答え方 | 会話 |
|---|---|---|---|
| 0 | NORMAL | ふつうに短く答える | 覚える |
| 1 | TUTOR | やさしく教える先生 | 覚える |
| 2 | BASIC | ELEC-16 の BASIC と機械語の相談役 | 覚える |
| 3 | QUIZ | クイズを出し、次に打った答えを判定する | 覚える |
| 4 | STORY | テキストアドベンチャーの語り手。選択肢を出す | 覚える |
| 5 | POET | 詩、俳句、川柳 | 覚える |
| 6 | FORTUNE | 占い（遊び） | 覚える |
| 7 | DICT | 辞書。語の意味を 1〜2 文で | 1 回ずつ |
| 8 | TRANS | 和英・英和。カナの問いは英語に、英語の問いはカナに訳す | 1 回ずつ |
| 9 | SEARCH | ウェブで調べて要約する | 1 回ずつ |
| 10 | WEATHER | 地名の天気予報（今日と明日） | 1 回ずつ |

- SEARCH と WEATHER は、プロバイダ側のウェブ検索を使います（Anthropic、OpenAI の検索に対応したモデルなど）。検索できないプロバイダやモデルでは `ERR:LINK` になります
- 答えはすべて AI が書いたものです。辞書や天気も、AI の答えとして読んでください

### 15.5 例: 質問を繰り返す

```basic
10 DIM Q$*78,A$*200
20 INPUT Q$
30 IF Q$="" THEN END
40 ASK Q$,A$
50 PRINT A$
60 GOTO 20
```

SOFT CARD の **CHAT**（§9.3）は、タイプを選び、答えを 1 文字ずつ語の切れ目で折り返して出すチャットです。中身は `LIST` で読めます。機械語から LINK を使う方法は [E16 マニュアル](elec16-e16.md) の §4.8 と ROM サービス 8 にあります。
