モック: すべて架空のアカウントと数字で、AWS には何も問い合わせません。2026-11-08 の決定: 名前は AWS STATUS。初めて表示したアカウントでは Cost Explorer を ON にするかを上段の下の 1 枚で尋ねる（上の Cost Explorer で状態を替えられる）。Quota で月の見込み額の QUOTA（USD、既定 0 = OFF）、AWS public status で公開ステータスの障害の帯（障害のときだけ）、Simulate で QUOTA 超えと障害のトースト（読むのは見えている間だけ。ウィンドウが前に無いときは OS の通知）。ACTIVE の下部に推定であることを明記。ACTIVE はいま動いていて料金の発生しているものを推定の月額の大きい順に（立ち上げっぱなしの GPU インスタンス、12 TB の S3 バケットなど。推定は定価で、割引や無料枠は入れない）。ドリルダウン: ACTIVE でサービスの行（または上の積み上げの帯）を押すと 2 段目（上の棒を押すとクロスフィルタ、列の見出しで並べ替え）、行を押すと 3 段目（関係するものを押すと横へ掘れる、HISTORY でそのリソースの CloudTrail）。COST はサービスの棒から日ごとの曲線へ、その下の使用の種類・リージョン別は有料の Cost Explorer（上の Cost Explorer で ON にして試せる。押すたびに $0.01 と台帳に数える）。ATTENTION の行は該当リソースの 3 段目へ飛び、↗ は実物ではコンソールを開きます。Enter で下へ、Escape / Backspace で上へ。行・セル・帯・足元の台帳にマウスを止めると詳細カード。
