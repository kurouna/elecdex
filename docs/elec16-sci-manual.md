## 1. SCI-128 を出す

ペインのピッカー（Ctrl+Shift+A）で **elec-16 sci** の行を選びます。新しいユニット「SCI 1」（2 台目からは SCI 2、SCI 3 …）を作って電卓を開きます。

- ポケコンのユニットはそのまま残ります。電卓はユニットごとに RAM（変数、Ans、履歴、STATS の表など）を持ち、電源を切っても残ります
- パネルは CORE、MEM、TUNE です。TUNE ではモデルの切り替え（RAM が消えるので 2 度押し）、クロック、自動電源 OFF（10 分 / 30 分 / しない）を選べます
- 本体の色は SLATE、CHALK、PLAIN の 3 つ。PLAIN は本体を描かず、液晶とキーだけを今のテーマの色で出します
- 本体の描き方は FULL、SIMPLE、COMPACT、LCD。SIMPLE は液晶と数のキー（0〜9、.、EXP、ANS、DEL、AC、+ − × ÷、=）だけで、4 列に並んだ縦長の本体になり、ふつうの電卓のように使えます。ほかの 3 つはポケコンのモデルと同じです

## 2. 本体と画面

- 液晶は 128×64 ドットです。上が式の欄、下が答えの欄で、小数の答えは大きな数字で出ます
- 液晶の上に表示記号が並びます: `S`（SHIFT）、`A`（ALPHA）、`M`（M が 0 でない）、`STO`、`HYP`、`STAT`、`D` `R` `G`（角度）、`FIX`、`EXP`、`2D`、`▲` `▼`（履歴や続きがある）
- 電源を入れると、名前が少し出てから、前のモードの画面に戻ります

## 3. キー

キーの刻印が主の面、上の小さな字が SHIFT の面（SHIFT を押してから）、右の色の字が ALPHA の面（ALPHA を押してから）です。SHIFT の面は、そのキーの**逆の関数**です（LOG と 10ˣ、SIN と SIN⁻¹）。よく使う x² と √ はどちらも主の面にあり、その SHIFT 面は 3 乗（x³）と 3 乗根（∛）です。逆のないもの（gcd、lcm、% など）は FUNC のメニューにあります。

| √ | 平方根 | ∛（3 乗根） | |
| xʸ | 累乗 | ʸ√x（何乗根） | |
| LOG / LN | log / ln | 10ˣ / eˣ | |
| (−) | 符号 | abs（絶対値） | A |
| °′″ | 度・分・秒 | →DMS | B |
| HYP | 双曲線関数（CPLX では i） | （CPLX では ∠） | C |
| SIN / COS / TAN | | 逆関数 | D / E / F |
| f(x) | X に値を入れて計算 | FIND X | |
| x⁻¹ | 逆数 | x! | |
| nCr | 組合せ | 順列 nPr | |
| ( / ) | 括弧 | `,`（コンマ） | X / Y |
| M+ | M に足す | M− | M |
| EXP | ×10ⁿ | π | e |
| STO | 変数に入れる | RCL（呼ぶ） | |

- **ON** は電源を入れ、いつでも AC と同じに働きます（計算の途中でも止まります）。**SHIFT ON** で電源を切ります
- **DEL** はカーソルの前を消します。**SHIFT DEL（INS）** で、打った字がカーソルの位置の字を置き換える上書きになり、`OVR` が出ます（もう一度で挿入に戻る。分数や √ の枠の印は上書きしません）。**AC** は式を消します

## 4. CALC: 式を打って答える

式を打って **=** を押すと、下に答えが出ます。答えが出た後に + − × ÷ などを押すと、Ans（前の答え）から続きます。数を押すと新しい式になります。

**定数計算**: `34+57=` のように「数 演算子 数」の式を答えると、その演算が定数として残り、答えの左下に `K` が出ます。続けて数だけを打って = を押すと、定数の演算をします。+ − ÷ は右の数が、× は左の数が定数です。

| 打つもの | 答え |
|---|---|
| `34+57=` のあと `45=` | 102（45+57） |
| `68×25=` のあと `40=` | 2720（68×40） |
| `79−59=` のあと `56=` | −3（56−59） |
| `56÷8=` のあと `92=` | 11.5（92÷8） |

AC を押すと定数は消えます。

**角度の換算**: **SHIFT SETUP（ANGLE）** で、答え（打ちかけの式があればその答え）を次の角度の単位に換算し、SETUP の単位も切り替えます。DEG → RAD → GRAD → DEG の順です（`90` は 1.570796327 → 100 → 90）。

**2D 表示**（電源を入れた最初の形）では、分数、√、累乗が教科書の形で組まれます。

- **a/b** は直前の値（数、π、変数、括弧の組、√ や分数）を分子にします。前に値がなければ空の分数で、分子から打ちます。分母を打ち終えたら ▶ で分数の外へ出ます
- ▲ ▼ で分子と分母を行き来します（行った先の部分の終わりへ）
- 空の枠は点線の箱で、カーソルはその中に入ります。DEL は枠のところで中へ入り、空の枠は消します
- 高すぎて画面に入らない分数（分数の中の分数の中の分数…）は入らず、短いブザーが鳴ります

**計算の順位**（強い順）:

1. 括弧、関数（閉じ括弧は省けます。式の終わりで閉じます）、分数や √ の枠
2. 累乗、x²、x³、x⁻¹、x!、%（累乗は右から: `2^3^2` は 2⁹ = **512**）
3. 符号（−）: `-2²` は **−4**
4. LINE 表示の分数 `/`
5. nCr、nPr
6. **記号のない掛け算**（`2π`、`3(4+1)`、`2√3`）は × ÷ より強い: `1÷2π` は 1/(2π) = **0.159154943**、`6÷2(1+2)` は **1**
7. × ÷
8. + −

値の後ろの (−) は引き算になりません（`2(−)3` は SYNTAX）。引き算は − のキーです。

## 5. 答えの形と F⇄D

答えは、できるかぎり**正確な形**で出ます: 分数、√、整数と √ の和（`(p + r√s)/q` の形）。

| 打つもの | 答え |
|---|---|
| `1 a/b 3 ▶ + 1 a/b 6 =` | 1/2 |
| `√ 8 =` | 2√2 |
| `sin 45 =` | √2/2 |
| `tan 15 =` | 2−√3 |
| `1 a/b 2 ▶ xʸ 3 =` | 1/8 |

- **F⇄D** で、形 → 帯分数（1 より大きい分数のとき）→ 小数 → 形と回ります
- **SHIFT =（≈）** は初めから小数で答えます。**SHIFT F⇄D（ENG）** は指数が 3 の倍数の小数で、もう一度押すと指数を SI 接頭辞の字で出します（[§7](#7-func度分秒双曲線関数)）
- 式に小数点を打ったときは、小数で答えます（`0.1+0.2` は 0.3。F⇄D で 3/10）
- 途中で形の数が 10 桁を越えたり、違う √ どうしを足したりすると、その計算は小数だけで続きます（誤りにはなりません）
- 特別な角度（15° の倍数）の sin・cos・tan は形で答えます。sin 15° のように √ が 2 重になるものは小数です

## 6. 変数、Ans、M、履歴

- **STO** のあと変数のキー（A〜F は (−)〜TAN、X は (、Y は )、M は M+）で、答え（打ちかけの式があればその値）をしまいます。**SHIFT STO（RCL）** のあと変数のキーで呼び出します。式の中では **ALPHA** のあと変数のキーで使えます。変数も Ans も分数や √ の形のまま残ります
- **M+** で M に足し、**SHIFT M+（M−）** で引きます。M が 0 でない間、`M` が点きます
- **履歴**: = を押した式を 10 本まで残します。式が空か、答えの後で ▲ を押すと前の式、▼ で後の式が出ます。電源を切っても残ります

## 7. FUNC、度分秒、双曲線関数

**FUNC** のメニュー（数字で選ぶ。▼ ▲ で 7 ページ）。1 ページ目:

| 番号 | 関数 | 例 |
|---|---|---|
| 1 | gcd(a,b) 最大公約数 | `gcd(12,18)` = 6 |
| 2 | lcm(a,b) 最小公倍数 | `lcm(4,6)` = 12 |
| 3 | % | `50%` = 0.5、`500+25%` = 625、`500−25%` = 375 |
| 4 | int(x) 0 の方へ切り捨て | `int(-2.7)` = −2 |
| 5 | round(x) 今の表示の桁で丸める | FIX 2 で `round(1÷3)×3` = 0.99 |
| 6 | pol(x,y) 直交 → 極座標 | `pol(3,4)`: X = 5、Y = 53.13010235 |
| 7 | rec(r,θ) 極 → 直交座標 | `rec(2,90)`: X = 0、Y = 2 |
| 8 | d/dx(f(X),a) 微分 | [§12](#12-σ微分積分) |
| 9 | ∫(f(X),a,b) 積分 | [§12](#12-σ微分積分) |
| 0 | Σ(f(X),a,b) 和 | [§12](#12-σ微分積分) |

2 ページ目（ENG）: SI 接頭辞。1 `k`、2 `M`、3 `G`、4 `T`、5 `m`、6 `μ`、7 `n`、8 `p`、9 `f`（下）。

3 ページ目（MORE）: 1 `mod`（余り。下）、2 `Π(`（積。[§12](#12-σ微分積分)）、3 `→PRIME`（素因数分解。下）。

4 ページ目（RANDOM）: 1 `rand`（0 から 1 までの乱数）、2 `dice`（1〜6 の整数）、3 `coin`（0 か 1）、4 `rint`（0〜99 の整数）。= を押すたびに新しい数が出ます。

関数の名前は sin( と同じく小文字で、行に入る形のままメニューに出ます。pol と rec は 2 つの答えを変数 X と Y に入れ、2 行で見せます。

**%**: `b%` は b ÷ 100 です。+ や − の後の項が % で終わるときは、足す（引く）相手の b% になります: `500+25%` は 500 × 1.25 = 625（割増）、`500−25%` は 375（割引）。× と ÷ はそのままで、`200×5%` は 10、`50÷25%` は 200。括弧の中の % は相手を持たないので、`500+(25%)` は 500.25 です。`x^(` の指数の中も同じで、`2+3^(50%)` は 2+√3 = 3.732050808 です（括弧を閉じなくても同じ）。決めるのは項の終わりで、`500+2×25%` は 500 の 50% を足して 750、`500+25%²` は % で終わらないので 500.0625 です。

**SI 接頭辞**: 数の後ろに付けると、その数に 10 の累乗を掛けます: k は 10³、M は 10⁶、G は 10⁹、T は 10¹²、m は 10⁻³、μ は 10⁻⁶、n は 10⁻⁹、p は 10⁻¹²、f は 10⁻¹⁵。x² と同じく直前の値に付き、答えの後なら Ans に付きます。`47k×220p` は 0.00001034、`1÷(2π×1k×100n)`（1 kΩ と 100 nF の遮断周波数）は 1591.549431。接頭辞を打った式は、小数点を打った式と同じく小数で答えます（F⇄D で形）。変数の M と接頭辞の M は同じ字です。

**ENG と接頭辞**: SHIFT F⇄D（ENG）の答えで、もう一度 SHIFT F⇄D を押すと、×10ⁿ の代わりに接頭辞の字で出します（`47k×220p` は 10.34μ）。もう一度で ×10ⁿ に戻ります。指数が 0 か、10⁻¹⁵〜10¹² の外ならブザーです。

**mod**: `a mod b` は a を b で割った余りです（`127 mod 16` は 15、`1024 mod 7` は 2）。× ÷ と同じ強さで左から計算し（`10+7 mod 3` は 11、`6 mod 4×2` は 4）、記号のない掛け算はそれより強く結びます（A が 7 なら `100 mod 3A` は 16）。ほかの関数電卓の余りと同じく、0 以上の整数を 1 以上の整数で割るときだけ使えます。負の数、小数、0 で割るときは ERR:MATH です。

**→PRIME**: 答えを素因数の積で見せます。式があれば先に答えを出し、式が空なら Ans を分解します: `360` は 2³×3²×5、`2026` は 2×1013、`-12` は −2²×3。Ans は変わらず、F⇄D で元の答えに戻ります。2 以上 10¹⁰ 未満の整数（符号は付いてよい）だけで、0、±1、整数でない数、10¹⁰ 以上は短いブザーです。画面に収まらない積は 2 行に分けます。10 桁の大きな素数では数秒かかります（BUSY が点き、ON で止まります）。

**5・6 ページ目: STATS の結果を式の中で**。STATS の表（[§10](#10-モード-statsbasetableequation)）から、式を計算するときに求めます。

| ページ | 番号 | 値 |
|---|---|---|
| 5 | 1〜7 | n、x̄、σx、sx、ȳ、σy、sy |
| 5 | 8、9、0 | r、a、b |
| 6 | 1〜5 | Σx、Σx²、Σy、Σy²、Σxy |
| 6 | 6 | x′(y): STATS の曲線で y になる x の推定値 |
| 6 | 7 | y′(x): x での y の推定値 |
| 6 | 8 | c（QUAD の x² の係数） |
| 6 | 9 | x₂′(y): QUAD のもう 1 つの x |

**7 ページ目（DIST）: 正規分布**。1 `nlow(t)`（−∞ から t までの確率）、2 `nmid(t)`（0 から t まで）、3 `nup(t)`（t から +∞ まで。片側の p 値）、4 `→z`（値の後ろに付けて、STATS の表の x̄ と σx で標準化した (x − x̄)/σx）。`nlow(1.96)` は 0.975002105、`nmid(1)` は 0.341344746、`nup(3)` は 0.001349898（中では 12 桁で、`nup(10)` のような小さな値も 7.619853024×10⁻²⁴ と桁を保ちます）。表が 1、2、3、4、5 なら `5→z` は 1.414213562（√2）。表が空のときの →z は ERR:MATH です。

STATS の表が LINE で X が 1、2、3、Y が 2、4、7 なら、`10x̄+1` は 21、`y′(4)` は 9.333333333、`x′(9.3333333333)` は 4。表が空のとき、1-VAR の表で y の値や r・a・b を使ったときは ERR:MATH です。

- **度分秒**: °′″ を数の後で押すたびに °、′、″ が付きます: `12°30′` は 12.5。答えの後で °′″ を押すと度分秒の表示と行き来します（`1.51` は 1°30′36″）
- **HYP** のあと SIN・COS・TAN で sinh・cosh・tanh、SHIFT を挟むとその逆です（`HYP sin 1` = 1.175201194）
- **ʸ√x**: `3 SHIFT xʸ 8` は ∛8 = 2。奇数乗根は負の数にも使えます
- **abs**: `SHIFT (−)` で絶対値

## 8. f(x) と FIND X

式の中の X を変えながら計算します（X は ALPHA ( で打ちます）。

- **f(x)**: 式を打って f(x) を押すと `X?` と聞かれます。今の X の値が出ているので、そのままなら =、別の値なら打って = です。その X で式を計算します（`X²+1` で X = 3 なら 10）。もう一度 f(x) を押せば別の X で計算できます
- **FIND X（SHIFT f(x)）**: 式が 0 になる X を、`X?` の値から探します（ニュートン法）。見つかった X は Ans と X に入り、`DIFF=` にその X での式の値が出ます。`X²−2` を 1 から探すと 1.414213562、−1 から探すと −1.414213562。見つからなければ `ERR:FIND` です
- `X?` の値には、ALPHA で変数も打てます（STATS・EQUATION・MATRIX の升も同じ）

## 9. SETUP

**SETUP** で設定のページが開きます（▼ ▲ でページを移り、AC で戻る）。項目の組ごとに、今の設定が反転しています。数字を押すと、その組の反転が押した項目に移ります。設定は電源を切っても残ります。

| ページ | キー | 設定 |
|---|---|---|
| 1 | 1 / 2 | 2D / LINE（LINE は式を 1 行の文字で。分数は `/`、√ は `√(`） |
| 1 | 3 / 4 / 5 | 角度: DEG / RAD / GRAD |
| 1 | 6 / 7 | 答えを形で先に / 小数で先に |
| 1 | 8 / 9 / 0 | 小数の出し方: FIX（小数点以下の桁、続けて数字）/ EXP（有効桁、続けて数字。0 は 10 桁）/ AUTO（AUTO のときにもう一度 0 で AUTO2） |
| 2 | 1 / 2 | 1 より大きい分数: そのまま / 帯分数で |
| 2 | 3、= | メモリーをすべて消す（A〜F、X、Y、M、Ans、STATS の表、CPLX の Ans、行列。プログラムは消さない）。3 を押して = で消し、ほかのキーでやめる |
| 2 | ◀ ▶ | 液晶のコントラスト |

AUTO は、液晶の 10 桁に入る間は小数（小数点の前の 0 も 1 桁に数えます: 1/(2π) は 0.159154943）、10¹⁰ 以上と 10⁻⁹ 未満は指数で出します。AUTO2 は 0.01 未満も指数で出します（`3÷1000` は 3×10⁻³）。FIX と EXP は小数の答えにだけ効き、分数と √ の形には効きません。

## 10. モード: STATS、BASE、TABLE、EQUATION

**MENU** の 1〜8 でモードを選びます（今のモードが反転しています。AC で戻る）。1〜5 はこの章、6 CPLX・7 MATRIX・8 PROG は [§13](#13-cplx-複素数)〜[§15](#15-prog-プログラム) です。式と履歴はモードごとに持ち、戻れば続きからです。変数、Ans、M、SETUP、STATS の表は、どのモードでも同じです。

### STATS（統計）

1. 種類を選びます: 1:1-VAR（1 変数）、2 変数の 2:LINE（y = a + bx）、3:QUAD（y = a + bx + cx²）、4:EXP（y = a·e^(bx)）、5:LOG（y = a + b·ln x）、6:PWR（y = a·x^b）、7:INV（y = a + b/x）。8 で FREQ（度数）の列を出し入れします
2. 表に数を打ち、= で入れます（下の升へ進みます）。升には式も打てます。十字キーで升を動きます。40 行まで
3. 何も打たずに = を押すと、結果が出ます（▲ ▼ でページ、AC で表へ）

結果: n、x̄、σx（母集団の標準偏差）、sx（標本の標準偏差）、Σx、Σx²。2 変数ではさらに ȳ、r、a、b、c（QUAD だけ）、σy、sy、Σy、Σy²、Σxy。値のないもの（1 つしかないときの sx、QUAD の r など）は `-` です。

EXP・LOG・PWR・INV は、データをまっすぐにして（ln y、ln x、1/x）直線をあてはめます。r、a、b はその直線のもの（EXP と PWR の a は e^ で戻した値）で、平均や標準偏差は入力したデータそのものです。推定値は FUNC の 6 ページ目の x′(、y′(、QUAD の 2 つ目の x は x₂′( です。

FUNC で 1:行を挿入、2:行を削除、3:全部消す、4:種類を選び直す。

例: X が 2、4、6 で FREQ が 1、2、1 なら、n = **4**、x̄ = **4**、σx = **1.414213562**、sx = **1.632993162**、Σx = 2 + 4×2 + 6 = **16**、Σx² = **72**。

### BASE（2・5・8・10・16 進）

32 ビットの整数（2 の補数）で計算します。

- 基数は FUNC の 1 ページ目の 1:HEX、2:DEC、3:OCT、4:BIN、5:PEN（5 進）か、**F⇄D** で回します。今の基数が帯の右に出ます
- HEX の A〜F は (−)、°′″、HYP、SIN、COS、TAN を ALPHA なしで押します。基数にない数字は入りません
- + − × ÷（÷ は 0 の方へ切り捨て）、FUNC の 2 ページ目の 1:AND、2:OR、3:XOR、4:XNOR、5:not(、6:neg(、7:mod（0 以上の数どうしの余り。HEX で `FF mod 10` は F）。AND は OR・XOR・XNOR より強い
- どの計算の後も 32 ビットに戻します（DEC で `2147483647+1` は −2147483648）
- 答えは今の基数の値と、残りの 3 つの基数で同時に出ます。BIN は 16 ビットずつで、▲ ▼ で上と下の半分を見ます。足もとに 16 ビットがドットの列でも出ます

- PEN では 32 ビットを 0 以上の数として 14 桁の 5 進で出し、下に HEX・DEC・OCT・BIN の 4 つを並べます（ドットの列は出ません）

例: HEX で `D016 AND 0AFF0` は 00008010（DEC 32784）。PEN で `1234` は DEC 194。

### TABLE（関数の表）

1. f(X) を打ちます（X は ALPHA (）
2. = を押すと START?、END?、STEP? を順に聞かれます
3. X と f(X) の表が出ます（30 行まで）。▲ ▼ で動き、AC で f(X) に戻ります

例: `X²−2X`、START 1、END 5、STEP 1 で、f(X) は −1、0、3、8、15。行が 30 を越えるか STEP が 0 なら `ERR:RANGE` です。

### EQUATION（方程式）

1. 種類を選びます: 1:aX+bY=c、2:aX+bY+cZ=d、3:aX²+bX+c=0、4:aX³+bX²+cX+d=0。AC で戻ります（種類を選んだことがあれば係数の表へ、まだなら CALC へ）
2. 係数を表に打ち、= で入れます（右へ、行の終わりで次の行へ）
3. 何も打たずに = で解きます。AC で係数に戻ります

- 連立方程式と 2 次方程式は、係数が整数や分数なら答えも分数や √ の形です（`X²−2X−1=0` は X1 = 1+√2、X2 = 1−√2）
- 2 次方程式の解が虚数なら `re ± im i` で出ます（`3X²+2X+1=0` は −1/3 ± √2/3 i）。▼ で頂点（X²−2X−1 なら X = 1、Y = −2）
- 3 次方程式は 3 つの解（`X³−6X²+11X−6=0` は 3、2、1）
- 解が 1 つに決まらない連立方程式は `NO ONE SOLUTION` です

**不等式**: 種類の画面で ▼ を押すと、2 ページ目に 2 次の不等式（1:aX²+bX+c>0、2:<0、3:≥0、4:≤0）、3 ページ目に 3 次の不等式（aX³+bX²+cX+d の同じ 4 つ）があります。係数の打ち方は方程式と同じです。

- 答えは X の範囲を 1 行に 1 つ: `X²−X−6>0` は X<−2 と 3<X、`X²−X−6≤0` は −2≤X≤3、`X³−6X²+11X−6>0` は 1<X<2 と 3<X
- 根は方程式と同じく、分数や √ の形のまま出ます（`X²+X−1<0` は (−1−√5)/2<X<(−1+√5)/2）。1 行に収まらなければ 6 桁の小数です。F⇄D で小数と形を行き来します
- 重なった根や、解のないときも書き分けます: `X²−2X+1>0` は X≠1、`≤0` は X=1、`≥0` は ALL REAL NUMBERS、`<0` は NO SOLUTION。`X³−X²≥0` は X=0 と 1≤X
- a が負なら、不等号の向きも合わせて解きます（`−X²+X+6≥0` は −2≤X≤3）。a が 0 なら ERR:MATH です

## 11. CONST と CONV

**CONST（SHIFT FUNC）**: 物理定数を式に入れます。▼ ▲ で 4 ページ、1〜5 で選びます。値は CODATA 2022（NIST）を 12 桁にしたもので、単位は SI です。定数は名前で式に入り（`2h`）、小数で計算します。CALC、TABLE、CPLX、MATRIX、PROG で使えます。

| ページ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 1 | c₀ 光速 299792458 m/s | h プランク定数 6.62607015×10⁻³⁴ J s | ħ h/2π | G 万有引力定数 6.67430×10⁻¹¹ | ε₀ 真空の誘電率 8.8541878188×10⁻¹² F/m |
| 2 | μ₀ 真空の透磁率 1.25663706127×10⁻⁶ N/A² | qₑ 電気素量 1.602176634×10⁻¹⁹ C | mₑ 電子の質量 | mₚ 陽子の質量 | mₙ 中性子の質量 |
| 3 | u 原子質量定数 | NA アボガドロ定数 6.02214076×10²³ /mol | k ボルツマン定数 1.380649×10⁻²³ J/K | R 気体定数 8.31446261815 J/(mol K) | σ シュテファン＝ボルツマン定数 |
| 4 | g 標準重力加速度 9.80665 m/s² | atm 標準気圧 101325 Pa | a₀ ボーア半径 | α 微細構造定数 | Vm 理想気体のモル体積 0.0224139695450 m³/mol |

- 電気素量は、e がネイピア数なので qₑ です

**CONV（SHIFT MENU）**: 答え（式があれば先に答えます。なければ Ans）を別の単位に換算し、Ans にします。▼ ▲ で 4 ページ、各行の左が順、右が逆で、1〜9、0 で選びます。答えの上に換算の名前が出ます。CALC だけです。

| ページ | 換算 |
|---|---|
| 1 | in↔cm、ft↔m、yd↔m、mile↔km、nmi↔m（海里） |
| 2 | acre↔m²、gal↔L（米）、floz↔mL（米）、oz↔g、lb↔kg |
| 3 | °F↔°C、km/h↔m/s、kgf↔N、atm↔Pa、mmHg↔Pa |
| 4 | kgfm↔J、cal↔J（熱化学カロリー）、hp↔W（英馬力）、kWh↔MJ、eV↔J |

- `2` `SHIFT MENU` `1`（in→cm）は 5.08。換算の数は形のまま掛けるので、2D なら F⇄D で 127/25
- `100` °F→°C は 37.77777778、`36` km/h→m/s は 10

## 12. Σ、微分、積分

FUNC の 1 ページ目の 8・9・0 と、3 ページ目（MORE）の Π( です。どれも最初の引数が X の式で、引数をコンマ（SHIFT (）で区切ります。計算の間だけ X を変え、終わると元に戻します（誤りや ON で止まったときも）。

- **Σ(f(X),a,b)**: X = a, a+1, …, b の和。a と b は整数で a ≤ b、項は 1000 まで。和は形のまま計算するので、`Σ(1/X,1,4)` は 25/12、`Σ(X²,1,10)` は 385
- **Π(f(X),a,b)**: X = a, a+1, …, b の積。決まりは Σ と同じです。積も形のまま計算するので、`Π(X,1,5)` は 120、`Π(1+1/X,1,9)` は 10、`Π(X/2,1,3)` は 3/4
- **d/dx(f(X),a)**: X = a での傾き（数値微分）。`d/dx(X³,2)` は 12、`d/dx(ln(X),2)` は 0.5。DEG で `d/dx(sin(X),0)` は π/180（0.0174532925）。答えは小数で、計算の精度が足りないときは 9 桁に丸めます
- **∫(f(X),a,b)**: a から b までの積分（数値積分）。`∫(X²,0,3)` は 9、`∫(X,3,1)` は −4、RAD で `∫(sin(X),0,π)` は 2。端の値は使わないので、`∫(1/√(X),0,1)`（= 2）のように端で式が無限大になるものも計算できます。∫ の中に ∫ は入れられません（ERR:MATH）

## 13. CPLX: 複素数

**MENU 6**。式は LINE 表示で打ちます。`i` は **HYP**、`∠` は **SHIFT HYP** です（FUNC からも打てます）。

- 四則、(−)、x²、x³、x⁻¹、xʸ、√ が複素数で使えます: `(1+2i)(3−i)` は 5+5i、`1÷i` は −i、`√(−4)` は 2i、`(1+i)^4` は −4、`e^(iπ)` は −1
- **極形式**: `r∠θ`（θ は SETUP の角度）。`2∠90` は 2i
- **FUNC**: 1 `i`、2 `∠`、3 `abs(`（大きさ）、4 `arg(`（偏角、SETUP の角度）、5 `conj(`（共役）、6 `Re(`、7 `Im(`
- 答えは 2 行（上が実部、下が虚部）で、虚部が 0 なら大きな数字です。**F⇄D** で r と ∠θ の 2 行と行き来します（5+5i は 7.071067812 と ∠45）
- sin や log などの関数は、虚部が 0 の数にだけ使えます（ほかは ERR:MATH）。変数と定数は実数として使えます
- CPLX の Ans は CPLX だけのもので、CALC の Ans は変わりません。STO、RCL、M+、f(x) は使いません

## 14. MATRIX: 行列とベクトル

**MENU 7**。行列は **MatA〜MatD** と答えの **MatAns** で、3×3 までです。ベクトルは 1 行か 1 列の行列（成分 2 つか 3 つ）です。

1. **FUNC の 3 ページ目（EDIT）** で 1〜4 の行列を選び、行の数と列の数を 1〜3 の数字で打ちます（= で今の大きさのまま）
2. 升の表に成分を打ち、= で入れます（右へ、行の終わりで次の行へ）。何も打たずに = か AC で式に戻ります
3. 式を打って = で計算します。FUNC の 1 ページ目で `MatA`〜`MatAns`、2 ページ目で `det(` `trn(` `dot(` `cross(` `angle(` を打ちます

- 演算: + −（同じ大きさどうし）、×（行列どうし・数と）、÷ 数、(−)、x²、x³、x⁻¹（逆行列）、xʸ（−9〜9 の整数乗）、`det(`（行列式）、`trn(`（転置）
- ベクトル: `dot(u,v)`（内積）、`cross(u,v)`（外積。成分 2 つのベクトルは z = 0 として）、`abs(v)`（長さ）、`angle(u,v)`（なす角、SETUP の角度）
- 例: MatA = [[1,2],[3,4]] なら `det(MatA)` は −2、`MatA⁻¹` は [[−2,1],[1.5,−0.5]]。MatB = [1,2,3]、MatC = [4,5,6] なら `dot(MatB,MatC)` は 32、`cross(MatB,MatC)` は [−3,6,−3]
- 答えが行列なら MatAns に入り、升の表で見せます（= か AC で式に戻ると、答えの欄に `MatAns`）。数なら大きな数字で、Ans に入ります
- 大きさが合わないと ERR:DIM、逆行列のない行列の x⁻¹ は ERR:MATH です。成分は小数で持ちます（分数の形にはなりません）

## 15. PROG: プログラム

**MENU 8**。プログラムは 4 本（P1〜P4）、1 本 199 ステップ（トークン）までで、電源を切っても残ります。

1. 一覧で 1〜4 を押すとそのプログラムを打てます（LINE 表示。下に `P1 =:RUN AC:LIST`）。AC で一覧に戻り、一覧の AC で CALC へ
2. = で走らせます。最後に計算した値が Ans になり、プログラムの下に出ます。続けてキーを打つと、プログラムの終わりに続きます（CALC のように式は消えません）
3. ON でいつでも止まります。`?` と `▶` で待っている間は AC でも止まります（一覧に戻ります。プログラムは消えません）

文は `:` で区切ります。FUNC の初めの 3 ページがプログラムの記号で、その後に CALC の FUNC が続きます。

| 書き方 | 意味 |
|---|---|
| `式` | 計算して Ans に |
| `式→V` | 計算して変数 V（A〜F、X、Y、M）に。→ は STO で打てます |
| `式▶` | 値を出して、= を待つ（`式→V▶` も書けます） |
| `?→V` | `V?` と聞き、打った式の値を V に |
| `条件⇒文` | 条件が 0 でないときだけ文を行う |
| `=` `≠` `<` `>` `≤` `≥` | 比べる（文の一番外側で。正しければ 1、違えば 0） |
| `lbl n` / `goto n` | n（0〜9）の位置へ |

- 例: `?→A:?→B:√(A²+B²)` は直角三角形の斜辺（A = 3、B = 4 で 5）
- 例: `1→X:lbl 1:X▶:X+1→X:X≤3⇒goto 1` は 1、2、3 を順に出します
- ないラベルへの goto は ERR:SYNTAX です。誤りの画面で ◀ ▶ を押すと、その文の誤りの位置に戻ります（`?` に打った値の誤りは、その `?` の文へ）。FUNC の 3 ページ目の 0（CLEAR）でプログラムを消します

## 16. 誤りの画面

| 誤り | 意味 |
|---|---|
| ERR:MATH | 関数の範囲の外、0 で割った、大きすぎる |
| ERR:SYNTAX | 式が読めない（カーソルの位置で） |
| ERR:STACK | 括弧や関数の入れ子が深すぎる |
| ERR:FIND | FIND X が X を見つけられなかった |
| ERR:RANGE | TABLE の START・END・STEP が 1〜30 行にならない |
| ERR:DIM | MATRIX で、行列の大きさが計算に合わない |

◀ ▶ で式に戻ります（誤りを見つけた位置にカーソルがあります）。AC で式を消します。

## 17. 数と範囲

- 数は 10 進の 12 桁（表示は 10 桁）、指数は ±99。四則と平方根は正確に計算して 1 回だけ丸めます
- 分数や √ の形の数（p、r、q）は 10 桁まで、√ の中は 2〜99
- 式は 199 トークン（BASE は 99）まで。履歴は CALC が 10 本、BASE が 5 本
- n! は 69 まで、STATS は 40 行、TABLE は 30 行
- Σ は 1000 項まで、行列は 3×3 まで、プログラムは 4 本で 1 本 199 ステップまで
